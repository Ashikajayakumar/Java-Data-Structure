## 01. Introduction to Strings — Beginner Interview Preparation

If you're preparing for **Java DSA interviews as a beginner**, learn Strings after Arrays. String problems are very common in coding rounds, and many beginner questions test your understanding of **characters, indexing, loops, and basic operations**.

---

# 1. What is a String?

A **String** is a sequence of characters.

For example:

```text
"hello"
"Java"
"12345"
"abc123"
```

In Java, `String` is a **class** used to represent a sequence of characters.

```java
String name = "Ashika";
```

Here:

```text
A s h i k a
0 1 2 3 4 5   ← index
```

Each character has an **index**, starting from `0`.

---

# 2. Creating a String in Java

### Method 1 — String literal

Most commonly used:

```java
String str = "Hello";
```

### Method 2 — Using `new`

```java
String str = new String("Hello");
```

For beginner DSA, you will mostly use:

```java
String str = "Hello";
```

# 3. String Indexing

Just like an array, characters in a String have indexes.

```java
String str = "HELLO";
```

| Character |  H |  E |  L |  L |  O |
| --------- | -: | -: | -: | -: | -: |
| Index     |  0 |  1 |  2 |  3 |  4 |

To access a character:

```java
System.out.println(str.charAt(0));
```

Output:

```text
H
```

Another example:

```java
System.out.println(str.charAt(3));
```

Output:

```text
L
```

### Important

```java
str.charAt(index)
```

is used to access a character.

# 5. Traversing a String

One of the most important basic operations.

### Using `for` loop

```java
String str = "Hello";

for(int i = 0; i < str.length(); i++) {
    System.out.println(str.charAt(i));
}
```

Output:

```text
H
e
l
l
o
```

### How it works

```text
i = 0 → H
i = 1 → e
i = 2 → l
i = 3 → l
i = 4 → o
```

This pattern is extremely important because many String problems start with:

```java
for(int i = 0; i < str.length(); i++) {
    char ch = str.charAt(i);
}
```

# 7. Character vs String

This is very important in Java.

### Character

Use single quotes:

```java
char ch = 'A';
```

### String

Use double quotes:

```java
String str = "A";
```

So:

```java
'A'    → char
"A"    → String
```

# 8. Comparing Strings

❌ Don't use `==` to compare String contents.

Example:

```java
String a = "hello";
String b = "hello";

System.out.println(a == b);
```

`==` checks whether the references are the same, not whether the String contents are equal.

Use:

```java
a.equals(b)
```

Example:

```java
String a = "hello";
String b = "hello";

System.out.println(a.equals(b));
```

Output:

```text
true
```

### Ignore case

```java
a.equalsIgnoreCase(b)
```

Example:

```java
String a = "Hello";
String b = "hello";

System.out.println(a.equalsIgnoreCase(b));
```

Output:

```text
true
```

# 10. Getting a Substring

```java

```

Example:



Important:


```text

```

# 14. Important String Property — Immutable

This is a very common interview question.

### What does immutable mean?

Once a String object is created, its contents **cannot be changed**.

Example:

```java
String str = "Hello";

str.concat(" World");

System.out.println(str);
```

Output:

```text
Hello
```

Why?

Because:

```java
str.concat(" World");
```

creates a **new String**.

To store it:

```java
str = str.concat(" World");
```

Now:

```text
Hello World
```

### Interview question

**Q: Is String mutable or immutable in Java?**

**Answer:**

> String is immutable in Java. Once a String object is created, its value cannot be modified. Operations such as concatenation create a new String object instead of modifying the existing one.

# 18. String and ASCII

For beginner String problems, you should understand that characters have numeric values.

For example:

```text
'A' → 65
'B' → 66
'C' → 67

'a' → 97
'b' → 98
'c' → 99
```

You can convert a character to an integer:

```java
char ch = 'A';

System.out.println((int) ch);
```

Output:

```text
65
```

This becomes useful in:

* Character frequency
* Anagram problems
* Alphabet problems
* Case conversion
* Counting letters

# 19. Basic String Pattern You Should Memorize

For many beginner problems:

```java
String str = "hello";

for(int i = 0; i < str.length(); i++) {

    char ch = str.charAt(i);

    // process ch
}
```

Think of this as the **basic String traversal template**.

---

# 20. Example: Count Characters

Problem:

```text
Input:
hello

Output:
5
```

Solution:

```java
String str = "hello";

int count = 0;

for(int i = 0; i < str.length(); i++) {
    count++;
}

System.out.println(count);
```

But in practice, simply:

```java
System.out.println(str.length());
```

---

# 21. Example: Count Vowels

Input:

```text
hello
```

Output:

```text
2
```

Code:

```java
String str = "hello";

int count = 0;

for(int i = 0; i < str.length(); i++) {

    char ch = str.charAt(i);

    if(ch == 'a' || ch == 'e' || ch == 'i' ||
       ch == 'o' || ch == 'u') {

        count++;
    }
}

System.out.println(count);
```

This teaches you the important pattern:

```text
String
  ↓
Traverse
  ↓
Get character
  ↓
Check condition
  ↓
Update answer
```

---

# 22. Example: Reverse a String

Input:

```text
hello
```

Output:

```text
olleh
```

Code:

```java
String str = "hello";

for(int i = str.length() - 1; i >= 0; i--) {
    System.out.print(str.charAt(i));
}
```

Output:

```text
olleh
```
