# 202. Happy Number

Pattern: Number Manipulation + Cycle Detection (HashSet / Floyd’s Cycle Detection)

Difficulty: Easy

## 1. Problem

You are given a positive integer `n`.

Determine whether it is a Happy Number.

A number is called a Happy Number if:

1. Take each digit of the number.
2. Square each digit.
3. Add all the squared digits.
4. Repeat the process using the new sum.

If the process eventually reaches `1`, the number is a Happy Number.

If it gets stuck in a cycle that never reaches `1`, it is not a Happy Number.

Return:

- `true` if `n` is a Happy Number.
- `false` otherwise.

## 2. Example

Example 1

```
Input: n = 19
Output: true
```

Explanation:

```
19
= 1² + 9²
= 1 + 81
= 82

82
= 8² + 2²
= 64 + 4
= 68

68
= 6² + 8²
= 36 + 64
= 100

100
= 1² + 0² + 0²
= 1
```



Happy Number

&#x20;Since the process reaches `1`, return `true`.



Example 2

```
Input: n = 2
Output: false
```

Explanation:

```
2 → 4 → 16 → 37 → 58
  → 89 → 145 → 42 → 20
  → 4 → ...
```

The sequence repeats `4` and enters a cycle. It never reaches `1`.



Not Happy

&#x20;Return `false`.



## 3. Important Points

- We need to calculate the square of every digit.
- `% 10` extracts the last digit.
- `/ 10` removes the last digit.
- We repeat until the number becomes `1` or enters a cycle.
- A repeated number means the process is stuck in a cycle.

## 4. Main Concepts

### Concept 1: Extract digits

```
int digit = n % 10;
n = n / 10;
```

Example: `n = 19`

| Operation | Result |
| --------- | ------ |
| `19 % 10` | 9      |
| `19 / 10` | 1      |
| `1 % 10`  | 1      |
| `1 / 10`  | 0      |

### Concept 2: Square and add digits

```
sum = sum + digit * digit;
```

For `19`:

```
sum = 0

digit = 9
sum = 0 + 9 * 9 = 81

digit = 1
sum = 81 + 1 * 1 = 82
```

### Concept 3: Cycle Detection using HashSet

A `HashSet` stores numbers that we have already visited.

- If the current number is `1`, return `true`.
- If the current number already exists in the set, return `false`.
- Otherwise, store it and calculate the next sum.

## 5. Main Logic

```
Start
  |
  v
Is n equal to 1?
  |
  +-- Yes --> Return true
  |
  +-- No
       |
       v
Is n already visited?
  |
  +-- Yes --> Return false
  |
  +-- No
       |
       v
Add n to HashSet
       |
       v
Calculate sum of squares of digits
       |
       v
Set n = sum
       |
       v
Repeat
```

## 6. Java Solution

Approach: HashSet + Digit Manipulation

```
import java.util.*;

class Solution {
    public boolean isHappy(int n) {

        HashSet<Integer> set = new HashSet<>();

        while (n != 1 && !set.contains(n)) {

            set.add(n);

            int sum = 0;

            while (n > 0) {

                int digit = n % 10;

                sum = sum + digit * digit;

                n = n / 10;
            }

            n = sum;
        }

        return n == 1;
    }
}
```

## 7. Understand the Code

Part A: Create HashSet

```
HashSet<Integer> set = new HashSet<>();
```

Stores the numbers that we have already visited.

Example:

```
set = {19, 82, 68, 100}
```

Part B: Check the condition

```
while (n != 1 && !set.contains(n))
```

Two conditions:

1. `n != 1`: Continue until the number becomes `1`.
2. `!set.contains(n)`: Continue only if the number has not been visited before.

If either condition fails, the loop stops.

Part C: Store the current number

```
set.add(n);
```

Before calculating the next number, store the current number.

This helps identify a cycle.

Part D: Calculate square sum

```
int sum = 0;

while (n > 0) {
    int digit = n % 10;
    sum = sum + digit * digit;
    n = n / 10;
}
```

Extract every digit, square it, and add it to `sum`.

Part E: Update the number

```
n = sum;
```

Use the calculated sum as the next number.

Part F: Return the answer

```
return n == 1;
```

If the final number is `1`, return `true`. Otherwise, return `false`.

Iteration 2

