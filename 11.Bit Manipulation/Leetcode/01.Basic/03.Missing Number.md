## 1. Problem

Given an array `nums` containing `n` distinct numbers in the range `[0, n]`, find the one number that is missing from the array.

- Numbers start from `0`.
- Array contains `n` elements.
- One number from `0` to `n` is missing.
- Return the missing number.

## 2. Example

Example 1:

```
Input: nums = [3,0,1]

Output: 2

Explanation:
Expected numbers: 0, 1, 2, 3
Available numbers: 3, 0, 1
Missing number: 2
```

Example 2:

```
Input: nums = [0,1]

Output: 2
```

Example 3:

```
Input: nums = [9,6,4,2,3,5,7,0,1]

Output: 8
```

## 3. Important Points

- Array contains distinct numbers.
- Numbers are in the range `0` to `n`.
- Exactly one number is missing.
- We can solve using Sum Formula or XOR.
- XOR approach avoids integer overflow concerns associated with summing large ranges.

## 4. Main Concepts / Approach

We use:

- Array
- Bit Manipulation
- XOR (`^`)
- Loop

Why XOR?

XOR has two important properties:

```
a ^ a = 0
a ^ 0 = a
```

If we XOR all expected numbers and all array elements, matching numbers cancel each other. The remaining number is the missing number.

## 5. Main Logic (Step-by-Step)

1. Initialize `missing = nums.length`.
2. Iterate through the array.
3. XOR the current index with the current array element.
4. Matching numbers cancel each other.
5. The remaining value is the missing number.
6. Return the result.

## 6. Java Solution

Optimized Approach – XOR

```
class Solution {
    public int missingNumber(int[] nums) {

        int missing = nums.length;

        for(int i = 0; i < nums.length; i++) {
            missing = missing ^ i ^ nums[i];
        }

        return missing;
    }
}
```

## 7. Understand the Code

Part A – Initialize

```
int missing = nums.length;
```

Initialize with `n` because the expected range includes `n`.

Part B – Loop

```
for(int i = 0; i < nums.length; i++)
```

Visit every array index.

Part C – XOR Operation

```
missing = missing ^ i ^ nums[i];
```

- XOR the expected index.
- XOR the actual array value.
- Duplicate values cancel each other.
- Missing value remains.

Part D – Return

```
return missing;
```

Returns the missing number.

## 8. Complete Dry Run

Input:

```
nums = [3, 0, 1]
```

Array length = 3

Expected numbers: `0, 1, 2, 3`

Initially:

```
missing = 3
```

Iteration 1:

```
i = 0
nums[i] = 3

missing = 3 ^ 0 ^ 3
        = 0
```

Iteration 2:

```
i = 1
nums[i] = 0

missing = 0 ^ 1 ^ 0
        = 1
```

Iteration 3:

```
i = 2
nums[i] = 1

missing = 1 ^ 2 ^ 1
        = 2
```

Final:

```
Output = 2
```
