# 171. Excel Sheet Column Number

Pattern: Math + Number System Conversion (Base 26)
Difficulty: Easy

<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/5c3ac7d6-ede9-4fdd-8960-22f835a64339" />

## 1. Problem

Given a string `columnTitle` that represents an Excel column title, return its corresponding column number.

Excel columns are named using letters:

```
A, B, C, D, ... Z,
AA, AB, AC, ... AZ,
BA, BB, ... ZZ,
AAA, AAB, ...
```

Convert the given Excel column title into its corresponding number.

## 2. Examples

Example 1

```
Input: columnTitle = "A"
Output: 1
```

Example 2

```
Input: columnTitle = "AB"
Output: 28
```

Explanation:

```
A = 1
B = 2

AB = 1 × 26 + 2
   = 26 + 2
   = 28
```

Example 3

```
Input: columnTitle = "ZY"
Output: 701
```

Explanation:

```
Z = 26
Y = 25

ZY = 26 × 26 + 25
   = 676 + 25
   = 701
```

## 3. Important Points

- Excel column titles use 26 letters.
- `A = 1`, `B = 2`, ..., `Z = 26`.
- This is similar to Base-26 conversion.
- Unlike ordinary Base-26, Excel uses values from `1` to `26`, not `0` to `25`.
- Process the string from left to right.

Important formula:

```
result = result * 26 + value;
```

This formula is the key to solving the problem.

## 4. Main Concepts

### Concept 1: Character to number conversion

In Java, characters have ASCII values.

```
'A' = 65
'B' = 66
'C' = 67
...
'Z' = 90
```

To convert a character into its Excel number:

```
int value = ch - 'A' + 1;
```

Example:

| Character | Calculation | Value |
| --------- | ----------- | ----- |
| A         | 65 - 65 + 1 | 1     |
| B         | 66 - 65 + 1 | 2     |
| C         | 67 - 65 + 1 | 3     |
| Z         | 90 - 65 + 1 | 26    |

### Concept 2: Base-26 conversion

For every new character:

```
result = result * 26 + value;
```

Why multiply by 26?

Because every new letter moves us one position to the left in a base-26 number system.

For example, `AB`:

```
A = 1
B = 2

result = 1

result = 1 × 26 + 2
       = 28
```

## 5. Main Logic

```
Start
  |
  v
Take columnTitle string
  |
  v
Initialize result = 0
  |
  v
Traverse each character from left to right
  |
  v
Convert character into number
value = ch - 'A' + 1
  |
  v
Update result
result = result × 26 + value
  |
  v
Process next character
  |
  v
Return result
```

## 6. Java Solution

Approach: Base-26 Mathematical Conversion

```
class Solution {
    public int titleToNumber(String columnTitle) {

        int result = 0;

        for (int i = 0; i < columnTitle.length(); i++) {

            char ch = columnTitle.charAt(i);

            int value = ch - 'A' + 1;

            result = result * 26 + value;
        }

        return result;
    }
}
```

## 7. Understand the Code

Part A: Initialize result

```
int result = 0;
```

Stores the final Excel column number.

Initially, the result is zero.

Part B: Traverse the string

```
for (int i = 0; i < columnTitle.length(); i++)
```

Visits each character from left to right.

For `"AB"`:

```
i = 0 → A
i = 1 → B
```

Part C: Get the character

```
char ch = columnTitle.charAt(i);
```

Extracts the character at the current index.

Part D: Convert character into number

```
int value = ch - 'A' + 1;
```

Converts the alphabet into its Excel numerical value.

Example:

```
A → 1
B → 2
Z → 26
```

Part E: Update the result

```
result = result * 26 + value;
```

Multiplies the previous result by 26 and adds the current character value.

This builds the final number one character at a time.

Part F: Return answer

```
return result;
```

Returns the converted Excel column number.
