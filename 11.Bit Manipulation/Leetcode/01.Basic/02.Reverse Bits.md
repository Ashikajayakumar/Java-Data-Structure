# 190. Reverse Bits

LeetCode: [190. Reverse Bits](https://leetcode.com/problems/reverse-bits/?utm_source=chatgpt.com)

Pattern: Bit Manipulation – Bit Shifting

Difficulty: Easy

## 1. Problem

Given a 32-bit unsigned integer, reverse the order of its 32 bits and return the reversed bit representation as an integer.

- Bit at position 0 moves to position 31.
- Bit at position 1 moves to position 30.
- Reverse all 32 bits, including leading zeros.

## 2. Example

Input:

```
n = 43261596
```

Binary Representation:

```
Input:
00000010 10010100 00011110 10011100

Reversed:
00111001 01111000 00101001 01000000
```

Output:

```
964176192
```

Explanation: Reverse the complete 32-bit binary representation, including leading zeros.

## 3. Important Points

- Integer contains exactly 32 bits.
- Leading zeros must also be considered.
- Use bitwise AND (`&`) to extract the last bit.
- Use left shift (`<<`) to make space for the next bit.
- Use unsigned right shift (`>>>`) to move to the next input bit.
- Always perform exactly 32 iterations.

## 4. Main Concepts / Approach

We use:

- Bit Manipulation
- Bitwise AND (`&`)
- Left Shift (`<<`)
- Unsigned Right Shift (`>>>`)
- For Loop

Why this approach?

Instead of converting the number into a binary string, we reverse the bits directly using bitwise operations.

## 5. Main Logic (Step-by-Step)

1. Initialize `result = 0`.
2. Run a loop exactly 32 times.
3. Left shift `result` by 1 to create space.
4. Extract the last bit of `n` using `n & 1`.
5. Add that bit to `result` using `|`.
6. Right shift `n` by 1 using `>>>`.
7. Repeat until all 32 bits are processed.
8. Return `result`.

## 6. Java Solution

```
public class Solution {
    public int reverseBits(int n) {
        int result = 0;

        for (int i = 0; i < 32; i++) {
            result <<= 1;
            result |= (n & 1);
            n >>>= 1;
        }

        return result;
    }
}
```

## 7. Understand the Code

Part A – Initialize Result

```
int result = 0;
```

Stores the reversed binary number.

Part B – Loop 32 Times

```
for (int i = 0; i < 32; i++)
```

Processes every bit, including leading zeros.

Part C – Left Shift

```
result <<= 1;
```

Moves existing result bits one position to the left to make space for the next bit.

Part D – Extract and Append Last Bit

```
result |= (n & 1);
```

- `n & 1` extracts the rightmost bit.
- `|` appends that bit to the result.

Part E – Unsigned Right Shift

```
n >>>= 1;
```

Removes the processed rightmost bit and moves the next bit into position 0.

Part F – Return Result

```
return result;
```

Returns the reversed 32-bit integer.

## 11. Complexity Analysis

- Time Complexity: O(1) – Always executes exactly 32 iterations.
- Space Complexity: O(1) – Uses only a constant number of variables.

## 12. Important Interview Points

- `n & 1` → Extracts the last bit.
- `result << 1` → Creates space for the next bit.
- `result | bit` → Appends the extracted bit.
- `n >>> 1` → Unsigned right shift.
- Exactly 32 iterations are required because leading zeros matter.
- Java `int` is signed, but its 32-bit pattern can represent the required unsigned result.

Pattern Recognition Trick:

If a question asks to reverse binary bits, think:

`Extract → Shift Result → Append → Shift Input`
