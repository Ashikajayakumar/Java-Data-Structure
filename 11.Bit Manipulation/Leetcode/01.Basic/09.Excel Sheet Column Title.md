# 168. Excel Sheet Column Title

Pattern: Math + Number System Conversion (Base 26)

Difficulty: Easy

## 1. Problem

Given an integer `columnNumber`, return its corresponding Excel column title.

Excel columns are named like this:

```
A, B, C, D, ... Z,
AA, AB, AC, ... AZ,
BA, BB, BC, ... ZZ,
AAA, AAB, ...
```

Convert the given column number into its corresponding Excel column title.

## 2. Examples

Example 1

```
Input: columnNumber = 1
Output: "A"
```

Example 2

```
Input: columnNumber = 28
Output: "AB"
```

Explanation:

```
1  → A
2  → B
...
26 → Z
27 → AA
28 → AB
```

Example 3

```
Input: columnNumber = 701
Output: "ZY"
```

Explanation:

```
701 → ZY
```

## 3. Important Points

- Excel column titles use 26 letters: `A` to `Z`.
- This looks like a Base-26 conversion.
- But normal Base-26 uses digits `0` to `25`.
- Excel uses values `1` to `26`.
- Therefore, we must subtract `1` from the number before using `% 26` and `/ 26`.

Important trick:

```
columnNumber--;
```

This is the key step in this problem.

## 4. Main Concepts

### Concept 1: Character conversion

In Java, characters have numeric ASCII values.

```
'A' = 65
'B' = 66
'C' = 67
...
'Z' = 90
```

To convert a number from `0` to `25` into a letter:

```
char ch = (char)('A' + remainder);
```

Example:

```
remainder = 0 → A
remainder = 1 → B
remainder = 2 → C
remainder = 25 → Z
```

### Concept 2: Modulus `%`

Finds the remainder.

```
remainder = columnNumber % 26;
```

The remainder tells us which letter to use.

### Concept 3: Division `/`

Removes the part that has already been converted.

```
columnNumber = columnNumber / 26;
```

### Concept 4: Why subtract 1?

Excel numbering starts from `1`, but our character conversion starts from `0`.

| Excel number | Letter index                            |
| ------------ | --------------------------------------- |
| 1            | 0 → A                                   |
| 2            | 1 → B                                   |
| 26           | 25 → Z                                  |
| 27           | 0 → A (after carrying to next position) |

Therefore:

```
columnNumber--;
```

## 5. Main Logic

```
Start
  |
  v
Is columnNumber > 0?
  |
  v
Subtract 1
  |
  v
Find remainder = columnNumber % 26
  |
  v
Convert remainder into a character
  |
  v
Add character to result
  |
  v
Divide columnNumber by 26
  |
  v
Repeat until columnNumber becomes 0
  |
  v
Reverse the result
  |
  v
Return Excel column title
```

Why reverse?

We calculate the last character first.

For `28`:

```
28 → remainder 1 → B
 1 → remainder 0 → A
```

We get `BA`, but the correct answer is `AB`.

So, reverse the result.

## 6. Java Solution

Approach: Mathematical Conversion

```
class Solution {
    public String convertToTitle(int columnNumber) {

        StringBuilder sb = new StringBuilder();

        while (columnNumber > 0) {

            columnNumber--;

            int remainder = columnNumber % 26;

            char ch = (char)('A' + remainder);

            sb.append(ch);

            columnNumber = columnNumber / 26;
        }

        return sb.reverse().toString();
    }
}
```

## 7. Understand the Code

Part A: Create StringBuilder

```
StringBuilder sb = new StringBuilder();
```

Used to store the characters generated during conversion.

Part B: Loop condition

```
while (columnNumber > 0)
```

Continue until all digits are converted.

Part C: Subtract 1

```
columnNumber--;
```

Excel uses `1` to `26`, whereas our character indexes use `0` to `25`.

Part D: Find remainder

```
int remainder = columnNumber % 26;
```

Finds the letter position.

Part E: Convert into character

```
char ch = (char)('A' + remainder);
```

Converts the remainder into its corresponding alphabet.

Part F: Append character

```
sb.append(ch);
```

Stores the generated character.

Part G: Update column number

```
columnNumber = columnNumber / 26;
```

Moves to the next position.

Part H: Reverse and return

```
return sb.reverse().toString();
```

Reverses the characters because they were generated from right to left.

## 8. Complete Dry Run

Input:

```
columnNumber = 28
```

Iteration 1

```
columnNumber = 28

Step 1: Subtract 1
28 - 1 = 27

Step 2: Find remainder
27 % 26 = 1

Step 3: Convert to character
'A' + 1 = 'B'

Step 4: Append
sb = "B"

Step 5: Divide
27 / 26 = 1
```

Iteration 2

```
columnNumber = 1

Step 1: Subtract 1
1 - 1 = 0

Step 2: Find remainder
0 % 26 = 0

Step 3: Convert to character
'A' + 0 = 'A'

Step 4: Append
sb = "BA"

Step 5: Divide
0 / 26 = 0
```

Loop stops because `columnNumber = 0`.

Reverse:

```
"BA" → "AB"
```

Output: AB
