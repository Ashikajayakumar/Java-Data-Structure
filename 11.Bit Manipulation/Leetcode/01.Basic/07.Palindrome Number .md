# 9. Palindrome Number

Pattern: Math – Number Reversal

Difficulty: Easy

## 1. Problem

Given an integer `x`, return `true` if `x` is a palindrome. Otherwise, return `false`.

A palindrome number reads the same from left to right and right to left.

In simple words:

- Reverse the given number.
- Compare the reversed number with the original number.
- If both are equal, it is a palindrome.
- Otherwise, it is not a palindrome.

## 2. Example

Example 1:

```
Input: x = 121
Output: true

Explanation:
Original number = 121
Reverse number  = 121

Both are equal.
```

Example 2:

```
Input: x = -121
Output: false

Explanation:
Original number = -121
Reverse number  = 121-

Both are not equal.
```

Example 3:

```
Input: x = 10
Output: false

Explanation:
Original number = 10
Reverse number  = 01 (1)

Both are not equal.
```

## 3. Important Points

- A palindrome reads the same in both directions.
- Negative numbers are never palindromes because of the negative sign.
- Numbers ending in `0` are not palindromes, except `0` itself.
- We can solve this using number reversal.
- Avoid converting the number into a String for the mathematical approach.

Examples:

| Number | Reverse | Palindrome? |
| ------ | ------- | ----------- |
| 121    | 121     | Yes         |
| 12321  | 12321   | Yes         |
| 123    | 321     | No          |
| -121   | 121     | No          |
| 10     | 1       | No          |
| 0      | 0       | Yes         |

## 4. Main Concepts / Approach

We use:

- Mathematics
- Modulo (`%`)
- Division (`/`)
- While Loop
- Number Reversal

Why this approach?

We extract the last digit using `% 10` and construct the reversed number using multiplication and addition.

Example:

```
x = 121

Last digit = 121 % 10 = 1
Reverse    = 0 * 10 + 1 = 1

Last digit = 12 % 10 = 2
Reverse    = 1 * 10 + 2 = 12

Last digit = 1 % 10 = 1
Reverse    = 12 * 10 + 1 = 121
```

## 5. Main Logic (Step-by-Step)

1. If `x` is negative, return `false`.
2. Store the original number.
3. Initialize `reverse = 0`.
4. Run a while loop until `x` becomes `0`.
5. Extract the last digit using `x % 10`.
6. Add the digit to the reversed number.
7. Remove the last digit using `x / 10`.
8. Compare the original number with the reversed number.
9. Return `true` if both are equal; otherwise, return `false`.

## 6. Java Solution

Approach – Mathematics + Number Reversal

```
class Solution {
    public boolean isPalindrome(int x) {

        if(x < 0) {
            return false;
        }

        int original = x;
        int reverse = 0;

        while(x != 0) {
            int digit = x % 10;

            reverse = reverse * 10 + digit;

            x = x / 10;
        }

        return original == reverse;
    }
}
```

## 7. Understand the Code

Part A – Negative Number Check

```
if(x < 0) {
    return false;
}
```

Negative numbers cannot be palindromes.

Part B – Store Original Number

```
int original = x;
```

Stores the original value because `x` will change during reversal.

Part C – Initialize Reverse

```
int reverse = 0;
```

Stores the reversed number.

Part D – Extract Last Digit

```
int digit = x % 10;
```

Gets the last digit of the number.

Example:

```
121 % 10 = 1
```

Part E – Construct Reverse Number

```
reverse = reverse * 10 + digit;
```

Moves the existing digits one position left and adds the extracted digit.

Part F – Remove Last Digit

```
x = x / 10;
```

Removes the last digit.

Example:

```
121 / 10 = 12
```

Part G – Compare Numbers

```
return original == reverse;
```

If both numbers are equal, return `true`.

## 8. Complete Dry Run

Input:

```
x = 121
```

Initially:

```
original = 121
reverse = 0
x = 121
```

Iteration 1:

```
digit = 121 % 10 = 1

reverse = 0 * 10 + 1
        = 1

x = 121 / 10
  = 12
```

Iteration 2:

```
digit = 12 % 10 = 2

reverse = 1 * 10 + 2
        = 12

x = 12 / 10
  = 1
```

Iteration 3:

```
digit = 1 % 10 = 1

reverse = 12 * 10 + 1
        = 121

x = 1 / 10
  = 0
```

Loop stops because `x == 0`.

Final comparison:

```
original = 121
reverse  = 121

121 == 121 → true
```

Output:

```
true
```
