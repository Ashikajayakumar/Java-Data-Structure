# 231. Power of Two

Pattern: Bit Manipulation – Bitwise AND

Difficulty: Easy

## 1. Problem

Given an integer `n`, return `true` if it is a power of two. Otherwise, return `false`.

A number is a power of two if it can be expressed as:

``[ 2^x ]``

where `x` is a non-negative integer.

Examples of powers of two:

```
(2^0 = 1)
(2^1 = 2)
(2^2 = 4)
(2^3 = 8)
(2^4 = 16)
(2^5 = 32)
```

## 2. Example

Example 1:

```
Input: n = 1
Output: true

Explanation: 2^0 = 1
```

Example 2:

```
Input: n = 16
Output: true

Explanation: 2^4 = 16
```

Example 3:

```
Input: n = 3
Output: false

Explanation: 3 is not a power of two.
```

## 3. Important Points

- A power of two has exactly one set bit (`1`) in binary.
- All remaining bits are `0`.
- `n` must be greater than zero.
- Use `n & (n - 1)` to check whether only one set bit exists.

Binary examples:

| Number | Binary | Power of Two? |
| ------ | ------ | ------------- |
| 1      | 0001   | Yes           |
| 2      | 0010   | Yes           |
| 4      | 0100   | Yes           |
| 8      | 1000   | Yes           |
| 16     | 10000  | Yes           |
| 6      | 0110   | No            |
| 10     | 1010   | No            |

## 4. Main Concepts / Approach

We use:

- Bit Manipulation
- Bitwise AND (`&`)
- Binary Representation
- Brian Kernighan's Algorithm

Why this approach?

For every power of two, there is exactly one `1` in its binary representation.

Example:

```
8 = 1000
7 = 0111

  1000
& 0111
------
  0000
```

Therefore:

```
n & (n - 1) == 0
```

If `n` is positive and this condition is true, it is a power of two.

## 5. Main Logic (Step-by-Step)

1. Check whether `n` is greater than zero.
2. If `n <= 0`, return `false`.
3. Calculate `n & (n - 1)`.
4. If the result is `0`, return `true`.
5. Otherwise, return `false`.

## 6. Java Solution

Optimized Approach – Bit Manipulation

```
class Solution {
    public boolean isPowerOfTwo(int n) {

        if(n <= 0) {
            return false;
        }

        return (n & (n - 1)) == 0;
    }
}
```

## 7. Understand the Code

Part A – Check Positive Number

```
if(n <= 0) {
    return false;
}
```

- Zero is not a power of two.
- Negative numbers are not powers of two.

Part B – Bitwise AND

```
n & (n - 1)
```

Removes the rightmost set bit.

Part C – Check Result

```
return (n & (n - 1)) == 0;
```

- Result `0` → Exactly one set bit → Power of two.
- Result not `0` → More than one set bit → Not a power of two.
