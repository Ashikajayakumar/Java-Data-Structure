## 1. Problem

Given a positive integer `n`, return the number of set bits (1s) in its binary representation.

The number of set bits is also called the Hamming Weight.
 
## 2. Example

Example 1:

```
Input: n = 11
Binary: 1011

Output: 3

Explanation:
There are three 1s in the binary representation.
```

Example 2:

```
Input: n = 128
Binary: 10000000

Output: 1
```

## 3. Important Points

- Set bit means a bit with value `1`.
- We need to count all the 1s in the binary representation.
- Use the bitwise AND (`&`) operator.
- `n & (n - 1)` removes the rightmost set bit.
- Repeat until `n` becomes `0`.

## 4. Main Concepts / Approach

We use:

- Bit Manipulation
- Bitwise AND (`&`)
- Brian Kernighan's Algorithm
- While Loop

Why this approach?

Instead of checking every bit, we directly remove one set bit in each iteration.

## 5. Main Logic (Step-by-Step)

1. Initialize `count = 0`.
2. Check whether `n != 0`.
3. Perform `n = n & (n - 1)`.
4. This removes the rightmost `1` bit.
5. Increase `count` by 1.
6. Repeat until `n` becomes `0`.
7. Return `count`.

## 6. Java Solution

```
public class Solution {
    public int hammingWeight(int n) {
        int count = 0;

        while (n != 0) {
            n = n & (n - 1);
            count++;
        }

        return count;
    }
}
```

## 7. Understand the Code

Part A – Initialize Count

```
int count = 0;
```

Stores the total number of set bits.

Part B – While Condition

```
while (n != 0)
```

Continue until all set bits are removed.

Part C – Remove Rightmost Set Bit

```
n = n & (n - 1);
```

Removes the rightmost `1` from the binary representation.

Part D – Increment Count

```
count++;
```

Increases the count for every removed set bit.

Part E – Return Result

```
return count;
```

Returns the total number of set bits.

## 8. Complete Dry Run

Input:

```
n = 11

Binary = 1011
```

Initially:

```
count = 0
n = 1011
```

Iteration 1:

```
  1011
& 1010
------
  1010
```

- n = 1010
- count = 1

Iteration 2:

```
  1010
& 1001
------
  1000
```

- n = 1000
- count = 2

Iteration 3:

```
  1000
& 0111
------
  0000
```

- n = 0000
- count = 3

Loop stops because `n == 0`.

Final Output:

```
3
```
