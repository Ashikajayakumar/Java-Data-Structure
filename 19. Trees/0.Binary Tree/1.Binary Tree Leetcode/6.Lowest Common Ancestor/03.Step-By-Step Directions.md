## Step-by-step directions to solve the problem in Java

BFS – Level Order Traversal

## Step 1: Understand the question

You are given a binary tree.

You need to find the leftmost node at the deepest level.

Example:

```
          2
         / \
        1   3
           / \
          4   5
         /
        7
```

Let's identify the levels:

```
Level 0:          2

Level 1:       1     3

Level 2:             4     5

Level 3:             7
```

The deepest level is Level 3.

The leftmost node at that level is `7`.

Output: 7

## Step 2: Identify the pattern

Ask yourself:

- Do I need to visit every node? Yes.
- Do I need to process nodes level by level? Yes.
- Do I need the first node at the deepest level? Yes.

Therefore, choose:

BFS (Breadth-First Search) + Queue.

## Step 3: Understand how Queue works

A Queue follows FIFO:

First In, First Out.

For example:

```
Add:  2 → 1 → 3

Queue: [2, 1, 3]

Remove: 2

Queue: [1, 3]
```

For binary tree BFS:

1. Add the root.
2. Remove the front node.
3. Add its left child.
4. Add its right child.
5. Continue until the queue is empty.

## Step 4: Write the Java code step by step

1\. Create a Queue

```
Queue<TreeNode> q = new LinkedList<>();
```

This stores the nodes waiting to be processed.

2\. Add the root

```
q.add(root);
```

Start traversal from the root.

3\. Create an answer variable

```
int ans = 0;
```

This stores the leftmost value of the latest level.

4\. Run BFS

```
while(!q.isEmpty()) {
```

Continue while there are nodes in the queue.

5\. Find the current level size

```
int size = q.size();
```

This is important!

It tells us how many nodes belong to the current level.

6\. Process all nodes in the current level

```
for(int i = 0; i < size; i++) {
    TreeNode curr = q.poll();
}
```

Remove each node from the front of the queue.

7\. Identify the first node of the level

```
if(i == 0) {
    ans = curr.val;
}
```

Since we add left children before right children, the first node is the leftmost node of that level.

8\. Add left and right children

```
if(curr.left != null) {
    q.add(curr.left);
}

if(curr.right != null) {
    q.add(curr.right);
}
```

Always add the left child first.

9\. Return the answer

```
return ans;
```

When BFS finishes, `ans` contains the bottom-left value.

## Step 5: Complete Java solution

```
class Solution {
    public int findBottomLeftValue(TreeNode root) {

        Queue<TreeNode> q = new LinkedList<>();

        q.add(root);

        int ans = 0;

        while(!q.isEmpty()) {

            int size = q.size();

            for(int i = 0; i < size; i++) {

                TreeNode curr = q.poll();

                if(i == 0) {
                    ans = curr.val;
                }

                if(curr.left != null) {
                    q.add(curr.left);
                }

                if(curr.right != null) {
                    q.add(curr.right);
                }
            }
        }

        return ans;
    }
}
```

## Step 8: Important logic to remember

```
int size = q.size();

for(int i = 0; i < size; i++) {

    TreeNode curr = q.poll();

    if(i == 0) {
        ans = curr.val;
    }
}
```

Why do we use `size`?

Because we want to process only the nodes belonging to the current level.

Why `i == 0`?

Because the first node removed at each level is the leftmost node.

Why add left child before right child?

Because it maintains left-to-right order.
