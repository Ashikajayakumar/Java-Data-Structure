# 1123 – Lowest Common Ancestor of Deepest Leaves (LeetCode)

Important interview problem

DFS + Recursion + Height



## 1. Problem

Given the root of a binary tree, return the lowest common ancestor (LCA) of its deepest leaves.

- A leaf is a node with no left or right child.
- Deepest leaves are the leaves that are at the maximum depth.
- LCA is the lowest node that is an ancestor of all those deepest leaves.

## 2. Understand with an example

```
             3
           /   \
          5     1
         / \   / \
        6   2 0   8
           / \
          7   4
```

Deepest leaves are:

- Node `7`
- Node `4`

Their lowest common ancestor is node `2`.

## Expected output

# 2

The LCA of deepest leaves 7 and 4 is node 2.

## 3. Main logic – Height + Recursion

We need to find the height of the left and right subtrees.

At every node, compare:

- `left` = height of left subtree
- `right` = height of right subtree

There are three possibilities:

| Condition       | Meaning                            | Answer              |
| --------------- | ---------------------------------- | ------------------- |
| `left == right` | Deepest leaves exist on both sides | Current node is LCA |
| `left > right`  | Deepest leaves are on the left     | Return left result  |
| `right > left`  | Deepest leaves are on the right    | Return right result |

Important: We can solve this by returning two things from each recursive call:

1. The height of the subtree.
2. The LCA of its deepest leaves.

## 4. Java solution – Easy approach

We use a helper method that returns an array:

- `result[0]` → LCA node
- `result[1]` → Height of subtree

```
class Solution {

    public TreeNode lcaDeepestLeaves(TreeNode root) {

        return dfs(root)[0];
    }

    public TreeNode[] dfs(TreeNode root) {

        if(root == null) {
            return new TreeNode[]{null, null};
        }

        TreeNode[] left = dfs(root.left);
        TreeNode[] right = dfs(root.right);

        int leftHeight = left[1] == null ? 0 : (int)left[1].val;
        int rightHeight = right[1] == null ? 0 : (int)right[1].val;

        if(leftHeight > rightHeight) {
            return new TreeNode[]{left[0], new TreeNode(leftHeight + 1)};
        }

        if(rightHeight > leftHeight) {
            return new TreeNode[]{right[0], new TreeNode(rightHeight + 1)};
        }

        return new TreeNode[]{root, new TreeNode(leftHeight + 1)};
    }
}
```

Note: The above approach uses `TreeNode` objects to store heights, which is not recommended. A cleaner and safer Java solution uses a small helper class.

## 5. Recommended Java solution

```
class Solution {

    class Pair {
        TreeNode node;
        int height;

        Pair(TreeNode node, int height) {
            this.node = node;
            this.height = height;
        }
    }

    public TreeNode lcaDeepestLeaves(TreeNode root) {
        return dfs(root).node;
    }

    public Pair dfs(TreeNode root) {

        if(root == null) {
            return new Pair(null, 0);
        }

        Pair left = dfs(root.left);
        Pair right = dfs(root.right);

        if(left.height > right.height) {
            return new Pair(left.node, left.height + 1);
        }

        if(right.height > left.height) {
            return new Pair(right.node, right.height + 1);
        }

        return new Pair(root, left.height + 1);
    }
}
```

## 6. Line-by-line explanation

Step 1 – Create Pair class

```
class Pair {
    TreeNode node;
    int height;
}
```

Each recursive call returns:

- The LCA candidate.
- The height of that subtree.

Step 2 – Base condition

```
if(root == null) {
    return new Pair(null, 0);
}
```

An empty subtree has height `0`.

Step 3 – Recursively check both sides

```
Pair left = dfs(root.left);
Pair right = dfs(root.right);
```

Find the height and LCA result of the left and right subtrees.

Step 4 – Left subtree is deeper

```
if(left.height > right.height) {
    return new Pair(left.node, left.height + 1);
}
```

Deepest leaves are on the left side.

So return the left subtree's LCA.

Step 5 – Right subtree is deeper

```
if(right.height > left.height) {
    return new Pair(right.node, right.height + 1);
}
```

Deepest leaves are on the right side.

So return the right subtree's LCA.

Step 6 – Both heights are equal

```
return new Pair(root, left.height + 1);
```

Deepest leaves are present on both sides.

Therefore, the current node becomes their LCA.

We start from the bottom and move upwards.

Step 1: Leaf nodes

Nodes `6`, `7`, `4`, `0`, and `8` have no children.

Each leaf returns:

```
height = 1
LCA = itself
```

Step 2: Node 2

```
       2
      / \
     7   4
```

- Left height = 1
- Right height = 1
- Both are equal.

So node `2` is the LCA.

```
LCA = 2
Height = 2
```

Step 3: Node 5

```
       5
      / \
     6   2
        / \
       7   4

- Left height = 1

Right side is deeper.

Returns:

```

Height = 3
```

Step 4: Node 1

```
       1
      / \
     0   8
```

- Left height = 1
- Right height = 1

Both are equal.

Returns:

```
LCA = 1

```
             3

- Left height = 3

Left side is deeper.

Returns:

```
