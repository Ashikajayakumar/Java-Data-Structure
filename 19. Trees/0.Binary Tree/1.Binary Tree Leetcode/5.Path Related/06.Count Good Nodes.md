# 1448 – Count Good Nodes in Binary Tree (LeetCode)

## 1. Problem

Given the root of a binary tree, find the total number of good nodes.

A node is called a good node if, while travelling from the root to that node, there is no node with a value greater than the current node's value.

In simple words:

A node is good if its value is greater than or equal to all its ancestor node values.

Return the total number of good nodes.

## 2. Example

Input:

```
        3
       / \
      1   4
     /   / \
    3   1   5
```

Check each node:

| Node | Ancestor values | Good? |
| ---- | --------------- | ----- |
| 3    | None            | Yes   |
| 1    | 3               | No    |
| 4    | 3               | Yes   |
| 3    | 3, 1            | Yes   |
| 1    | 3, 4            | No    |
| 5    | 3, 4            | Yes   |

Good nodes:

```
3, 4, 3, 5
```

Output: 4

## 3. Important Point

A good node must satisfy:

```
Current Node >= Maximum Ancestor Value
```

Example:

```
        5
       /
      3
     /
    4
```

Check:

```
Node 5:
No ancestors → Good

Node 3:
3 < 5 → Not Good

Node 4:
4 < 5 → Not Good
```

Answer:

```
1
```

Important: Compare the current node with the maximum value among all its ancestors, not just its parent.

## 4. Main Logic

Your solution uses DFS + Recursion + Maximum Tracking.

1. If root is null → return 0.
2. Maintain the maximum value seen from the root to the current node.
3. Check whether the current node is greater than or equal to that maximum.
4. If yes → increase the good node count by 1.
5. Update the maximum value.
6. Recursively check the left subtree.
7. Recursively check the right subtree.
8. Return the total count.

### Formula

```
If current node >= maxSoFar:

    count = 1

Otherwise:

    count = 0
```

Update maximum:

\\[ newMax = \max(maxSoFar,current.val) \\]

## 5. Easy Recursive Java Solution

DFS + Recursion

```
class Solution {

    public int goodNodes(TreeNode root) {

        return dfs(root, Integer.MIN_VALUE);
    }

    public int dfs(TreeNode root, int max) {

        if(root == null){
            return 0;
        }

        int count = 0;

        if(root.val >= max){
            count = 1;
        }

        max = Math.max(max, root.val);

        int left = dfs(root.left, max);
        int right = dfs(root.right, max);

        return count + left + right;
    }
}
```

## 6. Understand Your Java Code

### Part A – Main Function

```
public int goodNodes(TreeNode root) {

    return dfs(root, Integer.MIN_VALUE);
}
```

We call the DFS function.

Why `Integer.MIN_VALUE`?

Because initially there are no ancestors.

So we start with the smallest possible integer.

```
max = -2147483648
```

This ensures the root node is always considered good.

### Part B – Base Condition

```
if(root == null){
    return 0;
}
```

If the node is null, there is nothing to count.

### Part C – Check Good Node

```
int count = 0;

if(root.val >= max){
    count = 1;
}
```

Check whether the current node is greater than or equal to the maximum ancestor value.

Example:

```
Current node = 4
Maximum      = 3
```

Check:

```
4 >= 3 → true
```

Therefore:

```
count = 1
```

If the condition is false:

```
count = 0
```

### Part D – Update Maximum

```
max = Math.max(max, root.val);
```

Update the maximum value for the next child nodes.

Example:

```
Previous max = 3
Current node = 4

New max = 4
```

### Part E – Recursive Calls

```
int left = dfs(root.left, max);
int right = dfs(root.right, max);
```

Check the left and right subtrees.

Both receive the updated maximum value.

### Part F – Return Total

```
return count + left + right;
```

Add:

```
Current node count
+ Left subtree good nodes
+ Right subtree good nodes
```
