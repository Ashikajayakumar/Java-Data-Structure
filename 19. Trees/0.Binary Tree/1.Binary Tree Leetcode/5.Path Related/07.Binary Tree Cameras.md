Important interview problem

Greedy + DFS + Postorder



## 1. Problem

Given the root of a binary tree, install cameras on some nodes.

Each camera can monitor:

- The node where it is placed.
- Its parent.
- Its immediate left and right children.

Return the minimum number of cameras needed to monitor every node in the tree.

## 2. Example

Consider this tree:

```
        0
       /
      0
     /
    0
   /
  0
```

One possible minimum camera placement:

```
        0
       /
      📷
     /
    0
   /
  📷
```

Output: `2`

A camera covers its parent, itself, and its immediate children.

## 3. Main logic – Greedy approach

We use postorder traversal (Left → Right → Root).

Why postorder?

We must first check whether the left and right children are covered before deciding whether to place a camera at the current node.

For every node, we identify three possible states:

| State | Meaning                           |
| ----- | --------------------------------- |
| `0`   | Node is not covered               |
| `1`   | Node has a camera                 |
| `2`   | Node is covered by a child camera |

### Three important conditions

Condition 1: If any child is not covered

Place a camera at the current node.

```
if(left == 0 || right == 0)
```

Condition 2: If any child has a camera

The current node is covered.

```
if(left == 1 || right == 1)
```

Condition 3: Otherwise

The current node is not covered.

```
return 0;
```

### 4. Java solution

```
class Solution {

    int cameras = 0;

    public int minCameraCover(TreeNode root) {

        if(dfs(root) == 0) {
            cameras++;
        }

        return cameras;
    }

    public int dfs(TreeNode root) {

        // Null node is considered covered
        if(root == null) {
            return 2;
        }

        // Check left and right subtrees
        int left = dfs(root.left);
        int right = dfs(root.right);

        // If any child is not covered,
        // place camera at current node
        if(left == 0 || right == 0) {
            cameras++;
            return 1;
        }

        // If any child has a camera,
        // current node is covered
        if(left == 1 || right == 1) {
            return 2;
        }

        // Both children are covered,
        // but current node is not covered
        return 0;
    }
}
```

## 5. Understand the three states visually

State 0 – Not covered

Both children are covered, but the current node is not covered.

State 1 – Camera placed

At least one child is not covered, so place a camera here.

State 2 – Covered

At least one child has a camera, so this node is covered.

Numbers inside circles represent DFS return states, not node values.

## 6. Dry run step by step

Consider this tree:

```
        0
       / \
      0   0
     /
    0
```

We process children before their parent.

Step 1: Start at the leftmost leaf.

```
    0
   /
  0  ← Current node
```

- Left child = null → state `2`
- Right child = null → state `2`
- Both children are covered.
- Current node is not covered.

Return `0`.

Step 2: Move to its parent.

```
      0  ← Current node
     /
    0
```

- Left child = `0`
- Right child = `2`
- One child is not covered.
- Place camera here.

Camera count = 1.

Return `1`.

Step 3: Move to the root.

```
        0  ← Current node
       / \
      0   0
```

- Left child = `1`
- Right child = `2`
- One child has a camera.
- Root is covered.

Return `2`.

Final root state is `2`, so no extra camera is needed.

Output: 1
