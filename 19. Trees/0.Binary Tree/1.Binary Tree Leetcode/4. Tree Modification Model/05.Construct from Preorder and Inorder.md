# 105 – Construct Binary Tree from Preorder and Inorder Traversal (LeetCode)
<img width="1312" height="1199" alt="image" src="https://github.com/user-attachments/assets/f3593869-e1d1-49a4-83db-b4543f7822ed" />

## 1. Problem

Given two integer arrays:

- `preorder` – represents the preorder traversal of a binary tree.
- `inorder` – represents the inorder traversal of the same binary tree.

Construct the original binary tree and return its root.

Remember:

- Preorder = Root → Left → Right
- Inorder = Left → Root → Right

## 2. Example

Input:

```
preorder = [3, 9, 20, 15, 7]

inorder  = [9, 3, 15, 20, 7]
```

Constructed Binary Tree:

```
        3
       / \
      9   20
         /  \
        15   7
```

Output:

```
[3, 9, 20, null, null, 15, 7]
```

## 3. Important Point

We use two traversals to identify the position of every node.

Preorder:

```
Root → Left → Right
```

```
[3, 9, 20, 15, 7]
 ↑
 Root
```

The first element is always the root.

Inorder:

```
Left → Root → Right
```

```
[9, 3, 15, 20, 7]
    ↑
   Root
```

The root divides the inorder array into two parts:

```
Left Subtree | Root | Right Subtree

[9]          |  3   | [15, 20, 7]
```

This is the main logic of the problem.

## 4. Main Logic

We use DFS + Recursion + HashMap.

1. If the preorder range is empty → return null.
2. Take the current preorder element as the root.
3. Find the root position in the inorder array.
4. Elements before the root belong to the left subtree.
5. Elements after the root belong to the right subtree.
6. Recursively construct the left subtree.
7. Recursively construct the right subtree.
8. Return the root.

### Formula

Let:

- `rootIndex` = root position in inorder.
- `leftSize` = number of nodes in the left subtree.

   ``` leftSize = rootIndex - inStart ```

Then:

```
Left subtree  → preorder starts at preStart + 1

Right subtree → preorder starts at preStart + leftSize + 1
```

## 5. Easy Recursive Java Solution

DFS + Recursion + HashMap

```
class Solution {

    HashMap<Integer, Integer> map = new HashMap<>();
    int index = 0;

    public TreeNode buildTree(int[] preorder, int[] inorder) {

        // Store inorder values and their indexes
        for(int i = 0; i < inorder.length; i++){
            map.put(inorder[i], i);
        }

        return solve(preorder, 0, inorder.length - 1);
    }

    public TreeNode solve(int[] preorder, int start, int end){

        // No elements
        if(start > end){
            return null;
        }

        // First element in preorder is root
        int val = preorder[index];
        index++;

        TreeNode root = new TreeNode(val);

        // Find root position in inorder
        int mid = map.get(val);

        // Build left subtree
        root.left = solve(preorder, start, mid - 1);

        // Build right subtree
        root.right = solve(preorder, mid + 1, end);

        return root;
    }
}
```

## 6. Understand Your Java Code

### Part A – Create HashMap

```
HashMap<Integer, Integer> map = new HashMap<>();
int index = 0;
```

The HashMap stores:

```
Node value → Inorder index
```

For example:

```
Inorder = [9, 3, 15, 20, 7]
```

HashMap:

| Value | Index |
| ----- | ----- |
| 9     | 0     |
| 3     | 1     |
| 15    | 2     |
| 20    | 3     |
| 7     | 4     |

Why HashMap?

To quickly find the root position in the inorder array.

### Part B – First Preorder Element

```
int val = preorder[index];
index++;
```

Preorder:

```
[3, 9, 20, 15, 7]
 ↑
```

First element = 3.

Therefore:

```
TreeNode root = new TreeNode(3);
```

### Part C – Find Root in Inorder

```
int mid = map.get(val);
```

Inorder:

```
[9, 3, 15, 20, 7]
    ↑
```

```
mid = 1
```

Now divide:

```
Left subtree  = [9]

Root          = [3]

Right subtree = [15, 20, 7]
```

### Part D – Build Left Subtree

```
root.left = solve(preorder, start, mid - 1);
```

For root 3:

```
start = 0
mid   = 1

Left range = 0 to 0
```

This constructs node 9.

### Part E – Build Right Subtree

```
root.right = solve(preorder, mid + 1, end);
```

For root 3:

```
Right range = 2 to 4
```

This constructs the subtree rooted at 20.
