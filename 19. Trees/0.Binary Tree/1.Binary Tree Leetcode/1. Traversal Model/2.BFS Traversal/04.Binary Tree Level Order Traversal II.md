# 107 – Binary Tree Level Order Traversal II (LeetCode)

## Problem

Given the root of a binary tree, return the bottom-up level order traversal of its nodes' values.

Bottom-up means:

- First, find the nodes at the deepest level.
- Then move level by level towards the root.
- Return the result from bottom to top.

# Important Point

Normal Level Order:

```
Root → Bottom
```

Level Order Traversal II:

```
Bottom → Root
```

Important: The nodes are visited using BFS (Queue), but the final levels are stored in reverse order.

# Main Logic

1. If root is null → return empty list.
2. Create a Queue to store tree nodes.
3. Insert the root into the Queue.
4. While Queue is not empty:
   - Find the current level size.
   - Create a new list for that level.
   - Remove nodes one by one.
   - Add their values to the level list.
   - Insert left and right children into the Queue.
5. Add the current level to the beginning of the answer.

# Main Concept – BFS + Queue

We use:

- Queue: To visit nodes level by level.
- Level list: To store nodes belonging to the same level.
- LinkedList: To insert each completed level at the beginning.

# Easy Recursive Java Solution (BFS)

```
class Solution {

    public List<List<Integer>> levelOrderBottom(TreeNode root) {

        List<List<Integer>> ans = new LinkedList<>();

        // Empty tree
        if(root == null){
            return ans;
        }

        Queue<TreeNode> q = new LinkedList<>();

        q.add(root);

        while(!q.isEmpty()){

            int size = q.size();

            List<Integer> level = new ArrayList<>();

            for(int i = 0; i < size; i++){

                TreeNode curr = q.poll();

                level.add(curr.val);

                // Add left child
                if(curr.left != null){
                    q.add(curr.left);
                }

                // Add right child
                if(curr.right != null){
                    q.add(curr.right);
                }
            }

            // Insert level at beginning
            ans.add(0, level);
        }

        return ans;
    }
}
```

# Why `ans.add(0, level)`?

Normally, in Level Order Traversal (LeetCode 102), we use:

```
ans.add(level);
```

This adds the level at the end.

But here we need bottom-up order.

So we use:

```
ans.add(0, level);
```

`0` means the first position.

Example:

First iteration – Root level

```
level = [3]

ans = [[3]]
```

Second iteration – Level 2

```
level = [9, 20]

ans = [[9, 20], [3]]
```

Third iteration – Level 3

```
level = [15, 7]

ans = [[15, 7], [9, 20], [3]]
```

Final answer:

```
[[15, 7], [9, 20], [3]]
```

- Every node is visited once.
- Queue and answer lists store the tree nodes' values.

# Interview Important – Difference Between 102 and 107

| Feature        | LeetCode 102     | LeetCode 107        |
| -------------- | ---------------- | ------------------- |
| Traversal      | BFS              | BFS                 |
| Data structure | Queue            | Queue               |
| Order          | Top to Bottom    | Bottom to Top       |
| Add level      | `ans.add(level)` | `ans.add(0, level)` |

Remember this pattern:

```
// LeetCode 102
ans.add(level);

// LeetCode 107
ans.add(0, level);
```
