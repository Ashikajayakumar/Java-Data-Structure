Let's understand your Java code using visualization + main logic + step-by-step dry run, similar to LeetCode 107.

## 1. Problem

Given the root of a binary tree, determine if it is height-balanced.

A binary tree is balanced if:

For every node, the difference between the height of its left subtree and right subtree is at most 1.

Formula:

\[|Height(left)-Height(right)| \leq 1\]

Return:

- `true` → If the tree is balanced.
- `false` → If the tree is not balanced.

## 3. Important Point

Balanced does NOT mean:

- Left and right sides must contain the same number of nodes.
- Tree must be perfectly symmetrical.

It means:

```
For EVERY node:

|Left Height - Right Height| <= 1
```

Even if the root is balanced, its child subtrees must also be balanced.

## 4. Main Logic

Your code uses two functions:

| Function       | Purpose                             |
| -------------- | ----------------------------------- |
| `isBalanced()` | Checks whether the tree is balanced |
| `height()`     | Calculates the height of a tree     |

Step-by-step:

1. If root is null → return true.
2. Calculate left subtree height.
3. Calculate right subtree height.
4. Find the absolute difference.
5. If difference is greater than 1 → return false.
6. Check left subtree recursively.
7. Check right subtree recursively.
8. If all nodes satisfy the condition → return true.

## 5. Understand Your Java Code

### Part A – isBalanced()

```
public boolean isBalanced(TreeNode root) {

    if(root == null){
        return true;
    }
```

If the tree is empty, it is balanced.

```
int left = height(root.left);
int right = height(root.right);
```

Calculate the height of left and right subtrees.

```
if(Math.abs(left - right) > 1){
    return false;
}
```

If the height difference is greater than 1, the tree is unbalanced.

```
return isBalanced(root.left) &&
       isBalanced(root.right);
```

Now check both subtrees.

`&&` means both conditions must be true.

### Part B – height()

```
public int height(TreeNode root){

    if(root == null){
        return 0;
    }

    int left = height(root.left);
    int right = height(root.right);

    return Math.max(left, right) + 1;
}
```

Height calculation:

- If node is null → height is 0.
- Calculate left height.
- Calculate right height.
- Take maximum height.
- Add 1 for current node.

Formula:

\\[ Height(root)=1+\max(left,right) \\]
