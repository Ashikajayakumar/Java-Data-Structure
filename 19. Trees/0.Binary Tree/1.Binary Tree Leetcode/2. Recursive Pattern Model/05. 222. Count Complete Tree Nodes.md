# 222 – Count Complete Tree Nodes (LeetCode)

## 1. Problem

Given the root of a complete binary tree, return the total number of nodes in the tree.

A complete binary tree means:

- Every level is completely filled except possibly the last level.
- The last level is filled from left to right.

Return the total number of nodes.

## 2. Example


```
        1
       / \
      2   3
     / \  /
    4  5 6
```

Count the nodes:

```
Node 1
Node 2
Node 3
Node 4
Node 5
Node 6
```

Answer:

```
6
```

## 3. Important Point

We need to find:

```
Total number of nodes in the tree
```

Not:

- Height of the tree.
- Number of leaf nodes.
- Number of levels.

For every node:

```
Total Nodes =
Left Subtree Nodes
+ Right Subtree Nodes
+ Current Node
```

## 4. Main Logic

Your code uses DFS + Recursion.

1. If root is null → return 0.
2. Count all nodes in the left subtree.
3. Count all nodes in the right subtree.
4. Add left count + right count + 1.
5. Return the total.

### Formula

\\[ Count(root)=Count(left)+Count(right)+1 \\]

## 5. Understand Your Java Code

### Part A – Base Condition

```
if(root == null){
    return 0;
}
```

If the node is null, there is nothing to count.

Example:

```
    2
   / \
 null null
```

Both children return 0.

### Part B – Count Left Subtree

```
int left = countNodes(root.left);
```

Recursively count all nodes in the left subtree.

### Part C – Count Right Subtree

```
int right = countNodes(root.right);
```

Recursively count all nodes in the right subtree.

### Part D – Calculate Total

```
return left + right + 1;
```

Why `+1`?

Because we must also count the current root node.

# 6. Complete Dry Run – Step by Step

Input:

```
        1
       / \
      2   3
     / \  /
    4  5 6
```

### Step 1 – Call countNodes(1)

```
int left = countNodes(root.left);
int right = countNodes(root.right);
```

First, the recursion goes towards the left.

### Step 2 – Call countNodes(2)

```
       2
      / \
     4   5
```

Again, it checks the left child.

### Step 3 – Call countNodes(4)

```
    4
   / \
 null null
```

Execute:

```
countNodes(null) = 0
```

Left:

```
left = 0
```

Right:

```
right = 0
```

Calculate:

```
return left + right + 1;
```

```
0 + 0 + 1 = 1
```

Therefore:

```
countNodes(4) = 1
```

### Step 4 – Call countNodes(5)

```
    5
   / \
 null null
```

Left = 0

Right = 0

```
0 + 0 + 1 = 1
```

Therefore:

```
countNodes(5) = 1
```

### Step 5 – Return to Node 2

Now we have:

```
       2
      / \
     4   5
```

Left subtree count:

```
left = 1
```

Right subtree count:

```
right = 1
```

Calculate:

```
return left + right + 1;
```

```
1 + 1 + 1 = 3
```

Therefore:

```
countNodes(2) = 3
```

### Step 6 – Call countNodes(3)

```
    3
   /
  6
```

Check left child.

Node 6:

```
left = 0
right = 0

0 + 0 + 1 = 1
```

Therefore:

```
countNodes(6) = 1
```

Right child of 3 is null:

```
countNodes(null) = 0
```

Return to node 3:

```
left = 1
right = 0
```

Calculate:

```
1 + 0 + 1 = 2
```

Therefore:

```
countNodes(3) = 2
```

### Step 7 – Return to Root Node 1

Now:

```
        1
       / \
      2   3
```

We already calculated:

```
left  = countNodes(2) = 3
right = countNodes(3) = 2
```

Execute:

```
return left + right + 1;
```

```
3 + 2 + 1 = 6
```

Final Answer: 6
