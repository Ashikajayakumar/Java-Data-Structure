## 1. Problem

Given the root of a binary tree, find all duplicate subtrees.

Two subtrees are considered duplicates if they have:
 
- The same node values.
- The same tree structure.

Return the root nodes of all duplicate subtrees.

Important: If a particular subtree appears more than twice, include it only once in the answer.

## 2. Example


Example input:

```
        1
       / \
      2   3
     /   / \
    4   2   4
       /
      4
```

Duplicate subtrees:

Duplicate 1:

```
    2
   /
  4
```

This subtree appears twice.

Duplicate 2:

```
4
```

This leaf node appears multiple times.

Output:

```
[[2, 4], [4]]
```

## 3. Important Point

Duplicate means:

```
Same Structure + Same Node Values
```

For example:

```
    2          2
   /            \
  4              4
```

These are NOT duplicates because their structures are different.

But:

```
    2          2
   /            /
  4            4
```

These are duplicates.

## 4. Main Logic

We use:

- DFS
- Postorder Traversal
- HashMap
- Subtree Serialization

Why Postorder?

Because we need to process:

```
Left Subtree
      ↓
Right Subtree
      ↓
Current Node
```

We identify a subtree using a unique ID.

For every node:

1. If root is null → return 0.
2. Find the left subtree ID.
3. Find the right subtree ID.
4. Create a unique representation using left ID, node value and right ID.
5. Check whether this representation already exists.
6. Increase its frequency.
7. If frequency becomes 2, add the current node to the answer.
8. Return its unique ID.

# 5. Java Solution

Optimized DFS + HashMap

```
class Solution {

    Map<String, Integer> map = new HashMap<>();
    Map<Integer, Integer> count = new HashMap<>();

    List<TreeNode> ans = new ArrayList<>();

    int id = 1;

    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {

        dfs(root);

        return ans;
    }

    public int dfs(TreeNode root) {

        if(root == null){
            return 0;
        }

        int left = dfs(root.left);
        int right = dfs(root.right);

        String key = left + "," + root.val + "," + right;

        if(!map.containsKey(key)){
            map.put(key, id++);
        }

        int curr = map.get(key);

        count.put(curr, count.getOrDefault(curr, 0) + 1);

        if(count.get(curr) == 2){
            ans.add(root);
        }

        return curr;
    }
}
```

# 6. Understand the Code

### Part A – HashMaps

```
Map<String, Integer> map = new HashMap<>();
Map<Integer, Integer> count = new HashMap<>();

List<TreeNode> ans = new ArrayList<>();
```

We use two HashMaps.

| Variable | Purpose                                    |
| -------- | ------------------------------------------ |
| `map`    | Stores subtree structure and its unique ID |
| `count`  | Stores how many times each subtree occurs  |
| `ans`    | Stores duplicate subtree roots             |

```
int id = 1;
```

Assigns a unique ID to each different subtree.

ID `0` is reserved for null nodes.

### Part B – Base Condition

```
if(root == null){
    return 0;
}
```

If the node is null, return 0.

### Part C – Postorder Traversal

```
int left = dfs(root.left);
int right = dfs(root.right);
```

First calculate left and right subtree IDs.

### Part D – Create Unique Key

```
String key = left + "," + root.val + "," + right;
```

Example:

```
left = 0
root.val = 4
right = 0
```

Key:

```
0,4,0
```

This represents a leaf node containing 4.

### Part E – Assign Unique ID

```
if(!map.containsKey(key)){
    map.put(key, id++);
}
```

If the subtree structure is new, assign a new ID.

If it already exists, reuse its ID.

### Part F – Count Occurrences

```
int curr = map.get(key);

count.put(curr, count.getOrDefault(curr, 0) + 1);
```

Increase the frequency of this subtree.

### Part G – Find Duplicate

```
if(count.get(curr) == 2){
    ans.add(root);
}
```

When the frequency becomes exactly 2, add the subtree root to the answer.

Why `== 2`?

Because if the same subtree appears 3 or 4 times, we should add it only once.
