## 1. Problem statement

Given the root of a binary tree, return the leftmost value in the last row of the tree.

In simple words:

1. Find the deepest level.
2. Find the first (leftmost) node at that level.
3. Return its value.

## 2. Example

```
          2
         / \
        1   3
           / \
          4   5
         /
        7
```

Level-wise:

```
Level 0:       2
Level 1:     1   3
Level 2:         4   5
Level 3:         7
```

Output: 7

## 3. Which approach should we use?

We can solve this problem using two approaches:

- BFS: Level Order Traversal using Queue.
- DFS: Recursion with depth tracking.

Let's understand BFS first.

## 4. BFS – Main logic

The important observation:

The first node processed at each level is the leftmost node of that level.

We maintain an answer variable and update it whenever we process the first node of a level.

The algorithm:

1. Create a Queue.
2. Add the root.
3. Get the current level size.
4. Process all nodes in that level.
5. When `i == 0`, update the answer.
6. Add left and right children.
7. Repeat until the queue is empty.

## 5. Java code – BFS

```
class Solution {
    public int findBottomLeftValue(TreeNode root) {

        Queue<TreeNode> q = new LinkedList<>();

        q.add(root);

        int ans = 0;

        while(!q.isEmpty()) {

            int size = q.size();

            for(int i = 0; i < size; i++) {

                TreeNode curr = q.poll();

                if(i == 0) {
                    ans = curr.val;
                }

                if(curr.left != null) {
                    q.add(curr.left);
                }

                if(curr.right != null) {
                    q.add(curr.right);
                }
            }
        }

        return ans;
    }
}
```

## 6. Understand the important code

A. Get the current level size

```
int size = q.size();
```

Suppose the queue contains:

```
Queue = [1, 3]
```

Then `size = 2`.

This means there are two nodes in the current level.

B. Process each node

```
for(int i = 0; i < size; i++) {
    TreeNode curr = q.poll();
}
```

We process only the nodes belonging to the current level.

C. Find the leftmost node

```
if(i == 0) {
    ans = curr.val;
}
```

Because BFS processes nodes from left to right, `i == 0` identifies the leftmost node.

D. Add children

```
if(curr.left != null) {
    q.add(curr.left);
}

if(curr.right != null) {
    q.add(curr.right);
}
```

Always add left before right to maintain left-to-right traversal.

## 8. Alternative approach – DFS (Recursion)

We can also solve this problem using recursion.

Main idea:

- Visit the left child first.
- Then visit the right child.
- Track the current depth.
- Update the answer only when we reach a new maximum depth.

```
class Solution {

    int maxDepth = -1;
    int ans = 0;

    public int findBottomLeftValue(TreeNode root) {

        dfs(root, 0);

        return ans;
    }

    public void dfs(TreeNode root, int depth) {

        if(root == null) {
            return;
        }

        if(depth > maxDepth) {
            maxDepth = depth;
            ans = root.val;
        }

        dfs(root.left, depth + 1);

        dfs(root.right, depth + 1);
    }
}
```
