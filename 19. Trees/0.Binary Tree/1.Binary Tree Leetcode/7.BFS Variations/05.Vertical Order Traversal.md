## 1. Understand the problem

Given the root of a binary tree, return its vertical order traversal.

Imagine looking at a binary tree vertically, from left to right.

Rules:

1. Nodes in the same column belong to the same vertical line.
2. Sort nodes by row (top to bottom).
3. If two nodes have the same row and column, sort their values in ascending order.

## 4. Important: Three sorting rules

This is the most important concept in LeetCode 987.

Suppose two nodes have the same row and column:

```
        1
       / \
      2   3
       \ /
        5 4
```

Coordinates:

| Node | Row | Column |
| ---- | --- | ------ |
| 1    | 0   | 0      |
| 2    | 1   | -1     |
| 3    | 1   | 1      |
| 5    | 2   | 0      |
| 4    | 2   | 0      |

Nodes `5` and `4` have the same row and column.

Sort them by value:

```
4, 5
```

Remember the priority:

1. Column ascending.
2. Row ascending.
3. Value ascending.

## 5. Which data structures should we use?

We need three levels of sorting.

TreeMap – Column

Automatically sorts columns left to right

TreeMap – Row

Automatically sorts rows top to bottom

PriorityQueue – Values

Automatically sorts values in ascending order

Our data structure:

```
TreeMap<Integer,
    TreeMap<Integer, PriorityQueue<Integer>>> map;
```

Meaning:

- Outer TreeMap → column.
- Inner TreeMap → row.
- PriorityQueue → node values.

## 6. Java solution – BFS + TreeMap

```
class Solution {

    class Pair {
        TreeNode node;
        int row;
        int col;

        Pair(TreeNode node, int row, int col) {
            this.node = node;
            this.row = row;
            this.col = col;
        }
    }

    public List<List<Integer>> verticalTraversal(TreeNode root) {

        TreeMap<Integer, TreeMap<Integer, PriorityQueue<Integer>>> map
            = new TreeMap<>();

        Queue<Pair> q = new LinkedList<>();

        q.add(new Pair(root, 0, 0));

        while(!q.isEmpty()) {

            Pair curr = q.poll();

            TreeNode node = curr.node;
            int row = curr.row;
            int col = curr.col;

            map.putIfAbsent(col, new TreeMap<>());

            map.get(col).putIfAbsent(row, new PriorityQueue<>());

            map.get(col).get(row).add(node.val);

            if(node.left != null) {
                q.add(new Pair(node.left, row + 1, col - 1));
            }

            if(node.right != null) {
                q.add(new Pair(node.right, row + 1, col + 1));
            }
        }

        List<List<Integer>> ans = new ArrayList<>();

        for(TreeMap<Integer, PriorityQueue<Integer>> rows : map.values()) {

            List<Integer> column = new ArrayList<>();

            for(PriorityQueue<Integer> values : rows.values()) {

                while(!values.isEmpty()) {
                    column.add(values.poll());
                }
            }

            ans.add(column);
        }

        return ans;
    }
}
```

## 7. Code explanation step by step

Step 1 – Create Pair class

```
class Pair {
    TreeNode node;
    int row;
    int col;
}
```

We need to store the node and its coordinates together.

Step 2 – Create the map

```
TreeMap<Integer, TreeMap<Integer, PriorityQueue<Integer>>> map
    = new TreeMap<>();
```

This stores nodes in sorted column, row and value order.

Step 3 – Create the queue

```
Queue<Pair> q = new LinkedList<>();

q.add(new Pair(root, 0, 0));
```

Root starts at row 0 and column 0.

Step 4 – Remove a node

```
Pair curr = q.poll();

TreeNode node = curr.node;
int row = curr.row;
int col = curr.col;
```

Get the node and its coordinates.

Step 5 – Create the column

```
map.putIfAbsent(col, new TreeMap<>());
```

If the column does not exist, create it.

Step 6 – Create the row

```
map.get(col).putIfAbsent(row, new PriorityQueue<>());
```

If the row does not exist in that column, create a PriorityQueue.

Step 7 – Store the value

```
map.get(col).get(row).add(node.val);
```

Add the node value to its correct column and row.

Step 8 – Move left

```
q.add(new Pair(node.left, row + 1, col - 1));
```

Row increases by 1, column decreases by 1.

Step 9 – Move right

```
q.add(new Pair(node.right, row + 1, col + 1));
```

Row increases by 1, column increases by 1.
