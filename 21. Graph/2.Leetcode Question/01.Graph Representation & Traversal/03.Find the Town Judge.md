# 🔷 LeetCode 997 — Find the Town Judge

---

## 📌 Problem Statement

* In a town, there are n people labeled from 1 to n. There is a rumor that one of these people is secretly the town judge.
* If the town judge exists, then:

  * The town judge trusts nobody.
  * Everybody (except for the town judge) trusts the town judge.
  * There is exactly one person that satisfies properties 1 and 2.
  * You are given an array trust where trust[i] = [ai, bi] representing that the person labeled ai trusts the person labeled bi.
* If a trust relationship does not exist in trust array, then such a trust relationship does not exist.

### 🎯 Goal

Return the label of the town judge if the town judge exists and can be identified, or return `-1` otherwise.

---

# 📝 Examples

### Example 1

```text
Input: n = 2, trust = [[1,2]]
Output: 2
```

### Example 2

```text
Input: n = 3, trust = [[1,3],[2,3]]
Output: 3
```

### Example 3

```text
Input: n = 3, trust = [[1,3],[2,3],[3,1]]
Output: -1
```

---

# ⚙️ Constraints

* `1 <= n <= 1000`
* `0 <= trust.length <= 104`
* `trust[i].length == 2`
* All the pairs of trust are `unique`.
* `ai != bi`
* `1 <= ai, bi <= n`

---

# 💻 Your Code

```java
class Solution { 
    public int findJudge(int n, int[][] trust) { 
       int[]indoor=new int[n+1]; 
       int[] outdoor=new int[n+1]; 
       for(int t[]:trust){ 
        int a=t[0]; 
        int b=t[1]; 
        indoor[b]++; 
        outdoor[a]++; 
       } 
        for(int i=1;i<=n;i++){ 
            if(indoor[i]==n-1 && outdoor[i]==0){ 
                return i; 
            } 
        } 
       return -1; 
    } 
}
```

# 🔵 1. Create the Arrays

```java

int[] outdoor = new int[n + 1];
```

Since:


we create arrays of size `5`.

### ❓ Why `n + 1`?

Because people are numbered:

```text

```

We can simply ignore index `0`.

Initially:

```text
indoor  = [0, 0, 0, 0, 0]
outdoor = [0, 0, 0, 0, 0]
           ↑  ↑  ↑  ↑  ↑
           0  1  2  3  4
```

### 💡 Meaning

| Array        | Meaning                           |
| ------------ | --------------------------------- |
| `indoor[i]`  | How many people trust person `i`  |
| `outdoor[i]` | How many people person `i` trusts |

Think:

```text
indoor  → people coming IN
outdoor → people going OUT
```

# 🔵 6. Now the Second `for` Loop

Your code:

```java
for(int i = 1; i <= n; i++){ 

    if(indoor[i] == n - 1 && outdoor[i] == 0){ 
        return i; 
    } 
}
```

The judge must satisfy **two conditions**:

---

## ✅ Condition 1

```java
indoor[i] == n - 1
```

Everyone else must trust the judge.

For:

```text
n = 4
```

we have:

```text
n - 1 = 3
```

So the judge needs:

```text
indoor[i] == 3
```

---

## ✅ Condition 2

```java
outdoor[i] == 0
```

The judge must trust nobody.

---

# 🔎 Iteration 1: `i = 1`

Check:

```java
indoor[1] == 3
```

We have:

```text
indoor[1] = 0
```

So:

```text
0 == 3 ❌
```

Condition fails.

---

# 🔎 Iteration 2: `i = 2`

Check:

```java
indoor[2] == 3
```

We have:

```text
indoor[2] = 0
```

So:

```text
0 == 3 ❌
```

Fails.

---

# 🔎 Iteration 3: `i = 3`

Check:

```java
indoor[3] == 3
```

We have:

```text
3 == 3 ✅
```

Now check:

```java
outdoor[3] == 0
```

We have:

```text

```

Both conditions are true:

```text
indoor[3] == 3       ✅
outdoor[3] == 0      ✅
```

Therefore:

```java
return 3;
```
