1791. Find Center of Star Graph

There is an undirected star graph consisting of n nodes labeled from 1 to n. 
A star graph is a graph where there is one center node and exactly n - 1 edges that connect the center node with every other node.
You are given a 2D integer array edges where each edges[i] = [ui, vi] indicates that there is an edge between the nodes ui and vi.
Return the center of the given star graph.

 

Example 1:


Input: edges = [[1,2],[2,3],[4,2]]
Output: 2
Explanation: As shown in the figure above, node 2 is connected to every other node, so 2 is the center.
Example 2:

Input: edges = [[1,2],[5,1],[1,3],[1,4]]
Output: 1
 

Constraints:

3 <= n <= 105
edges.length == n - 1

Absolutely. This solution is much simpler than the BFS one. The key idea is:

> In a **star graph**, the center node appears in **both of the first two edges**.

Let's take an example and trace **every statement step by step**.

---

# 🔷 Problem

Suppose:

```java
edges = [
    [1,2],
    [2,3],
    [2,4]
];
```

The graph is:

```text
      1
      |
      2
     / \
    3   4
```

The center is:

```text
2
```

---

# 🔷 Your Code

```java
class Solution {
    public int findCenter(int[][] edges) {

        int a = edges[0][0];
        int b = edges[0][1];

        if(a == edges[1][0] || a == edges[1][1]){
            return a;
        }

        return b;
    }
}
```

Now let's execute it **line by line**.

---

# 🔷 Step 1 — Understand `edges`

Our input is:

```text
edges = [
    [1, 2],
    [2, 3],
    [2, 4]
]
```

Think of the 2D array like this:

```text
              0    1
            +----+----+
edges[0] →  | 1  | 2  |
            +----+----+
edges[1] →  | 2  | 3  |
            +----+----+
edges[2] →  | 2  | 4  |
            +----+----+
```

So:

```text
edges[0][0] = 1
edges[0][1] = 2

edges[1][0] = 2
edges[1][1] = 3

edges[2][0] = 2
edges[2][1] = 4
```

---

# 🔷 Step 2 — Get First Node

This line:

```java
int a = edges[0][0];
```

means:

> Take the first value from the first edge.

We have:

```text
edges[0][0] = 1
```

Therefore:

```text
a = 1
```

Current variables:

```text
a = 1
```

---

# 🔷 Step 3 — Get Second Node

Next:

```java
int b = edges[0][1];
```

We have:

```text
edges[0][1] = 2
```

Therefore:

```text
b = 2
```

Now:

```text
a = 1
b = 2
```

So the first edge is:

```text
[1, 2]

a     b
↓     ↓
1     2
```

---

# 🔷 Step 4 — The Important `if`

Now we reach:

```java
if(a == edges[1][0] || a == edges[1][1]){
    return a;
}
```

This is the main logic.

Let's break it into two conditions.

```text
a == edges[1][0]
```

OR

```text
a == edges[1][1]
```

The `||` means **OR**.

---

# 🟢 Condition 1

We know:

```text
a = 1
```

And:

```text
edges[1][0] = 2
```

So:

```text
a == edges[1][0]

1 == 2
```

❌ False.

---

# 🟢 Condition 2

Now:

```text
a == edges[1][1]
```

We know:

```text
a = 1

edges[1][1] = 3
```

Therefore:

```text
1 == 3
```

❌ False.

---

# 🔷 Combine Both Conditions

We have:

```text
1 == 2  → false

1 == 3  → false
```

The condition is:

```java
if(false || false)
```

Remember:

```text
false OR false = false
```

Therefore:

```text
if(false)
```

The `if` block is **not executed**.

So this does NOT happen:

```java
return a;
```

---

# 🔷 Step 5 — Execute `return b`

We reach:

```java
return b;
```

We already know:

```text
b = 2
```

Therefore:

```text
return 2;
```

Answer:

```text
2
```

🎯 The center is `2`.

# 🔷 Why Does This Work?

This is the important concept.

A **star graph** looks like:

```text
          1
          |
          |
      2---5---3
          |
          |
          4
```

The center is:

```text
5
```

Every edge contains the center:

```text
[5,1]
[5,2]
[5,3]
[5,4]
```

Therefore, if we look at just the **first two edges**:

```text
Edge 1 → [5,1]
Edge 2 → [5,2]
```

The common node is:

```text
5
```

So we only need to compare the nodes in the first edge with the nodes in the second edge.

Consider:

```text
edges = [
    [2,1],
    [2,3],
    [2,4]
]
```

Graph:

```text
      1
      |
      2
     / \
    3   4
```

Now:

```java
int a = edges[0][0];
```

gives:

```text
a = 2
```

And:

```java
int b = edges[0][1];
```

gives:

```text
b = 1
```

Now check:

```java
if(a == edges[1][0] || a == edges[1][1])
```

Substitute:

```text
if(2 == 2 || 2 == 3)
```

First condition:

```text
2 == 2 → true
```

Because `||` is OR, Java already knows the entire condition is true.

So:

```java
return a;
```

returns:

```text
2
```

# 🧠 Very Important: Why Only `edges[0]` and `edges[1]`?

You might wonder:

> "There could be many edges. Why are we checking only the first two?"

Because the problem guarantees that the graph is a **star graph**.

A star graph has:

```text
One center
   ↓
Connected to every other node
```

Therefore, the center **must appear in every edge**.

So:

```text
First edge:
[a, b]

Second edge:
[x, y]
```

The center must be one of:

```text
a or b
```

If `a` appears in the second edge:

```text
a == x
OR
a == y
```

then:

```text
a = center
```

Otherwise:

```text
b = center
```

That's exactly what your code does.


The given edges represent a valid star graph.
