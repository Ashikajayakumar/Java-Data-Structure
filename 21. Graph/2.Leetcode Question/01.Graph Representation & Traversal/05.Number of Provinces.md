547. Number of Provinces

There are n cities. Some of them are connected, while some are not. If city a is connected directly with city b, and city b is connected directly with city c, then city a is connected indirectly with city c.

A province is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an n x n matrix isConnected where isConnected[i][j] = 1 if the ith city and the jth city are directly connected, and isConnected[i][j] = 0 otherwise.

Return the total number of provinces. 

 ```

Example 1:


Input: isConnected = [[1,1,0],[1,1,0],[0,0,1]]
Output: 2
Example 2:

Input: isConnected = [[1,0,0],[0,1,0],[0,0,1]]
Output: 3
 ```

Constraints:

1 <= n <= 200
n == isConnected.length
n == isConnected[i].length
isConnected[i][j] is 1 or 0.
isConnected[i][i] == 1
isConnected[i][j] == isConnected[j][i]

# 🔷 LeetCode 547 — Number of Provinces

This problem is basically asking:

> **How many separate groups of connected cities are there?**

The easiest beginner approach is **DFS (Depth First Search)**.

---

## 1. First understand the matrix

Suppose:

```text
isConnected =

[
 [1, 1, 0],
 [1, 1, 0],
 [0, 0, 1]
]
```

We have **3 cities**:

```text
City 0
City 1
City 2
```

The matrix tells us whether two cities are directly connected.

|        | City 0 | City 1 | City 2 |
| ------ | ------ | ------ | ------ |
| City 0 | 1      | 1      | 0      |
| City 1 | 1      | 1      | 0      |
| City 2 | 0      | 0      | 1      |

So:

```text
0 ↔ 1

2
```

City `0` and `1` are connected.

City `2` is completely separate.

Therefore:

```text
Province 1 → {0, 1}
Province 2 → {2}

Answer = 2
```

#  Complete Java code

```java
class Solution {

    public int findCircleNum(int[][] isConnected) {

        int n = isConnected.length;

        boolean[] visited = new boolean[n];

        int provinces = 0;

        for (int i = 0; i < n; i++) {

            if (!visited[i]) {

                provinces++;

                dfs(i, isConnected, visited);
            }
        }

        return provinces;
    }

    private void dfs(int city, int[][] isConnected, boolean[] visited) {

        visited[city] = true;

        for (int j = 0; j < isConnected.length; j++) {

            if (isConnected[city][j] == 1 && !visited[j]) {

                dfs(j, isConnected, visited);
            }
        }
    }
}
```
