## 📌 Problem 
  
You are given an `m x n` image.  
  
Each number represents the **color of a pixel**. 
 
For example:

```text
image =

[
 [1, 1, 1],
 [1, 1, 0],
 [1, 0, 1]
]
```

You are also given:

```text
sr = 1
sc = 1
color = 2
```

This means:

> Start from the pixel at row `1`, column `1` and change its color to `2`.

Then change all pixels that:

1. Have the **same original color**.
2. Are directly connected to the starting pixel.
3. Are connected horizontally or vertically.



# 🖼️ Example

Input:

```text
image = [
    [1, 1, 1],
    [1, 1, 0],
    [1, 0, 1]
]

sr = 1
sc = 1

color = 2
```

Let's number the positions:

```text
        col
        0   1   2

row 0   1   1   1
row 1   1   1   0
row 2   1   0   1
```

Starting position:

```text
(sr, sc) = (1, 1)
```

So:

```text
        0   1   2
      ┌───┬───┬───┐
  0   │ 1 │ 1 │ 1 │
      ├───┼───┼───┤
  1   │ 1 │ 🔴│ 0 │
      ├───┼───┼───┤
  2   │ 1 │ 0 │ 1 │
      └───┴───┴───┘
            ↑
         (1,1)
```

The starting color is:

```text
originalColor = 1
```

We need to change all connected `1`s to `2`.

---

# 🔑 Important Concept: What Does "Connected" Mean?

Only **4 directions** are allowed.

```text
        (r-1,c)
           ↑
           |
(r,c-1) ← (r,c) → (r,c+1)
           |
           ↓
        (r+1,c)
```

We **DO NOT** consider diagonals.

For example:

```text
1  0
0  1
```

The two `1`s are **NOT connected**.

Because they only touch diagonally.

# 💻 Java Solution — DFS

```java
class Solution {

    public int[][] floodFill(  int[][] image,int sr,int sc,int color) {
        int originalColor = image[sr][sc];
        if (originalColor == color) {
            return image;
        }
        dfs(image, sr, sc, originalColor, color);
        return image;
    }

    private void dfs(int[][] image,int row,int col,int originalColor,int newColor) {
        image[row][col] = newColor;

        // Up
        if (row > 0 && image[row - 1][col] == originalColor) {
            dfs(image,row - 1,col,originalColor,newColor);
        }

        // Down
        if (row + 1 < image.length && image[row + 1][col] == originalColor) {
            dfs(image,row + 1,col,originalColor,newColor);
        }

        // Left
        if (col > 0 && mage[row][col - 1] == originalColor) {
            dfs(image,row,col - 1,originalColor,newColor);
        }

        // Right
        if (col + 1 < image[0].length && image[row][col + 1] == originalColor) {
            dfs(image, row, col + 1, originalColor, newColor);
        }
    }
}
```

# ⭐ Easier Version Using Directions Array

The above code is beginner-friendly because every direction is written separately.

Once you understand it, we can make it shorter using:

```java
int[][] directions = {
    {-1, 0}, // up
    {1, 0},  // down
    {0, -1}, // left
    {0, 1}   // right
};
```

Then:

```java
class Solution {
    public int[][] floodFill( int[][] image, int sr, int sc, int color) {
        int originalColor = image[sr][sc];
        if (originalColor == color) {
            return image;
        }

        dfs(image, sr, sc, originalColor, color);
        return image;
    }

    private void dfs( int[][] image,int row,int col,int originalColor,int color) {
        image[row][col] = color;
        int[][] directions = {
            {-1, 0},  // up
            {1, 0},   // down
            {0, -1},  // left
            {0, 1}    // right
        };

        for (int[] direction : directions) {

            int newRow = row + direction[0];
            int newCol = col + direction[1];

            if (newRow >= 0 && newRow < image.length && newCol >= 0 && newCol < image[0].length && image[newRow][newCol] == originalColor) {

                dfs(image,newRow,newCol,originalColor,color);
            }
        }
    }
}
```

# 🔵 Step 8 — Continue Backtracking

DFS now returns to previous calls.

Remember:

```text
(2,0)
   ↑
(1,0)
   ↑
(0,0)
   ↑
(0,1)
   ↑
(1,1)
```

This is called **backtracking** in recursion.

We go back and check other neighbors that we haven't explored.

# 🔵 Step 11 — What About Bottom-Right `(2,2)`?

We have:

```text
2 2 1
2 2 0
2 0 1
```

The bottom-right pixel is:

```text
(2,2) = 1
```

It has the original color!

But it is **not directly connected** to our filled region.

Why?

Its neighbors are:

```text
(1,2) = 0
(2,1) = 0
```

Both are `0`.

The pixel:

```text
(2,2)
```

is only diagonally related to the filled `2`s.

Therefore it must remain `1`.
