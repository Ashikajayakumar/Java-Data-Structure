# **746. Min Cost Climbing Stairs**
![Uploading image.png…]()

## **1. Problem Statement**

You are given an integer array `cost`, where `cost[i]` represents the cost of stepping on the `i`th stair.

Once you pay the cost, you can climb either:

- 1 step
- 2 steps

You can start from either step `0` or step `1`.

Find the minimum cost to reach the top of the floor.

**Important:** Reaching the top does not require paying any additional cost because the top is beyond the last index of the array.

### **Example 1**

```
Input: cost = [10, 15, 20]

Output: 15
```

**Explanation:**

- Start at index 1.
- Pay cost = 15.
- Take 2 steps to reach the top.

Minimum cost = 15.

### **Example 2**

```
Input: cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]

Output: 6
```

**Explanation:**

One optimal path:

```
Index:  0 → 2 → 3 → 4 → 6 → 7 → 9 → Top

Cost:   1 + 1 + 1 + 1 + 1 + 1 = 6
```

## **2. Important Points**

1. We can start at index `0` or index `1`.
2. We can climb either 1 or 2 steps.
3. We need to minimize the total cost.
4. We don't need to pay for reaching the top.
5. This problem uses the **Minimum DP / Fibonacci-style pattern**.

## **3. Understanding the Logic**

Consider:

```
cost = [10, 15, 20]
```

Stair positions:

**Step 0**

# **10**

Cost

**Step 1**

# **15**

Cost

**Step 2**

# **20**

Cost

**Top**

# **0**

No cost

You can jump from step 0, 1 or 2 toward the top according to the 1-step or 2-step rule.

We have two choices to reach any stair `i`:

- Come from the previous stair `i-1`.
- Come from the second previous stair `i-2`.

We choose whichever path has the minimum cost.

Therefore:

\\[ dp[i] = cost[i] + \min(dp[i-1],dp[i-2]) \\]

**What does this mean?**

- `dp[i-1]` = Minimum cost to reach stair `i-1`.
- `dp[i-2]` = Minimum cost to reach stair `i-2`.
- `cost[i]` = Cost of stepping on the current stair.

## **4. Approach 1: Recursion**

**Main Logic**

For every stair, calculate the minimum cost of reaching it from either of the previous two stairs.

Base conditions:

```
if (i == 0) {
    return cost[0];
}

if (i == 1) {
    return cost[1];
}
```

Recurrence:

```
return cost[i] + Math.min(
    minCost(cost, i - 1),
    minCost(cost, i - 2)
);
```

**Java Code**

```
class Solution {

    public int minCostClimbingStairs(int[] cost) {

        int n = cost.length;

        return Math.min(
            minCost(cost, n - 1),
            minCost(cost, n - 2)
        );
    }

    public int minCost(int[] cost, int i) {

        if (i == 0) {
            return cost[0];
        }

        if (i == 1) {
            return cost[1];
        }

        return cost[i] + Math.min(
            minCost(cost, i - 1),
            minCost(cost, i - 2)
        );
    }
}
```

**Why do we return the minimum of the last two stairs?**

Because the top is at index `n`, and we can reach it from either:

- Index `n-1` using one step.
- Index `n-2` using two steps.

We don't pay any cost at the top.

**Complexity**

- Time: O(2ⁿ)
- Space: O(n) recursion stack.

This solution repeats calculations, so we can optimize it using DP.

## **5. Approach 2: Dynamic Programming – Tabulation**

We store the minimum cost calculated for each stair in a DP array.

**Main Logic**

1. Create `dp[n]`.
2. Initialize `dp[0] = cost[0]`.
3. Initialize `dp[1] = cost[1]`.
4. Calculate the minimum cost for every remaining stair.
5. Return the minimum of the last two DP values.

**Java Code**

```
class Solution {

    public int minCostClimbingStairs(int[] cost) {

        int n = cost.length;

        int[] dp = new int[n];

        dp[0] = cost[0];
        dp[1] = cost[1];

        for (int i = 2; i < n; i++) {

            dp[i] = cost[i] + Math.min(
                dp[i - 1],
                dp[i - 2]
            );
        }

        return Math.min(dp[n - 1], dp[n - 2]);
    }
}
```

### **Dry Run: Example 2**

```

```

Initially:

```
dp[0] = 1
dp[1] = 100
```

Now calculate the remaining values.

| i | cost[i] | dp[i-1] | dp[i-2] | Calculation    | dp[i] |
| - | ------- | ------- | ------- | -------------- | ----- |
| 2 | 1       | 100     | 1       | 1 + min(100,1) | 2     |
| 3 | 1       | 2       | 100     | 1 + min(2,100) | 3     |
| 4 | 1       | 3       | 2       | 1 + min(3,2)   | 3     |
| 5 | 100     | 3       | 3       | 100 + min(3,3) | 103   |
| 6 | 1       | 103     | 3       | 1 + min(103,3) | 4     |

| 8 | 100     | 5       | 4       | 100 + min(5,4) | 104   |
| 9 | 1       | 104     | 5       | 1 + min(104,5) | 6     |

**Complexity**

- Time: O(n)
- Space: O(n)

## **6. Approach 3: Space Optimization**

Do we need the entire DP array?

No.

To calculate the current minimum cost, we only need:

- Previous stair's minimum cost.
- Second previous stair's minimum cost.

So we can replace the DP array with two variables.

**Java Code – Optimized Solution**

```
class Solution {

    public int minCostClimbingStairs(int[] cost) {

        int n = cost.length;

        int prev2 = cost[0];
        int prev1 = cost[1];

        for (int i = 2; i < n; i++) {

            int curr = cost[i] + Math.min(prev1, prev2);

            prev2 = prev1;
            prev1 = curr;
        }

        return Math.min(prev1, prev2);
    }
}
```

### **Line-by-Line Explanation**

| Code                            | Explanation                               |
| ------------------------------- | ----------------------------------------- |
| `int n = cost.length`           | Find the number of stairs.                |
| `prev2 = cost[0]`               | Minimum cost to reach stair 0.            |
| `prev1 = cost[1]`               | Minimum cost to reach stair 1.            |
| `for (int i = 2; i < n; i++)`   | Calculate from stair 2 to the last stair. |
| `Math.min(prev1, prev2)`        | Choose the cheaper previous path.         |
| `cost[i] + ...`                 | Add the current stair's cost.             |
| `prev2 = prev1`                 | Move the previous state backward.         |
| `prev1 = curr`                  | Store the newly calculated minimum cost.  |
| `return Math.min(prev1, prev2)` | Choose the cheaper way to reach the top.  |

### **Dry Run: n = 5**

Consider:

```
cost = [10, 15, 20, 5, 10]
```

Initially:

```
prev2 = 10
prev1 = 15
```

| i | cost[i] | prev2 | prev1 | curr |
| - | ------- | ----- | ----- | ---- |
| 2 | 20      | 10    | 15    | 30   |
| 3 | 5       | 15    | 30    | 20   |
| 4 | 10      | 30    | 20    | 30   |

At the end:

```
prev2 = 20
prev1 = 30

Answer = min(20, 30)

       = 20
```

**Complexity**

- Time: O(n)
- Space: O(1)
