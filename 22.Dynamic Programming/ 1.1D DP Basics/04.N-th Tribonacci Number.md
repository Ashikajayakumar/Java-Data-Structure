## **1. Problem Statement**

The Tribonacci sequence is similar to the Fibonacci sequence.

In Fibonacci, each number is the sum of the previous **two** numbers.

In Tribonacci, each number is the sum of the previous **three** numbers.

The sequence is defined as:

\\[ T_0=0,\quad T_1=1,\quad T_2=1 \\]

For \\(n \geq 3\\):

\\[ \boxed{T_n=T\_{n-1}+T\_{n-2}+T\_{n-3}} \\]

Given an integer `n`, return the value of `Tn`.

### **Example 1**

```
Input: n = 4
Output: 4
```

Explanation:

```
T0 = 0
T1 = 1
T2 = 1
T3 = 0 + 1 + 1 = 2
T4 = 1 + 1 + 2 = 4
```

### **Example 2**

```
Input: n = 25
Output: 1389537
```

## **2. Important Points**

- Tribonacci starts with `0, 1, 1`.
- Every next number is the sum of the previous three numbers.
- We need to calculate the nth Tribonacci number.
- This problem follows the **3-variable DP pattern**.

## **3. Understanding the Logic**

Let's calculate the Tribonacci sequence.

T0

# **0**

T1

# **1**

T2

# **1**

T3

# **2**

T4

# **4**

T5

# **7**

T6

# **13**

T7

Tribonacci sequence: 0, 1, 1, 2, 4, 7, 13, 24

For example, to calculate `T4`:

```
T4 = T3 + T2 + T1

   = 2 + 1 + 1

   = 4
```

**Main Logic:**

To calculate the current value, we need three previous values.

\\[ dp[i]=dp[i-1]+dp[i-2]+dp[i-3] \\]

## **4. Approach 1: Recursion**

**Main Logic**

For every `n`, calculate:

- `tribonacci(n-1)`
- `tribonacci(n-2)`
- `tribonacci(n-3)`

Add all three results.

**Base Conditions**

```
if (n == 0) {
    return 0;
}

if (n == 1 || n == 2) {
    return 1;
}
```

**Java Code**

```
class Solution {
    public int tribonacci(int n) {

        if (n == 0) {
            return 0;
        }

        if (n == 1 || n == 2) {
            return 1;
        }

        return tribonacci(n - 1)
             + tribonacci(n - 2)
             + tribonacci(n - 3);
    }
}
```

### **Dry Run: n = 4**

```
tribonacci(4)
   |
   +---- tribonacci(3)
   |         |
   |         +---- T2 = 1
   |         +---- T1 = 1
   |         +---- T0 = 0
   |         Result = 2
   |
   +---- tribonacci(2) = 1
   |
   +---- tribonacci(1) = 1

Result = 2 + 1 + 1
       = 4
```

**Complexity**

- Time: Exponential, O(3ⁿ) upper bound.
- Space: O(n) recursion stack.

Recursion repeats calculations, so let's optimize it.

## **5. Approach 2: Dynamic Programming – Tabulation**

Instead of calculating the same subproblems repeatedly, store their results in a DP array.

**Main Logic**

1. Create an array `dp[n + 1]`.
2. Initialize `dp[0] = 0`.
3. Initialize `dp[1] = 1`.
4. Initialize `dp[2] = 1`.
5. Calculate remaining values using the previous three values.
6. Return `dp[n]`.

**Java Code**

```
class Solution {
    public int tribonacci(int n) {

        if (n == 0) {
            return 0;
        }

        if (n == 1 || n == 2) {
            return 1;
        }

        int[] dp = new int[n + 1];

        dp[0] = 0;
        dp[1] = 1;
        dp[2] = 1;

        for (int i = 3; i <= n; i++) {

            dp[i] = dp[i - 1]
                  + dp[i - 2]
                  + dp[i - 3];
        }

        return dp[n];
    }
}
```

### **Dry Run: n = 5**

Initially:

```
dp[0] = 0
dp[1] = 1
dp[2] = 1
```

Now calculate the remaining values.

| i | dp[i-1] | dp[i-2] | dp[i-3] | Calculation | dp[i] |
| - | ------- | ------- | ------- | ----------- | ----- |
| 3 | 1       | 1       | 0       | 1+1+0       | 2     |
| 4 | 2       | 1       | 1       | 2+1+1       | 4     |
| 5 | 4       | 2       | 1       | 4+2+1       | 7     |

Final DP array:

```
Index:  0  1  2  3  4  5
Value:  0  1  1  2  4  7
```

Output:

```
7
```

**Complexity**

- Time: O(n)
- Space: O(n)

## **6. Approach 3: Space Optimization**

Do we really need the entire DP array?

No.

To calculate the current Tribonacci number, we only need the previous three numbers.

So instead of using an array, we can maintain three variables.

**Main Logic**

We maintain:

- `prev3` → Third previous number.
- `prev2` → Second previous number.
- `prev1` → Previous number.

Calculate:

\\[ curr=prev1+prev2+prev3 \\]

Then update all three variables.

**Java Code – Optimized Solution**

```
class Solution {
    public int tribonacci(int n) {

        if (n == 0) {
            return 0;
        }

        if (n == 1 || n == 2) {
            return 1;
        }

        int prev3 = 0;
        int prev2 = 1;
        int prev1 = 1;

        for (int i = 3; i <= n; i++) {

            int curr = prev1 + prev2 + prev3;

            prev3 = prev2;
            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
}
```

### **Line-by-Line Explanation**

| Code                           | Explanation                              |
| ------------------------------ | ---------------------------------------- |
| `prev3 = 0`                    | Stores T0.                               |
| `prev2 = 1`                    | Stores T1.                               |
| `prev1 = 1`                    | Stores T2.                               |
| `curr = prev1 + prev2 + prev3` | Adds the previous three values.          |
| `prev3 = prev2`                | Moves the third previous value forward.  |
| `prev2 = prev1`                | Moves the second previous value forward. |
| `prev1 = curr`                 | Stores the newly calculated value.       |
| `return prev1`                 | Returns Tn.                              |

### **Dry Run: n = 5**

Initially:

```
prev3 = 0
prev2 = 1
prev1 = 1
```

| Iteration | prev3 | prev2 | prev1 | curr |
| --------- | ----- | ----- | ----- | ---- |
| i = 3     | 0     | 1     | 1     | 2    |
| i = 4     | 1     | 1     | 2     | 4    |
| i = 5     | 1     | 2     | 4     | 7    |

At the end:

```
prev1 = 7
```

Output: `7`

**Complexity**

- Time: O(n)
- Space: O(1)
