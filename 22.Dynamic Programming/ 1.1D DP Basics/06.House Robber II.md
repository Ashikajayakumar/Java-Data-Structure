# **213. House Robber II**


## **1. Problem Statement**

You are a professional robber planning to rob houses along a street.

Each house has a certain amount of money. You cannot rob two adjacent houses because the security system will alert the police.

This time, all houses are arranged in a **circle**.

The first house and the last house are also adjacent.

Given an integer array `nums`, return the maximum amount of money you can rob without alerting the police.

### **Example 1**

```
Input: nums = [2, 3, 2]
Output: 3
```

**Explanation:**

- Rob house 0 → collect 2.
- Skip house 1.
- Skip house 2 because house 0 and house 2 are adjacent.

Maximum money = 3 (rob house 1).

### **Example 2**

```
Input: nums = [1, 2, 3, 1]
Output: 4
```

**Explanation:**

One optimal choice:

- Rob house 0 → 1.
- Skip house 1.
- Rob house 2 → 3.
- Skip house 3.

Total = 1 + 3 = 4.

### **Example 3**

```
Input: nums = [1, 2, 3]
Output: 3
```

**Explanation:**

Rob house 1 or house 2.

Maximum money = 3.

## **2. Important Points**

- Houses are arranged in a circle.
- The first and last houses are adjacent.
- We cannot rob two adjacent houses.
- We need to maximize the total money.
- This problem is an extension of **House Robber I (LC 198)**.
- The main pattern is **Take or Skip DP**.

## **3. Understanding the Circular Arrangement**

In House Robber I, houses are arranged in a straight line.

In House Robber II, houses are arranged in a circle.

**House Robber I – Straight Line**

**2**

H0

**3**

H1

**2**

H2

**5**

H3

Only neighboring houses in the line are adjacent.



**The main problem:**

If we rob the first house, we cannot rob the last house.

If we rob the last house, we cannot rob the first house.

Therefore, we cannot directly apply House Robber I to the complete array.

## **4. Main Logic – Divide into Two Cases**

We solve the problem by considering two possible cases.

**Case 1: Exclude the last house**

Consider houses from index `0` to `n-2`.

```
nums[0] ........ nums[n-2]
```

We can rob the first house, but cannot rob the last house.

**Case 2: Exclude the first house**

Consider houses from index `1` to `n-1`.

```
       nums[1] ........ nums[n-1]
```

We can rob the last house, but cannot rob the first house.

Both cases are now straight-line House Robber I problems.

Finally:

\\[ \boxed{ Answer=\max(case1,case2) } \\]

Where:

\\[ case1=rob(0,n-2) \\]

\\[ case2=rob(1,n-1) \\]

## **5. Approach 1: Recursion**

We can reuse the Take or Skip logic from House Robber I.

For a given range:

- Take current house → `nums[i] + solve(i-2)`
- Skip current house → `solve(i-1)`
- Return the maximum.

### **Java Code**

```
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1) {
            return nums[0];
        }

        int case1 = solve(nums, 0, n - 2);

        int case2 = solve(nums, 1, n - 1);

        return Math.max(case1, case2);
    }

    public int solve(int[] nums, int i, int end) {

        if (i > end) {
            return 0;
        }

        int take = nums[i] + solve(nums, i + 2, end);

        int skip = solve(nums, i + 1, end);

        return Math.max(take, skip);
    }
}
```

**Explanation**

| Code                   | Explanation                          |
| ---------------------- | ------------------------------------ |
| `n == 1`               | Only one house exists, so rob it.    |
| `solve(nums, 0, n-2)`  | Exclude the last house.              |
| `solve(nums, 1, n-1)`  | Exclude the first house.             |
| `i > end`              | No houses left in the current range. |
| `nums[i] + solve(i+2)` | Rob current house and skip the next. |
| `solve(i+1)`           | Skip current house.                  |
| `Math.max(take, skip)` | Select maximum money.                |

**Complexity**

- Time: O(2ⁿ)
- Space: O(n) recursion stack.

## **6. Approach 2: Dynamic Programming – Memoization**

We can optimize recursion by storing previously calculated answers.

We use a DP array to avoid repeated calculations.

### **Java Code**

```
import java.util.Arrays;

class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1) {
            return nums[0];
        }

        int[] dp1 = new int[n];
        int[] dp2 = new int[n];

        Arrays.fill(dp1, -1);
        Arrays.fill(dp2, -1);

        int case1 = solve(nums, 0, n - 2, dp1);

        int case2 = solve(nums, 1, n - 1, dp2);

        return Math.max(case1, case2);
    }

    public int solve(int[] nums, int i, int end, int[] dp) {

        if (i > end) {
            return 0;
        }

        if (dp[i] != -1) {
            return dp[i];
        }

        int take = nums[i] + solve(nums, i + 2, end, dp);

        int skip = solve(nums, i + 1, end, dp);

        dp[i] = Math.max(take, skip);

        return dp[i];
    }
}
```

**Why two DP arrays?**

We have two different ranges:

- Case 1: `0` to `n-2`
- Case 2: `1` to `n-1`

We use separate DP arrays to keep the results of the two cases independent.

**Complexity**

- Time: O(n)
- Space: O(n) for DP arrays and recursion stack.

## **7. Approach 3: Dynamic Programming – Tabulation**

Instead of recursion, we use a loop to calculate the maximum money.

We apply House Robber I logic to both ranges.

### **Java Code**

```
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1) {
            return nums[0];
        }

        int case1 = solve(nums, 0, n - 2);

        int case2 = solve(nums, 1, n - 1);

        return Math.max(case1, case2);
    }

    public int solve(int[] nums, int start, int end) {

        int[] dp = new int[nums.length];

        dp[start] = nums[start];

        if (start + 1 <= end) {
            dp[start + 1] = Math.max(nums[start], nums[start + 1]);
        }

        for (int i = start + 2; i <= end; i++) {

            int take = nums[i] + dp[i - 2];

            int skip = dp[i - 1];

            dp[i] = Math.max(take, skip);
        }

        return dp[end];
    }
}
```

### **Dry Run: Example 1**

```
nums = [2, 3, 2]
```

**Case 1: Exclude last house**

```
Range = [2, 3]

Index:  0  1
Money:  2  3
```

| i | Take | Skip | dp[i] |
| - | ---- | ---- | ----- |
| 0 | 2    | 0    | 2     |
| 1 | 3    | 2    | 3     |

Result = 3.

**Case 2: Exclude first house**

```
Range = [3, 2]

Index:  1  2
Money:  3  2
```

| i | Take | Skip | dp[i] |
| - | ---- | ---- | ----- |
| 1 | 3    | 0    | 3     |
| 2 | 2    | 3    | 3     |

Result = 3.

**Final Answer**

```
case1 = 3
case2 = 3

Answer = max(3, 3)

       = 3
```

Output: 3

**Complexity**

- Time: O(n)
- Space: O(n)

## **8. Approach 4: Space Optimization**

We don't need the complete DP array.

Remember House Robber I:

```
int prev2 = 0;
int prev1 = 0;

for (int i = start; i <= end; i++) {

    int take = nums[i] + prev2;

    int skip = prev1;

    int curr = Math.max(take, skip);

    prev2 = prev1;
    prev1 = curr;
}
```

We only need two previous states.

### **Java Code – Optimized Solution**

```
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1) {
            return nums[0];
        }

        int case1 = solve(nums, 0, n - 2);

        int case2 = solve(nums, 1, n - 1);

        return Math.max(case1, case2);
    }

    public int solve(int[] nums, int start, int end) {

        int prev2 = 0;
        int prev1 = 0;

        for (int i = start; i <= end; i++) {

            int take = nums[i] + prev2;

            int skip = prev1;

            int curr = Math.max(take, skip);

            prev2 = prev1;

            prev1 = curr;
        }

        return prev1;
    }
}
```

## **9. Line-by-Line Explanation of Optimized Solution**

| Code                       | Explanation                                  |
| -------------------------- | -------------------------------------------- |
| `n = nums.length`          | Find the number of houses.                   |
| `n == 1`                   | Handle the single-house case.                |
| `solve(nums, 0, n-2)`      | Calculate maximum money without last house.  |
| `solve(nums, 1, n-1)`      | Calculate maximum money without first house. |
| `prev2 = 0`                | Maximum money before the previous house.     |
| `prev1 = 0`                | Maximum money up to the previous house.      |
| `take = nums[i] + prev2`   | Rob current house.                           |
| `skip = prev1`             | Skip current house.                          |
| `curr = max(take, skip)`   | Choose the maximum.                          |
| `prev2 = prev1`            | Update second previous state.                |
| `prev1 = curr`             | Update previous state.                       |
| `return max(case1, case2)` | Choose the better circular-house scenario.   |
