## **1. Problem Statement**

You are given an array `arr[]` where each element represents the amount of money present in a house.

A thief wants to steal the maximum amount of money, but there is one restriction:

- The thief cannot rob two adjacent houses.
- Find the maximum amount of money that can be stolen.

### **Example 1**

```
Input: arr[] = [5, 5, 10, 100, 10, 5]

Output: 110
```

**Explanation:**

Choose houses with money `5`, `100`, and `5`.

Total = 5 + 100 + 5 = 110.

### **Example 2**

```
Input: arr[] = [2, 1, 1, 2]

Output: 4
```

**Explanation:**

Choose the first and last houses.

Total = 2 + 2 = 4.

## **2. Important Point**

At every house, we have two choices:

1. **Take:** Rob the current house and skip the previous house.
2. **Skip:** Do not rob the current house and use the previous maximum.

**DP Recurrence:**

\\[ dp[i]=\max(arr[i]+dp[i-2],dp[i-1]) \\]

## **3. Approach 1 – Recursion**

```
class Solution {
    int findMaxSum(int arr[]) {
        return solve(arr, arr.length - 1);
    }

    int solve(int arr[], int i) {

        if (i < 0) {
            return 0;
        }

        int take = arr[i] + solve(arr, i - 2);

        int skip = solve(arr, i - 1);

        return Math.max(take, skip);
    }
}
```

**Complexity:**

- Time: O(2ⁿ)
- Auxiliary space: O(n) recursion stack.

## **4. Approach 2 – Memoization (Top-Down DP)**

```
import java.util.Arrays;

class Solution {
    int findMaxSum(int arr[]) {

        int n = arr.length;

        int dp[] = new int[n];
        Arrays.fill(dp, -1);

        return solve(arr, n - 1, dp);
    }

    int solve(int arr[], int i, int dp[]) {

        if (i < 0) {
            return 0;
        }

        if (dp[i] != -1) {
            return dp[i];
        }

        int take = arr[i] + solve(arr, i - 2, dp);

        int skip = solve(arr, i - 1, dp);

        dp[i] = Math.max(take, skip);

        return dp[i];
    }
}
```

**Important:** `dp[i]` stores the maximum money that can be stolen from houses `0` to `i`.

**Complexity:**

- Time: O(n)
- Auxiliary space: O(n) DP array + O(n) recursion stack.

## **5. Approach 3 – Tabulation (Bottom-Up DP)**

**Step 1: Initialize**

```
dp[0] = arr[0];

dp[1] = Math.max(arr[0], arr[1]);
```

**Step 2: Apply recurrence**

```
dp[i] = Math.max(arr[i] + dp[i - 2], dp[i - 1]);
```

**Java Code:**

```
class Solution {
    int findMaxSum(int arr[]) {

        int n = arr.length;

        if (n == 1) {
            return arr[0];
        }

        int dp[] = new int[n];

        dp[0] = arr[0];

        dp[1] = Math.max(arr[0], arr[1]);

        for (int i = 2; i < n; i++) {

            int take = arr[i] + dp[i - 2];

            int skip = dp[i - 1];

            dp[i] = Math.max(take, skip);
        }

        return dp[n - 1];
    }
}
```

### **Dry Run**

Input:

```
arr = [5, 5, 10, 100, 10, 5]
```

| i | arr[i] | Take          | Skip | dp[i] |
| - | ------ | ------------- | ---- | ----- |
| 0 | 5      | —             | —    | 5     |
| 1 | 5      | —             | —    | 5     |
| 2 | 10     | 10 + 5 = 15   | 5    | 15    |
| 3 | 100    | 100 + 5 = 105 | 15   | 105   |
| 4 | 10     | 10 + 15 = 25  | 105  | 105   |
| 5 | 5      | 5 + 105 = 110 | 105  | 110   |

Final DP array:

```
dp = [5, 5, 15, 105, 105, 110]
```

**Output: 110**

**Complexity:**

- Time: O(n)
- Auxiliary space: O(n).

## **6. Approach 4 – Space Optimization**

We only need the previous two DP values.

- `prev2` represents `dp[i-2]`.
- `prev1` represents `dp[i-1]`.
- `curr` represents `dp[i]`.

### **Java Code**

```
class Solution {
    int findMaxSum(int arr[]) {

        int prev2 = 0;
        int prev1 = 0;

        for (int i = 0; i < arr.length; i++) {

            int take = arr[i] + prev2;

            int skip = prev1;

            int curr = Math.max(take, skip);

            prev2 = prev1;

            prev1 = curr;
        }

        return prev1;
    }
}
```

**Complexity:**

- Time: O(n)
- Auxiliary space: O(1).
