## **1. Problem Statement**

The Fibonacci sequence is a sequence where each number is the sum of the two preceding numbers.

The sequence starts with:

``F(0)=0, F(1)=1``

For \\(n > 1\\):
``F(n)=F(n-1) +F(n-2)``

Given an integer `n`, return the `n`th Fibonacci number.

### **Example 1**

```
Input: n = 2
Output: 1

Explanation:
F(2) = F(1) + F(0)
     = 1 + 0
     = 1
```

### **Example 2**

```
Input: n = 3
Output: 2

Explanation:
F(3) = F(2) + F(1)
     = 1 + 1
     = 2
```

### **Example 3**

```
Input: n = 4
Output: 3

Explanation:
F(4) = F(3) + F(2)
     = 2 + 1
     = 3
```

## **2. Important Points**

- Fibonacci starts with `0` and `1`.
- Every next number is the sum of the previous two numbers.
- We can solve this problem using recursion or Dynamic Programming.
- DP avoids recalculating the same subproblems.

## **4. Approach 1: Recursion**

**Main Logic**

For every number, calculate:

- Previous number: `fib(n-1)`
- Second previous number: `fib(n-2)`
- Add both results.

**Java Code**

```
class Solution {
    public int fib(int n) {

        if (n <= 1) {
            return n;
        }

        return fib(n - 1) + fib(n - 2);
    }
}
```

### **Dry Run: n = 4**

```
fib(4)
  |
  +-- fib(3)
  |     |
  |     +-- fib(2) = 1
  |     +-- fib(1) = 1
  |     Result = 2
  |
  +-- fib(2) = 1

fib(4) = 2 + 1 = 3
```

**Complexity**

- Time: \\(O(2^n)\\)
- Space: \\(O(n)\\) recursion stack.

## **5. Approach 2: Dynamic Programming – Tabulation**

Instead of repeatedly calculating Fibonacci numbers, store previously calculated answers in an array.

**Main Logic**

1. Create an array `dp`.
2. Set `dp[0] = 0`.
3. Set `dp[1] = 1`.
4. Calculate each next value using the previous two values.
5. Return `dp[n]`.

**Java Code**

```
class Solution {
    public int fib(int n) {

        if (n <= 1) {
            return n;
        }

        int[] dp = new int[n + 1];

        dp[0] = 0;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {

            dp[i] = dp[i - 1] + dp[i - 2];

        }

        return dp[n];
    }
}
```

### **Dry Run: n = 5**

Initially:

```
dp[0] = 0
dp[1] = 1
```

| Iteration | Calculation   | dp[i] |
| --------- | ------------- | ----- |
| i = 2     | dp[1] + dp[0] | 1     |
| i = 3     | dp[2] + dp[1] | 2     |
| i = 4     | dp[3] + dp[2] | 3     |
| i = 5     | dp[4] + dp[3] | 5     |

Final DP array:

```
Index:  0  1  2  3  4  5
Value:  0  1  1  2  3  5
```

Output:

```
5
```

**Complexity**

- Time: \\(O(n)\\)
- Space: \\(O(n)\\)

## **6. Approach 3: Space Optimization**

We don't actually need the entire DP array.

To calculate the next Fibonacci number, we only need the previous two numbers.

**Java Code – Optimized Solution**

```
class Solution {
    public int fib(int n) {

        if (n <= 1) {
            return n;
        }

        int prev2 = 0;
        int prev1 = 1;

        for (int i = 2; i <= n; i++) {

            int curr = prev1 + prev2;

            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
}
```

### **Dry Run: n = 5**

Initially:

```
prev2 = 0
prev1 = 1
```

| i | prev2 | prev1 | curr = prev1 + prev2 |
| - | ----- | ----- | -------------------- |
| 2 | 0     | 1     | 1                    |
| 3 | 1     | 1     | 2                    |
| 4 | 1     | 2     | 3                    |
| 5 | 2     | 3     | 5                    |

At the end:

```
prev1 = 5
```

Output: `5`

**Complexity**

- Time: \\(O(n)\\)
- Space: \\(O(1)\\)
