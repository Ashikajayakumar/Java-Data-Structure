## **1. Problem Statement**

You are climbing a staircase. It takes `n` steps to reach the top.

Each time, you can climb either:

- 1 step
- 2 steps

Find the number of distinct ways to reach the top.

### **Example 1**

```
Input: n = 2
Output: 2
```

**Explanation:**

There are two ways to reach the top:

```
1. 1 step + 1 step
2. 2 steps
```

### **Example 2**

```
Input: n = 3
Output: 3
```

**Explanation:**

There are three ways to reach the top:

```
1. 1 + 1 + 1
2. 1 + 2
3. 2 + 1
```

## **2. Important Points**

- You can take either 1 step or 2 steps.
- The order of steps matters.
- We need to count all possible ways, not find the minimum number of steps.
- This problem follows the Fibonacci pattern.

## **3. Understanding the Logic**

Suppose `n = 4`.

We need to reach step 4.

There are only two possible ways to reach step 4:

**Case 1:** Come from step 3 by taking 1 step.

**Case 2:** Come from step 2 by taking 2 steps.

Therefore:

\\[ dp[n] = dp[n-1] + dp[n-2] \\]

Why?

- `dp[n-1]` = Number of ways to reach the previous step.
- `dp[n-2]` = Number of ways to reach the second previous step.

Add both possibilities.

## **4. Fibonacci Pattern**

Let's calculate the number of ways for each staircase.

| Steps (n) | Number of ways |
| --------- | -------------- |
| 1         | 1              |
| 2         | 2              |
| 3         | 3              |
| 4         | 5              |
| 5         | 8              |
| 6         | 13             |
| 7         | 21             |

Notice the pattern:

```
1, 2, 3, 5, 8, 13, 21
```

Every number is the sum of the previous two numbers.

This is similar to Fibonacci:

```
Fibonacci:       0, 1, 1, 2, 3, 5, 8, 13
Climbing Stairs: 1, 2, 3, 5, 8, 13, 21
```

The difference is the starting values.

## **5. Approach 1: Recursion**

**Main Logic**

To reach step `n`, we can:

1. Come from `n-1` by taking 1 step.
2. Come from `n-2` by taking 2 steps.

So:

\\[ climbStairs(n)=climbStairs(n-1)+climbStairs(n-2) \\]

**Base Conditions:**

```
if (n == 1) {
    return 1;
}

if (n == 2) {
    return 2;
}
```

**Java Code**

```
class Solution {
    public int climbStairs(int n) {

        if (n == 1) {
            return 1;
        }

        if (n == 2) {
            return 2;
        }

        return climbStairs(n - 1) + climbStairs(n - 2);
    }
}
```

### **Dry Run: n = 4**

```
climbStairs(4)
       |
       +----------------+
       |                |
 climbStairs(3)    climbStairs(2)
       |                |
       |                2
   +---+---+
   |       |
 climb(2) climb(1)
   |       |
   2       1

Result = 2 + 1 + 2
       = 5
```

**Complexity**

- Time: O(2ⁿ)
- Space: O(n) recursion stack.

This approach repeats calculations, so it is not optimal.

## **6. Approach 2: Dynamic Programming – Tabulation**

Instead of calculating the same subproblems repeatedly, store their answers in a DP array.

**Main Logic**

1. Create `dp[n + 1]`.
2. Initialize `dp[1] = 1`.
3. Initialize `dp[2] = 2`.
4. Calculate the remaining values using the previous two values.
5. Return `dp[n]`.

**Java Code**

```
class Solution {
    public int climbStairs(int n) {

        if (n <= 2) {
            return n;
        }

        int[] dp = new int[n + 1];

        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {

            dp[i] = dp[i - 1] + dp[i - 2];

        }

        return dp[n];
    }
}
```

### **Dry Run: n = 5**

Initially:

```
dp[1] = 1
dp[2] = 2
```

Iteration table:

| i | dp[i-1] | dp[i-2] | dp[i] |
| - | ------- | ------- | ----- |
| 3 | 2       | 1       | 3     |
| 4 | 3       | 2       | 5     |
| 5 | 5       | 3       | 8     |

Final DP array:

```
Index:  0  1  2  3  4  5
Value:  0  1  2  3  5  8
```

Output:

```
8
```

**Complexity**

- Time: O(n)
- Space: O(n)

## **7. Approach 3: Space Optimization**

Do we really need the entire DP array?

No.

To calculate the current answer, we only need:

- Previous step: `prev1`
- Second previous step: `prev2`

Therefore, we can use two variables instead of an array.

**Java Code – Optimized Solution**

```
class Solution {
    public int climbStairs(int n) {

        if (n <= 2) {
            return n;
        }

        int prev2 = 1;
        int prev1 = 2;

        for (int i = 3; i <= n; i++) {

            int curr = prev1 + prev2;

            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
}
```

### **Line-by-Line Explanation**

| Code                           | Explanation                        |
| ------------------------------ | ---------------------------------- |
| `if (n <= 2)`                  | Handles the first two staircases.  |
| `prev2 = 1`                    | Ways to reach step 1.              |
| `prev1 = 2`                    | Ways to reach step 2.              |
| `for (int i = 3; i <= n; i++)` | Calculate from step 3 to n.        |
| `curr = prev1 + prev2`         | Add the previous two answers.      |
| `prev2 = prev1`                | Move the previous value backward.  |
| `prev1 = curr`                 | Store the newly calculated answer. |
| `return prev1`                 | Return the answer for step n.      |

### **Dry Run: n = 5**

Initial values:

```
prev2 = 1
prev1 = 2
```

| Iteration | prev2 | prev1 | curr |
| --------- | ----- | ----- | ---- |
| i = 3     | 1     | 2     | 3    |
| i = 4     | 2     | 3     | 5    |
| i = 5     | 3     | 5     | 8    |

At the end:

```
prev1 = 8
```

Output: `8`

**Complexity**

- Time: O(n)
- Space: O(1)
