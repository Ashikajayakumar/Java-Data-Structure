## **1. Problem Statement**

You are a professional robber planning to rob houses along a street.

Each house has a certain amount of money. You cannot rob two adjacent houses because the security system will automatically alert the police if two neighboring houses are robbed on the same night.

Given an integer array `nums`, representing the amount of money in each house, return the maximum amount of money you can rob without alerting the police.

### **Example 1**

```
Input: nums = [1, 2, 3, 1]
Output: 4
```

**Explanation:**

- Rob house 0 → collect 1.
- Skip house 1 → collect 0.
- Rob house 2 → collect 3.
- Skip house 3.

Total = 1 + 3 = 4.

### **Example 2**

```
Input: nums = [2, 7, 9, 3, 1]
Output: 12
```

**Explanation:**

- Rob house 0 → 2.
- Skip house 1.
- Rob house 2 → 9.
- Skip house 3.
- Rob house 4 → 1.

Total = 2 + 9 + 1 = 12.

## **2. Important Points**

- We cannot rob two adjacent houses.
- We can either rob the current house or skip it.
- Our objective is to maximize the total money.
- We need to make the best decision at every house.
- This problem follows the **Take or Skip DP pattern**.

## **1**

# **2 + 9 + 1 = 12**

At every house, we have two choices.

**Choice 1: Take the current house**

If we rob the current house, we cannot rob the previous house.

So:

\\[ Take = nums[i] + dp[i-2] \\]

**Choice 2: Skip the current house**

If we skip the current house, we keep the maximum money collected up to the previous house.

\\[ Skip = dp[i-1] \\]

**Choose the maximum:**

\\[ \boxed{dp[i]=\max(nums[i]+dp[i-2],dp[i-1])} \\]

This is the main formula of House Robber.

## **4. Approach 1: Recursion**

**Main Logic**

At every house, we have two choices:

1. Rob the current house and move to `i-2`.
2. Skip the current house and move to `i-1`.

Return whichever choice gives more money.

### **Java Code**

```
class Solution {
    public int rob(int[] nums) {
        return solve(nums, nums.length - 1);
    }

    public int solve(int[] nums, int i) {

        if (i < 0) {
            return 0;
        }

        // Take current house
        int take = nums[i] + solve(nums, i - 2);

        // Skip current house
        int skip = solve(nums, i - 1);

        return Math.max(take, skip);
    }
}
```

### **Line-by-Line Explanation**

| Code                           | Explanation                                     |
| ------------------------------ | ----------------------------------------------- |
| `solve(nums, nums.length - 1)` | Start from the last house.                      |
| `if (i < 0)`                   | No houses left, return 0.                       |
| `nums[i] + solve(nums, i-2)`   | Rob current house and skip adjacent house.      |
| `solve(nums, i-1)`             | Skip current house and consider previous house. |
| `Math.max(take, skip)`         | Select the option giving maximum money.         |

### **Dry Run:&#x20;**`nums = [2, 7, 9, 3, 1]`

We start from index 4.

```
                         solve(4)
                       /          \
                  TAKE              SKIP
               1 + solve(2)       solve(3)
```

At each recursive call, the same smaller problems can be calculated repeatedly.

For example, `solve(2)` can be reached through multiple branches.

**Complexity**

- Time: O(2ⁿ)
- Space: O(n) recursion stack.

This approach is correct but inefficient because of repeated calculations.

## **5. Approach 2: Dynamic Programming – Memoization**

Memoization means storing the results of previously solved subproblems.

Instead of calculating the same state repeatedly, we save its answer in an array.

**Main Logic**

1. Create a `dp` array.
2. Initialize all values with `-1`.
3. Before calculating a state, check whether its answer is already stored.
4. If stored, return it.
5. Otherwise calculate Take and Skip.
6. Store the maximum result.

### **Java Code**

```
import java.util.Arrays;

class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        int[] dp = new int[n];

        Arrays.fill(dp, -1);

        return solve(nums, n - 1, dp);
    }

    public int solve(int[] nums, int i, int[] dp) {

        if (i < 0) {
            return 0;
        }

        if (dp[i] != -1) {
            return dp[i];
        }

        int take = nums[i] + solve(nums, i - 2, dp);

        int skip = solve(nums, i - 1, dp);

        dp[i] = Math.max(take, skip);

        return dp[i];
    }
}
```

**Complexity**

- Time: O(n)
- Space: O(n) for the DP array and recursion stack.

## **6. Approach 3: Dynamic Programming – Tabulation**

In tabulation, we solve the smaller subproblems first and store their answers in an array.

Instead of recursion, we use a loop.

### **Main Logic**

1. Create a DP array.
2. Initialize the first house.
3. Calculate the maximum money for the second house.
4. Start iterating from index 2.
5. At every house, calculate Take and Skip.
6. Store the maximum result.
7. Return `dp[n-1]`.

### **Java Code**

```
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1) {
            return nums[0];
        }

        int[] dp = new int[n];

        dp[0] = nums[0];

        dp[1] = Math.max(nums[0], nums[1]);

        for (int i = 2; i < n; i++) {

            int take = nums[i] + dp[i - 2];

            int skip = dp[i - 1];

            dp[i] = Math.max(take, skip);
        }

        return dp[n - 1];
    }
}
```

### **Dry Run:&#x20;**`nums = [2, 7, 9, 3, 1]`

**Step 1: Initialization**

```
nums = [2, 7, 9, 3, 1]

dp[0] = nums[0] = 2

dp[1] = max(nums[0], nums[1])
      = max(2, 7)
      = 7
```

Initial DP array:

```
Index:  0  1  2  3  4
nums:   2  7  9  3  1
dp:     2  7  _  _  _
```

**Step 2: Iteration**

For `i = 2`:

```
take = nums[2] + dp[0]
     = 9 + 2
     = 11

skip = dp[1]
     = 7

dp[2] = max(11, 7) = 11
```

For `i = 3`:

```
take = nums[3] + dp[1]
     = 3 + 7
     = 10

skip = dp[2]
     = 11

dp[3] = max(10, 11) = 11
```

For `i = 4`:

```
take = nums[4] + dp[2]
     = 1 + 11
     = 12

skip = dp[3]
     = 11

dp[4] = max(12, 11) = 12
```

### **Iteration Table**

| i | nums[i] | Take | Skip | dp[i] |
| - | ------- | ---- | ---- | ----- |
| 0 | 2       | —    | —    | 2     |
| 1 | 7       | —    | —    | 7     |
| 2 | 9       | 11   | 7    | 11    |
| 3 | 3       | 10   | 11   | 11    |
| 4 | 1       | 12   | 11   | 12    |

Final DP array:

```
Index:  0   1   2   3   4
nums:   2   7   9   3   1
dp:     2   7  11  11  12
```

Output: 12

**Complexity**

- Time: O(n)
- Space: O(n)

## **7. Approach 4: Space Optimization**

Do we really need the entire DP array?

No.

To calculate the current result, we only need:

- `prev1` → Maximum money up to the previous house.
- `prev2` → Maximum money up to the second previous house.

Our formula is:

\\[ curr=\max(nums[i]+prev2,prev1) \\]

After calculating:

```
prev2 = prev1
prev1 = curr
```

### **Java Code – Optimized Solution**

```
class Solution {

    public int rob(int[] nums) {

        int prev2 = 0;
        int prev1 = 0;

        for (int i = 0; i < nums.length; i++) {

            int take = nums[i] + prev2;

            int skip = prev1;

            int curr = Math.max(take, skip);

            prev2 = prev1;

            prev1 = curr;
        }

        return prev1;
    }
}
```

### **Line-by-Line Explanation**

| Code                          | Explanation                              |
| ----------------------------- | ---------------------------------------- |
| `prev2 = 0`                   | Maximum money before the previous house. |
| `prev1 = 0`                   | Maximum money up to the previous house.  |
| `for` loop                    | Visit every house.                       |
| `take = nums[i] + prev2`      | Rob current house.                       |
| `skip = prev1`                | Skip current house.                      |
| `curr = Math.max(take, skip)` | Select maximum money.                    |
| `prev2 = prev1`               | Shift previous state backward.           |
| `prev1 = curr`                | Store current maximum.                   |
| `return prev1`                | Return maximum money.                    |

### **Dry Run:&#x20;**`nums = [2, 7, 9, 3, 1]`

Initially:

```
prev2 = 0
prev1 = 0
```

| i | nums[i] | prev2 | prev1 | Take | Skip | curr |
| - | ------- | ----- | ----- | ---- | ---- | ---- |
| 0 | 2       | 0     | 0     | 2    | 0    | 2    |
| 1 | 7       | 0     | 2     | 7    | 2    | 7    |
| 2 | 9       | 2     | 7     | 11   | 7    | 11   |
| 3 | 3       | 7     | 11    | 10   | 11   | 11   |
| 4 | 1       | 11    | 11    | 12   | 11   | 12   |

Final values:

```

prev1 = 12
```

Output:

```

```



Recommended

&#x20;Approach 4 – Space Optimization.



**Complexity**

- Time: O(n)
- Space: O(1)
