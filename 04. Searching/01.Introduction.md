### 04.1 Introduction to Searching

**Searching** is the process of finding a particular element, called the **target**, in a collection of data such as an array.

Example:

```text
Array  = [10, 25, 30, 45, 50]
Target = 30
```

The goal is to determine:

* Whether the target exists
* The index/position of the target if it exists

### Types of Searching

There are two basic searching techniques you should know for beginner-level interviews:

```text
Searching
│
├── 1. Linear Search
│
└── 2. Binary Search
```

---

# 1. Linear Search

### Concept

Linear Search checks each element **one by one from left to right** until the target is found.

Example:

```text
Array:  [10, 25, 30, 45, 50]
Target: 45

10 → 25 → 30 → 45 ✓
```

### Important Points

* Works on **sorted or unsorted** arrays.
* Starts from the first element.
* Checks every element until the target is found.
* Very easy to implement.
* Worst-case time complexity: **O(n)**
* Best-case time complexity: **O(1)**
* Space complexity: **O(1)**

### Java

```java
public class LinearSearch {

    static int linearSearch(int[] arr, int target) {

        for (int i = 0; i < arr.length; i++) {

            if (arr[i] == target) {
                return i;
            }
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {10, 25, 30, 45, 50};
        int target = 45;

        int result = linearSearch(arr, target);

        System.out.println("Index: " + result);
    }
}
```

Output:

```text
Index: 3
```

# 2. Binary Search

### Concept

Binary Search is a faster searching technique that repeatedly divides the search space into **two halves**.

**Important:** Binary Search requires the array to be **sorted**.

Example:

```text
Array:  [10, 20, 30, 40, 50, 60, 70]
Target: 60
```

Instead of checking every element:

```text
Middle = 40

60 > 40
→ Search right half

[50, 60, 70]

Middle = 60
→ Found
```

### Important Points

* Array must be **sorted**.
* Divides the search space into two halves.
* Much faster than Linear Search for large sorted arrays.
* Best-case time complexity: **O(1)**
* Worst-case time complexity: **O(log n)**
* Space complexity for iterative implementation: **O(1)**

### Java

```java
public class BinarySearch {

    static int binarySearch(int[] arr, int target) {

        int left = 0;
        int right = arr.length - 1;

        while (left <= right) {

            int mid = left + (right - left) / 2;

            if (arr[mid] == target) {
                return mid;
            }
            else if (arr[mid] < target) {
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {10, 20, 30, 40, 50, 60, 70};
        int target = 60;

        int result = binarySearch(arr, target);

        System.out.println("Index: " + result);
    }
}
```

Output:

```text
Index: 5
```
