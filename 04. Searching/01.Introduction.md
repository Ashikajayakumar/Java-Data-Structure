
## 01. Introduction to Searching

### What is Searching?

**Searching** is the process of finding a particular element (called a **target element**) in a collection of data such as an array, list, or other data structure.

For example:

```text
Array = [10, 25, 30, 45, 50]

Target = 30
```

Searching means finding whether `30` exists in the array and, if it exists, finding its **position/index**.

### Why is Searching important?

Searching is one of the most fundamental DSA concepts because:

* It is frequently asked in coding interviews.
* It teaches how to efficiently find data.
* It introduces **time complexity**.
* Binary Search forms the foundation for many advanced problems.
* Searching techniques are used inside many real-world applications.

## 1. Linear Search

### What is Linear Search?

**Linear Search** checks each element one by one from the beginning until the target element is found or the entire array is searched.

Example:

```text
Array:  [10, 25, 30, 45, 50]
Target: 45

Step 1 → 10 ❌
Step 2 → 25 ❌
Step 3 → 30 ❌
Step 4 → 45 ✅ Found
```

### Important points

* Works on **sorted or unsorted** arrays.
* Simple and easy to implement.
* Checks elements sequentially.
* No special condition is required.

### Time Complexity

| Case         | Complexity |
| ------------ | ---------- |
| Best Case    | O(1)       |
| Average Case | O(n)       |
| Worst Case   | O(n)       |
| Space        | O(1)       |

### Java Implementation

```java
class LinearSearch {

    static int linearSearch(int[] arr, int target) {

        for (int i = 0; i < arr.length; i++) {

            if (arr[i] == target) {
                return i;
            }
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {10, 25, 30, 45, 50};
        int target = 45;

        int result = linearSearch(arr, target);

        if (result != -1) {
            System.out.println("Element found at index: " + result);
        } else {
            System.out.println("Element not found");
        }
    }
}
```

# 2. Binary Search

### What is Binary Search?

**Binary Search** is an efficient searching algorithm that repeatedly divides the search space into two halves.

⚠️ **Important:** Binary Search requires the array to be **sorted**.

Example:

```text
Array:  [10, 20, 30, 40, 50, 60, 70]
Target: 60
```

Start:

```text
low = 0
high = 6

mid = (low + high) / 2
    = 3

arr[mid] = 40
```

Since:

```text
60 > 40
```

Search only the right half:

```text
[50, 60, 70]
```

Then continue dividing until the target is found.

### Important points

* Array must be **sorted**.
* Eliminates half of the search space in every step.
* Much faster than Linear Search for large sorted arrays.
* Very important for coding interviews.

### Time Complexity

| Case              | Complexity |
| ----------------- | ---------- |
| Best Case         | O(1)       |
| Average Case      | O(log n)   |
| Worst Case        | O(log n)   |
| Space — Iterative | O(1)       |

### Java Implementation

```java
class BinarySearch {

    static int binarySearch(int[] arr, int target) {

        int low = 0;
        int high = arr.length - 1;

        while (low <= high) {

            int mid = low + (high - low) / 2;

            if (arr[mid] == target) {
                return mid;
            }

            if (arr[mid] < target) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {10, 20, 30, 40, 50, 60, 70};
        int target = 60;

        int result = binarySearch(arr, target);

        if (result != -1) {
            System.out.println("Element found at index: " + result);
        } else {
            System.out.println("Element not found");
        }
    }
}
```
