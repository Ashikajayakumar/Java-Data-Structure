## **1. Problem Statement**

You are running a lemonade stand where each lemonade costs **$5**.

Customers stand in a queue and pay one at a time. Each customer pays using one of these bills:

- $5
- $10
- $20

You must provide the correct change so that every customer effectively pays exactly $5.

Initially, you have no money in your cash box.

Given an integer array `bills`, return:

- `true` if you can provide correct change to every customer.
- `false` if you cannot provide change to any customer.

**Important:** Customers must be served in the given order. You cannot rearrange the queue.

### **Example 1**

```
Input:
bills = [5, 5, 5, 10, 20]

Output:
true
```

Explanation:

| Customer | Payment | Change given | Remaining $5 | Remaining $10 |
| -------- | ------- | ------------ | ------------ | ------------- |
| 1        | $5      | $0           | 1            | 0             |
| 2        | $5      | $0           | 2            | 0             |
| 3        | $5      | $0           | 3            | 0             |
| 4        | $10     | $5           | 2            | 1             |
| 5        | $20     | $10 + $5     | 1            | 0             |

Every customer receives the correct change.

### **Example 2**

```
Input:
bills = [5, 5, 10, 10, 20]

Output:
false
```

Explanation:

| Customer | Payment | Change given    | Remaining $5 | Remaining $10 |
| -------- | ------- | --------------- | ------------ | ------------- |
| 1        | $5      | $0              | 1            | 0             |
| 2        | $5      | $0              | 2            | 0             |
| 3        | $10     | $5              | 1            | 1             |
| 4        | $10     | $5              | 0            | 2             |
| 5        | $20     | Cannot give $15 | 0            | 2             |

The last customer needs $15 change, but we only have two $10 bills.

Therefore, return `false`.

## **2. Important Points**

1. Lemonade costs $5.
2. Initially, we have zero $5 and zero $10 bills.
3. A customer paying $5 does not need change.
4. A customer paying $10 needs one $5 bill as change.
5. A customer paying $20 needs $15 change.
6. We only need to track the number of $5 and $10 bills.

**Why don't we track $20 bills?**

We never use a $20 bill to provide change because the required change is either $5 or $15.

## **3. Main Concept — Greedy Algorithm**

We use a greedy approach to decide which bills to give as change.

There are three possible customer payments.

**Case 1: Customer pays $5**

# **$5**

**No change**

```
five++;
```

We simply collect the $5 bill.

**Case 2: Customer pays $10**

# **$10**

**Give $5 change**

```
if (five == 0) return false;

ten++;
five--;
```

We need one $5 bill. If unavailable, return `false`.

**Case 3: Customer pays $20**

# **$20**

**Give $15 change**

We have two choices:

**Choice 1 — Prefer one $10 + one $5**

```
if (ten > 0 && five > 0) {
    ten--;
    five--;
}
```

**Choice 2 — Otherwise, use three $5 bills**

```
else if (five >= 3) {
    five -= 3;
}
```

If neither is possible, return `false`.

## **4. Why Prefer $10 + $5 Over Three $5 Bills?**

This is the most important greedy decision in this problem.

Suppose a customer pays $20.

We need to return $15.

We can provide:

- One $10 + one $5, or
- Three $5 bills.

**Greedy strategy: Prefer $10 + $5 whenever possible.**

Why?

Because $5 bills are more valuable for future transactions.

For example, a customer paying $10 can only receive one $5 bill as change.

But a $10 bill cannot be used to give change to a customer paying $10.

Therefore, preserve smaller bills whenever possible.

## **5. Complete Java Solution**

Your submitted code is correct. Here is the same solution with standard formatting and comments.

```
class Solution {
    public boolean lemonadeChange(int[] bills) {

        int five = 0;
        int ten = 0;

        for (int i = 0; i < bills.length; i++) {

            if (bills[i] == 5) {
                five++;
            }

            else if (bills[i] == 10) {

                if (five == 0) {
                    return false;
                }

                ten++;
                five--;
            }

            else {

                if (ten > 0 && five > 0) {
                    ten--;
                    five--;
                }

                else if (five >= 3) {
                    five -= 3;
                }

                else {
                    return false;
                }
            }
        }

        return true;
    }
}
```
