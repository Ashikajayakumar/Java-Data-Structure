## **1. Problem Statement**

You are given an array of non-negative integers `nums`.

Arrange the integers such that they form the **largest possible number** and return it as a string.

For example:

**Input:**

```
nums = [10, 2]
```

**Output:**

```
"210"
```

Why? Because:

- `10 + 2` gives `"102"`
- `2 + 10` gives `"210"`

Since `210 > 102`, we place `2` before `10`.

## **2. Important Point**

We cannot simply sort the numbers in ascending or descending order.

Instead, we need to compare two numbers by checking which concatenation produces the larger result.

For two numbers `a` and `b`, compare:

- `a + b`
- `b + a`

If `b + a` is larger, place `b` before `a`.

This is the main greedy idea.

## **3. Java Solution**

```
class Solution {
    public String largestNumber(int[] nums) {

        String[] arr = new String[nums.length];

        // Step 1: Convert integers into strings
        for (int i = 0; i < nums.length; i++) {
            arr[i] = String.valueOf(nums[i]);
        }

        // Step 2: Custom sorting
        Arrays.sort(arr, (a, b) ->
            (b + a).compareTo(a + b)
        );

        // Step 3: Handle all zeros
        if (arr[0].equals("0")) return "0";

        // Step 4: Join all strings
        StringBuilder sb = new StringBuilder();

        for (String s : arr) {
            sb.append(s);
        }

        return sb.toString();
    }
}
```

## **4. Line-by-Line Explanation**

### **Step 1: Convert integers into strings**

```
String[] arr = new String[nums.length];

for (int i = 0; i < nums.length; i++) {
    arr[i] = String.valueOf(nums[i]);
}
```

Why convert integers into strings?

Because we need to concatenate two numbers and compare their combinations.

Example:

**Original array**

# **10**

# **2**

# **9**

# **39**

**String array**

# **10**

# **2**

# **9**

# **39**

`String.valueOf(nums[i])` converts an integer into a string.

### **Step 2: Custom sorting**

```
Arrays.sort(arr, (a, b) ->
    (b + a).compareTo(a + b)
);
```

**This is the most important line in the solution.**

Let's understand it.

Suppose:

```
a = "10";
b = "2";
```

We calculate two combinations:

| Expression | Result  |
| ---------- | ------- |
| `a + b`    | `"102"` |
| `b + a`    | `"210"` |

Now compare:

```
(b + a).compareTo(a + b)
```

It becomes:

```
"210".compareTo("102")
```

Since `"210"` is lexicographically greater than `"102"`, the comparator places `"2"` before `"10"`.

**Remember:**

- If `b + a` is greater → `b` comes first.
- If `a + b` is greater → `a` comes first.
- If both are equal → either order works.

### **What does compareTo() return?**

For strings:

```
"210".compareTo("102")
```

- Positive value: first string is greater.
- Negative value: first string is smaller.
- Zero: both strings are equal.

We don't need the exact positive or negative number. Only its sign matters.

## **6. Step 3: Handle all zeros**

```
if (arr[0].equals("0")) return "0";
```

Why is this condition necessary?

Consider:

```
nums = [0, 0, 0]
```

After sorting:

```
arr = ["0", "0", "0"]
```

Without the condition, concatenation produces:

```
"000"
```

But the correct largest number is:

```
"0"
```

If the first element is `"0"` after sorting, all elements must be zero because zero would be placed after any positive number.

## **7. Step 4: Build the final number**

```
StringBuilder sb = new StringBuilder();

for (String s : arr) {
    sb.append(s);
}

return sb.toString();
```

We iterate through the sorted array and append every string.

Example:

| Iteration | s  | sb          |
| --------- | -- | ----------- |
| 1         | 9  | `"9"`       |
| 2         | 5  | `"95"`      |
| 3         | 34 | `"9534"`    |
| 4         | 3  | `"95343"`   |
| 5         | 30 | `"9534330"` |

Finally:

```
return sb.toString();
```

Output:

```
"9534330"
```
