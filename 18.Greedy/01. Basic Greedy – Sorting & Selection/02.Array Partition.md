# LeetCode 561 – Array Partition


## 1. Problem Statement

You are given an integer array `nums` containing `2n` integers.

You must divide the array into `n` pairs:

(a_1,b_1), (a_2,b_2), \ldots, (a_n,b_n) 

For each pair, calculate the minimum of its two numbers.

Your task is to maximize the sum of these minimum values.

Return the maximum possible sum.

In simple words:

- Sort the array.
- Make pairs of two adjacent elements.
- Add the smaller number from each pair.
- This gives the maximum possible sum.

## 2. Examples

Example 1

```
Input:
nums = [1, 4, 3, 2]

Output:
4
```

Explanation:

There are 4 numbers, so we need 2 pairs.

Possible pairing:

```
[1, 2]  [3, 4]

min(1, 2) = 1
min(3, 4) = 3

Total = 1 + 3 = 4
```

Example 2

```
Input:
nums = [6, 2, 6, 5, 1, 2]

Output:
9
```

Explanation:

After sorting:

```
[1, 2, 2, 5, 6, 6]
```

Make adjacent pairs:

```
[1, 2]  [2, 5]  [6, 6]

Minimum values:
   1       2       6

Total = 1 + 2 + 6 = 9
```

## 3. Important Points

1. Array length is always even.
2. We must create exactly `n` pairs.
3. Each number must be used exactly once.
4. We calculate the minimum of each pair.
5. We need to maximize the sum of all minimum values.
6. Negative numbers can also appear.

Important observation: We should avoid pairing a very small number with a very large number because that wastes the larger number's potential contribution.

## 4. Main Concept – Greedy Algorithm

Why do we sort the array?

Consider:

```
nums = [1, 4, 3, 2]
```

After sorting:

```
[1, 2, 3, 4]
```

If we create adjacent pairs:

```
[1, 2] and [3, 4]
```

We get:

```
1 + 3 = 4
```

Why is this optimal?

The smaller element in each pair contributes to the answer. Pairing adjacent sorted elements allows us to keep these smaller values as large as possible overall.

Greedy strategy:

Pair the smallest number with the second smallest, the third smallest with the fourth smallest, and so on.

## 5. Main Logic – Sorting + Pairing

We use:

- `Arrays.sort()` – sorts the array.
- `i` – iterates through the array, skipping two positions each time.
- `sum` – stores the sum of minimum values.

Algorithm:

Step 1: Sort the array.

```
Arrays.sort(nums);
```

Step 2: Start from index 0.

```
for (int i = 0; i < nums.length; i += 2)
```

Why `i += 2`?

Because each pair contains two elements.

Step 3: Add the first element of every pair.

```
sum = sum + nums[i];
```

Since the array is sorted, `nums[i]` is the smaller element in its adjacent pair.

Step 4: Return the sum.

```
return sum;
```

## 6. Java Solution

```
import java.util.Arrays;

class Solution {
    public int arrayPairSum(int[] nums) {

        Arrays.sort(nums);

        int sum = 0;

        for (int i = 0; i < nums.length; i += 2) {

            sum = sum + nums[i];

        }

        return sum;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Method declaration

```
public int arrayPairSum(int[] nums)
```

- Accepts an integer array.
- Returns the maximum sum of pair minimums.

Part B – Sorting

```
Arrays.sort(nums);
```

Example:

```
Before:
[6, 2, 6, 5, 1, 2]

After:
[1, 2, 2, 5, 6, 6]
```

Part C – Initialize sum

```
int sum = 0;
```

Stores the minimum value from each pair.

Part D – Loop

```
for (int i = 0; i < nums.length; i += 2)
```

The loop visits indices:

```
0 → 2 → 4
```

Why not `i++`?

Because we process one complete pair during each iteration.

Part E – Add minimum

```
sum = sum + nums[i];
```

Since the array is sorted, the element at index `i` is the minimum of the pair:

```
nums[i], nums[i + 1]
```

Part F – Return

```
return sum;
```

Returns the maximum possible sum.
