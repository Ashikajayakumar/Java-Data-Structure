# LeetCode 976 – Largest Perimeter Triangle

## 1. Problem Statement

You are given an integer array `nums`, where each element represents the length of a side.

Your task is to select three sides from the array that can form a valid triangle and have the largest possible perimeter.

Return the largest possible perimeter. If no valid triangle can be formed, return `0`.

In simple words:

- Select any three numbers from the array.
- Check whether they can form a triangle.
- Calculate their perimeter (sum of three sides).
- Return the maximum possible perimeter.

## 2. Triangle Rule – Important Concept

For three sides to form a valid triangle, the sum of the two smaller sides must be greater than the largest side.

Suppose the sides are sorted:

``(a_1,b_1), (a_2,b_2), \ldots, (a_n,b_n)``

Give feedback

The triangle condition is:

`` a+b>c``

If this condition is false, the three sides cannot form a valid triangle.

Examples:

| Sides   | Condition | Valid? |
| ------- | --------- | ------ |
| 2, 3, 4 | 2 + 3 > 4 | Yes    |
| 3, 4, 5 | 3 + 4 > 5 | Yes    |
| 1, 2, 3 | 1 + 2 = 3 | No     |
| 2, 3, 6 | 2 + 3 < 6 | No     |

Remember: Equality is not enough. The sum must be strictly greater.

## 4. Main Concept – Greedy Algorithm

Why do we use Greedy?

We need the largest perimeter.

The perimeter is the sum of all three sides:

`` P=a+b+c ``

To maximize the perimeter, we should try the three largest available sides first.

But there is one condition: those three sides must form a valid triangle.

Greedy strategy:

1. Sort the array in ascending order.
2. Start checking from the largest three elements.
3. If they form a valid triangle, return their sum.
4. Otherwise, move one position to the left and check again.

Why does this work?

Once sorted, the first valid triple found while moving from right to left has the largest possible perimeter. Any later triple will have at least one side replaced by a smaller or equal value.

## 5. Main Logic – Sorting + Greedy

We use:

- `Arrays.sort()` – sorts the array.
- `i` – selects the starting index of three consecutive sides.
- `nums[i]` – smallest side.
- `nums[i + 1]` – middle side.
- `nums[i + 2]` – largest side.

Algorithm:

```
Arrays.sort(nums);

for (int i = nums.length - 3; i >= 0; i--) {

    if (nums[i] + nums[i + 1] > nums[i + 2]) {

        return nums[i] + nums[i + 1] + nums[i + 2];

    }
}

return 0;
```

Why `i = nums.length - 3`?

We need three elements, so the first check must start at the third-last index.

Why `i--`?

We check the largest three sides first. If they are invalid, we try the next smaller combination.

## 6. Java Solution

```
import java.util.Arrays;

class Solution {
    public int largestPerimeter(int[] nums) {

        Arrays.sort(nums);

        for (int i = nums.length - 3; i >= 0; i--) {

            if (nums[i] + nums[i + 1] > nums[i + 2]) {

                return nums[i] + nums[i + 1] + nums[i + 2];

            }
        }

        return 0;
    }
}
```
