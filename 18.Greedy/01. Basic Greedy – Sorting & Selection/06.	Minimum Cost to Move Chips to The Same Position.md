# LeetCode 1217 – Minimum Cost to Move Chips to The Same Position

## 1. Problem Statement

You are given an integer array `position`, where `position[i]` represents the current position of the `i-th` chip.

You can move a chip using two operations:

1. Move a chip by 2 positions (left or right) – Cost = `0`.
2. Move a chip by 1 position (left or right) – Cost = `1`.

Your task is to move all chips to the same position with the minimum total cost.

Return the minimum cost.

## 2. Example

Input:

```
position = [1, 2, 3]
```

Output:

```
1
```

Explanation:

We can move all chips to position 2.

| Chip   | Starting Position | Movement    | Cost |
| ------ | ----------------- | ----------- | ---- |
| Chip 1 | 1                 | 1 → 2       | 1    |
| Chip 2 | 2                 | No movement | 0    |
| Chip 3 | 3                 | 3 → 2       | 1    |

But there is a better way:

Move all chips to position 1.

| Chip   | Starting Position | Movement               | Cost |
| ------ | ----------------- | ---------------------- | ---- |
| Chip 1 | 1                 | No movement            | 0    |
| Chip 2 | 2                 | 2 → 1                  | 1    |
| Chip 3 | 3                 | 3 → 1 (two steps of 2) | 0    |

Total cost:

``  0+1+0=\boxed{1} ``

## 3. Important Points

The most important observation is:

- Moving by 2 positions costs `0`.
- Moving by 1 position costs `1`.

Consider these movements:

```
Position:  1  2  3  4  5  6  7

Odd:       1     3     5     7
Even:         2     4     6
```

Key observation:

- A chip at an odd position can reach any other odd position with zero cost.
- A chip at an even position can reach any other even position with zero cost.
- Moving from an odd position to an even position requires one 1-step move, costing `1`.

Therefore, we do not need to calculate every possible destination.

We only need to count:

1. How many chips are at odd positions?
2. How many chips are at even positions?

## 4. Main Concept – Greedy + Parity

What is parity?

Parity means whether a number is odd or even.

| Number | Parity | Condition in Java      |
| ------ | ------ | ---------------------- |
| 1      | Odd    | `position[i] % 2 != 0` |
| 2      | Even   | `position[i] % 2 == 0` |
| 3      | Odd    | `position[i] % 2 != 0` |
| 4      | Even   | `position[i] % 2 == 0` |

Greedy idea:

Move all chips to whichever group has more chips.

Why?

- Chips in the same parity group can move together for free.
- Every chip in the opposite group needs to pay cost `1`.
- Choosing the larger group minimizes the number of chips that must move across parity.

Therefore:

`` boxed{Answer = \min(oddCount, evenCount)} ``

## 5. Main Logic – Step by Step

1. Initialize `oddCount = 0`.
2. Initialize `evenCount = 0`.
3. Traverse the `position` array.
4. If the position is odd, increment `oddCount`.
5. Otherwise, increment `evenCount`.
6. Return the smaller count.

## 6. Java Solution



Greedy + Math

Optimal



```
class Solution {
    public int minCostToMoveChips(int[] position) {

        int oddCount = 0;
        int evenCount = 0;

        for (int i = 0; i < position.length; i++) {

            if (position[i] % 2 == 0) {
                evenCount++;
            } else {
                oddCount++;
            }
        }

        return Math.min(oddCount, evenCount);
    }
}
```

## 7. Understand the Code

Part A – Initialize counters

```
int oddCount = 0;
int evenCount = 0;
```

We use two variables:

- `oddCount` counts chips at odd positions.
- `evenCount` counts chips at even positions.

Initially, both are zero.

Part B – Traverse the array

```
for (int i = 0; i < position.length; i++)
```

The loop checks every chip's position.

Part C – Check even position

```
if (position[i] % 2 == 0) {
    evenCount++;
}
```

The `%` operator gives the remainder.

For example:

```
4 % 2 = 0  → Even
6 % 2 = 0  → Even
```

If the remainder is zero, increase `evenCount`.

Part D – Check odd position

```
else {
    oddCount++;
}
```

If the position is not even, it is odd.

```
3 % 2 = 1 → Odd
5 % 2 = 1 → Odd
```

Increase `oddCount`.

Part E – Find the minimum cost

```
return Math.min(oddCount, evenCount);
```

`Math.min()` returns the smaller of the two values.

Why the smaller count?

We move all chips to the parity group that already contains more chips. Only the chips in the smaller group need to pay a cost of `1` each.
