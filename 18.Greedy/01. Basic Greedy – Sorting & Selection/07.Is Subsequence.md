## **1. Problem Statement**

Given two strings `s` and `t`, return `true` if `s` is a subsequence of `t`, or `false` otherwise.

A **subsequence** is a string that can be formed by deleting zero or more characters from another string without changing the relative order of the remaining characters.

The characters do not need to be next to each other, but their order must remain the same.

### **Example 1**

```
Input:
s = "abc"
t = "ahbgdc"

Output:
true

Explanation:
a b c appear in t in the same order.

t = a h b g d c
    ↑   ↑     ↑

s = a   b     c
```

### **Example 2**

```
Input:
s = "axc"
t = "ahbgdc"

Output:
false

Explanation:
'a' and 'c' are present, but 'x' is not present
between them in the required order.
```

### **Example 3**

```
Input:
s = ""
t = "ahbgdc"

Output:
true

Explanation:
An empty string is a subsequence of every string.
```

## **2. Important Points**

1. We must check whether all characters of `s` exist in `t`.
2. Characters must appear in the same relative order.
3. Characters do not need to be consecutive.
4. We cannot rearrange characters.
5. An empty `s` is always a subsequence of `t`.

## **3. Main Concept — Two Pointers**

We use two pointers:

- `i` → traverses string `s`.
- `j` → traverses string `t`.

The idea is simple:

- If both characters match, move both pointers.
- If they do not match, move only `j`.
- If we successfully match every character of `s`, return `true`.

**Pointer visualization**

```
s = a b c
    ↑
    i

t = a h b g d c
    ↑
    j
```

Match

Move both `i` and `j`.

No match

Move only `j`.

## **4. Main Logic — Step by Step**

Suppose:

```
s = "abc"
t = "ahbgdc"
```

Initially:

```
int i = 0;
int j = 0;
```

**Step 1: Compare characters**

```
if (s.charAt(i) == t.charAt(j))
```

If characters match:

```
i++;
j++;
```

If they do not match:

```
j++;
```

**Step 2: Continue until&#x20;**`t`**&#x20;is completed or&#x20;**`s`**&#x20;is matched.**

```
while (i < s.length() && j < t.length())
```

**Step 3: Check whether all characters of&#x20;**`s`**&#x20;were matched.**

```
return i == s.length();
```

If `i` reaches the length of `s`, all characters have been found in order.

## **5. Complete Java Solution**

```
class Solution {
    public boolean isSubsequence(String s, String t) {

        int i = 0;
        int j = 0;

        while (i < s.length() && j < t.length()) {

            if (s.charAt(i) == t.charAt(j)) {
                i++;
            }

            j++;
        }

        return i == s.length();
    }
}
```

## **6. Understand the Code — Line by Line**

### **Part A — Initialize two pointers**

```
int i = 0;
int j = 0;
```

| Pointer | Purpose                           |
| ------- | --------------------------------- |
| `i`     | Current character position in `s` |
| `j`     | Current character position in `t` |

Initially, both point to the first character.

### **Part B — While loop**

```
while (i < s.length() && j < t.length())
```

The loop continues while:

- We still have characters to match in `s`.
- We still have characters to examine in `t`.

### **Part C — Compare characters**

```
if (s.charAt(i) == t.charAt(j)) {
    i++;
}
```

If the characters match, we have successfully found the current character of `s`.

Move `i` to the next character.

### **Part D — Move the second pointer**

```
j++;
```

Regardless of whether characters match, move `j` forward.

Why?

Because each character of `t` can be checked only once, and we must preserve its order.

### **Part E — Return the result**

```
return i == s.length();
```

If `i` reaches the end of `s`, every character has been matched.

Return `true`; otherwise return `false`.
