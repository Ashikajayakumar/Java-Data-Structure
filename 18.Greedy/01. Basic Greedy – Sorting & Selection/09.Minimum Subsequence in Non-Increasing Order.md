## 1. Problem Statement

You are given an array of positive integers `nums`.

Find a subsequence such that:

1. The sum of the selected elements is strictly greater than the sum of the remaining elements.
2. The subsequence contains the minimum possible number of elements.
3. The subsequence must be in non-increasing order (largest to smallest).

Return the subsequence.

### Example 1

**Input:**
```java
nums = [4, 3, 10, 9, 8]
```

**Output:**
```java
[10, 9]
```

**Explanation:**

Total sum:

\[
4+3+10+9+8=34
\]

We need to select elements whose sum is greater than the remaining sum.

- Select `10`: Selected sum = 10, Remaining sum = 24. Not enough.
- Select `9`: Selected sum = 19, Remaining sum = 15.

Now:

\[
19 > 15
\]

Therefore, the answer is:

```java
[10, 9]
```

We cannot select just one element because the largest element, 10, is not greater than the remaining sum, 24.

---

## 2. Important Point – Greedy Approach

**How can we get the minimum number of elements?**

We should always select the largest available element first.

**Why?**

Selecting larger elements helps us reach the required sum using fewer elements.

### Strategy

1. Sort the array in ascending order.
2. Start selecting elements from the largest.
3. Keep adding elements to the selected sum.
4. Stop when the selected sum becomes greater than the remaining sum.

This is called the **Greedy Approach**.

### Key Condition

\[
\boxed{SelectedSum > RemainingSum}
\]

---

## 3. Java Solution

```java
class Solution {
    public List<Integer> minSubsequence(int[] nums) {

        // Step 1: Sort the array
        Arrays.sort(nums);

        // Step 2: Calculate total sum
        int total = 0;

        for (int i = 0; i < nums.length; i++) {
            total += nums[i];
        }

        // Step 3: Select elements from largest
        List<Integer> res = new ArrayList<>();
        int sum = 0;

        for (int i = nums.length - 1; i >= 0; i--) {

            sum += nums[i];
            res.add(nums[i]);

            // Step 4: Check the condition
            if (sum > total - sum) {
                break;
            }
        }

        return res;
    }
}
```

## 4. Line-by-Line Explanation

### Step 1: Sort the Array

```java
Arrays.sort(nums);
```

Java sorts the array in ascending order.

**Before sorting:**

```text
[4, 3, 10, 9, 8]
```

**After sorting:**

```text
[3, 4, 8, 9, 10]
```

Ascending order means smallest to largest.

**Why ascending order?**

Because we can easily start from the last index to select the largest element.

### Step 2: Calculate the Total Sum

```java
int total = 0;

for (int i = 0; i < nums.length; i++) {
    total += nums[i];
}
```

We calculate the sum of all elements.

| i | nums[i] | total |
|---|---|---|
| 0 | 3 | 3 |
| 1 | 4 | 7 |
| 2 | 8 | 15 |
| 3 | 9 | 24 |
| 4 | 10 | 34 |

Final:

```java
total = 34;
```

**Why calculate the total?**

Because:

\[
RemainingSum = TotalSum - SelectedSum
\]

We don't need another loop to calculate the remaining sum.

### Step 3: Initialize Variables

```java
List<Integer> res = new ArrayList<>();
int sum = 0;
```

- `res`: Stores the selected elements.
- `sum`: Stores the sum of selected elements.

Initially:

```java
res = []
sum = 0
```

### Step 4: Iterate from Largest to Smallest

```java
for (int i = nums.length - 1; i >= 0; i--) {
```

Our sorted array:

```text
Index:  0  1  2  3   4
        3  4  8  9  10
                    ↑
                  Start
```

We start at index `4` because it contains the largest element.

The loop moves backwards:

```text
10 → 9 → 8 → 4 → 3
```

### Step 5: Add the Selected Element

```java
sum += nums[i];
res.add(nums[i]);
```

- Add the current element to `sum`.
- Add the current element to the result list.

### Step 6: Check the Condition

```java
if (sum > total - sum) {
    break;
}
```

This is the most important condition.

Here:

- `sum` = Selected sum.
- `total - sum` = Remaining sum.

If the selected sum is greater than the remaining sum, we stop.

**Why `break`?**

Because we already have the minimum number of elements. Selecting more elements is unnecessary.

## 5. Complete Dry Run

**Input:**

```java
nums = [4, 3, 10, 9, 8]
```

**After sorting:**

```java
nums = [3, 4, 8, 9, 10]
```

**Total sum:**

```java

```

**Initial values:**

```java

```

Let's trace each iteration.

| Iteration | i | nums[i] | Selected Sum | Remaining Sum | Condition |
|---|---:|---:|---:|---:|---|
| 1 | 4 | 10 | 10 | 24 | 10 > 24 ❌ |
| 2 | 3 | 9 | 19 | 15 | 19 > 15 ✅ |

At iteration 2, the condition becomes true.

Therefore, `break` executes.

### Visual Dry Run

**Iteration 1: Select 10**

| Selected | Remaining |
|---|---|
| 10 | 8 + 9 + 4 + 3 = 24 |

10 is not greater than 24.

**Iteration 2: Select 9**

| Selected | Remaining |
|---|---|
| 10 + 9 = 19 | 8 + 4 + 3 = 15 |

19 is greater than 15. Stop!

**Final Result:**

```java
[10, 9]
```
