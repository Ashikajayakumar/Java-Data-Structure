## 1. Problem Statement

You are given a 2D integer array `boxTypes`, where:

- `boxTypes[i][0]` represents the number of boxes of type `i`.
- `boxTypes[i][1]` represents the number of units in each box of type `i`.

You are also given an integer `truckSize`, which represents the maximum number of boxes the truck can carry.

Your task is to load boxes onto the truck to maximize the total number of units.

Return the maximum total units that can be loaded onto the truck.

In simple words:

- Different types of boxes are available.
- Each type has a certain number of boxes.
- Each box contains a certain number of units.
- The truck has a limited capacity.
- Select boxes to get the maximum possible units.

## 2. Example

Example 1

```
Input:

boxTypes = [
    [1, 3],
    [2, 2],
    [3, 1]
]

truckSize = 4

Output: 8
```

Explanation:

There are three types of boxes:

| Box type | Number of boxes | Units per box |
| -------- | --------------- | ------------- |
| Type 1   | 1               | 3             |
| Type 2   | 2               | 2             |
| Type 3   | 3               | 1             |

Truck capacity = 4 boxes.

We should select boxes with the highest units first.

```
Type 1 → 1 box × 3 units = 3
Type 2 → 2 boxes × 2 units = 4
Type 3 → 1 box × 1 unit  = 1
```

Total:

```
3 + 4 + 1 = 8
```

Output: `8`

## 3. Important Points

1. Each box contains a fixed number of units depending on its type.
2. We can select fewer boxes than the available quantity.
3. We cannot exceed `truckSize`.
4. Our goal is to maximize total units, not the number of boxes.
5. We can choose boxes from different types.

Important observation: A box with more units should be preferred over a box with fewer units.

## 4. Main Concept – Greedy Algorithm

What is the best choice at every step?

Select the box type that contains the maximum number of units per box.

Example:

```
Box type A → 3 boxes, 5 units each
Box type B → 4 boxes, 2 units each
Box type C → 2 boxes, 8 units each
```

Which should we choose first?

```
Type C → 8 units
Type A → 5 units
Type B → 2 units
```

We choose the highest-value boxes first.

This is called the Greedy Strategy.

## 5. Main Logic – Sorting + Greedy

We use:

- `Arrays.sort()` – sorts box types by units per box.
- `truckSize` – remaining truck capacity.
- `totalUnits` – stores the total units loaded.

Step 1 – Sort by units per box in descending order

Example:

```
Before sorting:

boxTypes = [
    [1, 3],
    [2, 2],
    [3, 1]
]
```

After sorting:

```
[
    [1, 3],
    [2, 2],
    [3, 1]
]
```

The highest units per box come first.

Step 2 – Traverse each box type

```
for (int i = 0; i < boxTypes.length; i++)
```

Step 3 – Find how many boxes we can take

```
int boxesToTake = Math.min(boxTypes[i][0], truckSize);
```

Why `Math.min()`?

We cannot take more boxes than:

- The number available.
- The remaining truck capacity.

Step 4 – Calculate units

```
totalUnits += boxesToTake * boxTypes[i][1];
```

Step 5 – Reduce truck capacity

```
truckSize -= boxesToTake;
```

Step 6 – Stop if truck is full

```
if (truckSize == 0) {
    break;
}
```

## 6. Java Solution

```
import java.util.Arrays;

class Solution {
    public int maximumUnits(int[][] boxTypes, int truckSize) {

        Arrays.sort(boxTypes, (a, b) -> b[1] - a[1]);

        int totalUnits = 0;

        for (int i = 0; i < boxTypes.length; i++) {

            int boxesToTake = Math.min(boxTypes[i][0], truckSize);

            totalUnits += boxesToTake * boxTypes[i][1];

            truckSize -= boxesToTake;

            if (truckSize == 0) {
                break;
            }
        }

        return totalUnits;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Method declaration

```
public int maximumUnits(int[][] boxTypes, int truckSize)
```

- `boxTypes` is a 2D array.
- `truckSize` is the maximum number of boxes allowed.
- Returns the maximum total units.

Part B – Sorting

```
Arrays.sort(boxTypes, (a, b) -> b[1] - a[1]);
```

This is the most important line.

Here:

- `a[0]` = number of boxes in type A.
- `a[1]` = units per box in type A.
- `b[1]` = units per box in type B.

`b[1] - a[1]` sorts in descending order based on units per box.

Example:

```
Before:

[1, 3]
[2, 2]
[3, 1]

After:

[1, 3]
[2, 2]
[3, 1]
```

Part C – Initialize total units

```
int totalUnits = 0;
```

Initially, the truck contains zero units.

Part D – Loop through box types

```
for (int i = 0; i < boxTypes.length; i++)
```

Processes each type starting from the highest units per box.

Part E – Select the number of boxes

```
int boxesToTake = Math.min(boxTypes[i][0], truckSize);
```

Suppose:

```
Available boxes = 5
Remaining truck capacity = 3
```

Then:

```
Math.min(5, 3) = 3
```

We can take only 3 boxes.

Part F – Calculate total units

```
totalUnits += boxesToTake * boxTypes[i][1];
```

If:

```
Boxes taken = 3
Units per box = 4
```

Then:

```
Total units = 3 × 4 = 12
```

Part G – Update capacity

```
truckSize -= boxesToTake;
```

If capacity was 4 and we took 2 boxes:

```
Remaining capacity = 4 - 2 = 2
```

Part H – Check whether truck is full

```
if (truckSize == 0) {
    break;
}
```

No need to process more box types once the truck is full.

Part I – Return answer

```
return totalUnits;
```

Returns the maximum units loaded onto the truck.
