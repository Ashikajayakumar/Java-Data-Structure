# LeetCode 435 – Non-overlapping Intervals


## 1. Problem Statement

You are given an array of intervals, where each interval contains a start time and an end time.

You need to remove the minimum number of intervals so that the remaining intervals do not overlap.

Return the minimum number of intervals you need to remove.

Important: Two intervals that touch at the boundary are not considered overlapping.

For example:

```
[1, 2] and [2, 3]
```

These intervals do not overlap because the first interval ends exactly when the second starts.

## 3. Important Points

Before writing the code, understand these observations.

1. We need to remove the minimum number of intervals.
2. We should keep as many non-overlapping intervals as possible.
3. When intervals overlap, keeping the interval that ends earlier is usually the better choice.
4. Sorting helps us process intervals in a predictable order.
5. If `currentEnd <= nextStart`, there is no overlap.

Key observation:

Instead of directly deciding which intervals to remove, we can:

- Find the maximum number of non-overlapping intervals.
- Subtract that number from the total number of intervals.

Formula:

\\[ \text{Removals} = \text{Total Intervals} - \text{Maximum Non-overlapping Intervals} \\]

## 4. Main Concept – Greedy Algorithm

What is Greedy?

Greedy means making the best available choice at each step, hoping to reach the optimal answer.

For this problem:

Always prefer the interval that finishes earliest.

Why?

Imagine two intervals overlap:

```
A = [1, 5]
B = [2, 3]
```

Which one should we keep?

- A finishes at 5.
- B finishes at 3.

If we keep B, we have more available time to select future intervals.

If we keep A, we may lose several intervals that start between 3 and 5.

Therefore, choose the interval with the smaller ending time.

Greedy decision visualization

A removed

B kept

Keeping B allows us to keep the next interval `[3,4]` too.

This is called the Earliest Finish Time Greedy Strategy.

## 5. Main Logic – Step by Step

We will use:

- Sorting
- Greedy selection
- One variable to track the ending time
- One counter to track removed intervals

### Step 1: Sort intervals by ending time

```
Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
```

Why sort by ending time?

Because we want to select intervals that finish earliest.

### Step 2: Initialize variables

```
int remove = 0;
int prevEnd = intervals[0][1];
```

- `remove` counts how many intervals we remove.
- `prevEnd` stores the ending time of the last interval we decided to keep.

### Step 3: Traverse the intervals

```
for (int i = 1; i < intervals.length; i++)
```

Start from index 1 because we have already selected the first interval.

### Step 4: Check for overlap

```
if (intervals[i][0] < prevEnd)
```

Here:

```
intervals[i][0] = Current interval start
prevEnd         = Previous kept interval end
```

If current start is less than previous end, they overlap.

So remove the current interval:

```
remove++;
```

Why remove the current interval?

Because we sorted by ending time. The previous kept interval ends earlier or at the same time, so keeping it leaves at least as much room for future intervals.

### Step 5: If there is no overlap

```
else {
    prevEnd = intervals[i][1];
}
```

Update the ending time because we are keeping the current interval.

### Step 6: Return the answer

```
return remove;
```

## 6. Java Solution

Greedy – Recommended Solution

```
import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {

        // Sort intervals by ending time
        Arrays.sort(intervals, (a, b) ->
            Integer.compare(a[1], b[1]));

        int remove = 0;

        // Keep the first interval
        int prevEnd = intervals[0][1];

        // Check remaining intervals
        for (int i = 1; i < intervals.length; i++) {

            // Check if current interval overlaps
            if (intervals[i][0] < prevEnd) {

                // Remove current interval
                remove++;

            } else {

                // Keep current interval
                prevEnd = intervals[i][1];
            }
        }

        return remove;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Sorting

```
Arrays.sort(intervals, (a, b) ->
    Integer.compare(a[1], b[1]));
```

Each interval has two values:

```
interval[0] = start
interval[1] = end
```

We compare `a[1]` and `b[1]`, which means we sort by ending time in ascending order.

Example:

```
Before sorting:
[[1,2], [2,3], [3,4], [1,3]]

After sorting:
[[1,2], [2,3], [1,3], [3,4]]
```

Part B – Variables

```
int remove = 0;
int prevEnd = intervals[0][1];
```

Initially:

```
remove = 0
prevEnd = 2
```

We assume the first interval `[1,2]` is kept.

Part C – Loop

```
for (int i = 1; i < intervals.length; i++)
```

Why start at 1?

Because index 0 is already selected.

Part D – Overlap condition

```
if (intervals[i][0] < prevEnd)
```

Example:

```
Current interval = [1,3]
prevEnd = 3
```

Check:

```
1 < 3 → true
```

So there is an overlap.

Part E – Remove or keep

```
if (overlap) {
    remove++;
} else {
    prevEnd = intervals[i][1];
}
```

If overlap exists, remove the current interval.

Otherwise, keep it and update `prevEnd`.
