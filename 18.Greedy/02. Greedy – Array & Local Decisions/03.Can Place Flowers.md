# LeetCode 605 – Can Place Flowers

Greedy Algorithm | Array | Easy

## 1. Problem Statement

You are given an integer array `flowerbed` consisting of `0`s and `1`s.

- `0` represents an empty plot.
- `1` represents a plot where a flower is already planted.

You are also given an integer `n`, which represents the number of new flowers you want to plant.

You cannot plant flowers in two adjacent plots because flowers need space to grow.

Your task is to determine whether you can plant all `n` flowers without violating this rule.

Return:

- `true` if all flowers can be planted.
- `false` otherwise.

## 2. Example

Input:

```
flowerbed = [1, 0, 0, 0, 1]
n = 1
```

Output:

```
true
```

Explanation:

There is one empty plot between the two existing flowers.

We can plant a new flower at index `2`.

```
Before planting:

[1, 0, 0, 0, 1]

After planting:

[1, 0, 1, 0, 1]
       ↑
   New flower
```

No two flowers are adjacent.

Therefore, the answer is `true`.

## 3. Important Points

1. `0` means an empty position.
2. `1` means a flower is already planted.
3. Two adjacent positions cannot both contain `1`.
4. We need to plant exactly `n` new flowers.
5. We cannot remove existing flowers.
6. If the flowerbed starts or ends with an empty position, we can plant there if the neighboring position is also empty or does not exist.

Important observation:

We can plant a flower at index `i` only when:

- The current position is empty.
- The left position is empty or does not exist.
- The right position is empty or does not exist.

## 4. Main Concept – Greedy Algorithm

The greedy idea is:

Plant a flower as soon as we find a valid empty position.

Why?

Planting at the earliest valid position is safe because it does not prevent us from using any earlier position. It also allows us to continue checking the remaining plots.

For every index `i`, check:

```
       Left       Current       Right
        i-1          i           i+1
         |           |            |
         0           0            0
```

We can plant when:

\\[ left=0,\quad current=0,\quad right=0 \\]

For boundary positions, a missing neighbor is treated as empty.

## 5. Main Logic – Step by Step

1. Traverse the `flowerbed` array from left to right.
2. If the current position contains `1`, skip it.
3. If the current position is `0`, check its left neighbor.
4. Check its right neighbor.
5. If both neighbors are empty or outside the array:
   - Plant a flower by changing `flowerbed[i] = 1`.
   - Decrease `n` by one.
6. If `n` becomes zero, return `true`.
7. After checking all positions, return whether `n` is zero.

## 6. Java Solution

Greedy – Optimal Approach

```
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {

        for (int i = 0; i < flowerbed.length; i++) {

            if (flowerbed[i] == 0) {

                int left = (i == 0) ? 0 : flowerbed[i - 1];

                int right = (i == flowerbed.length - 1)
                            ? 0 : flowerbed[i + 1];

                if (left == 0 && right == 0) {

                    flowerbed[i] = 1;
                    n--;

                    if (n == 0) {
                        return true;
                    }
                }
            }
        }

        return n == 0;
    }
}
```

## 7. Understand the Code

Part A – Traverse the flowerbed

```
for (int i = 0; i < flowerbed.length; i++)
```

We visit each position from left to right.

Example:

```
Index:     0  1  2  3  4
Flowerbed: [1, 0, 0, 0, 1]
```

Part B – Check whether the current position is empty

```
if (flowerbed[i] == 0)
```

If the current position already contains a flower (`1`), we cannot plant there.

If it contains `0`, we check its neighbors.

Part C – Check the left neighbor

```
int left = (i == 0) ? 0 : flowerbed[i - 1];
```

This is a ternary operator.

It means:

- If `i == 0`, there is no left neighbor, so treat it as `0`.
- Otherwise, read the previous position.

Example:

```
Index:     0  1  2
Flowerbed: [0, 0, 1]

At index 0:

left = 0
```

Part D – Check the right neighbor

```
int right = (i == flowerbed.length - 1)
            ? 0 : flowerbed[i + 1];
```

It means:

- If `i` is the last index, treat the right neighbor as `0`.
- Otherwise, read the next position.

This prevents an array index error.

Part E – Check whether planting is possible

```
if (left == 0 && right == 0)
```

We can plant only when both neighboring positions are empty.

Remember: the current position is already confirmed as empty by the outer `if`.

Part F – Plant a flower

```
flowerbed[i] = 1;
n--;
```

We update the array to show the new flower.

Then decrease the remaining flower count.

Part G – Check whether all flowers are planted

```
if (n == 0) {
    return true;
}
```

If we have planted all required flowers, we can immediately return `true`.

Part H – Final result

```
return n == 0;
```

If the loop finishes:

- `n == 0` → All flowers were planted.
- `n > 0` → Not enough empty positions were available.
