## 1. Problem Statement

You are given an integer array `nums`.

Your task is to find a contiguous subarray (a continuous part of the array) that has the largest possible sum.

Return the maximum subarray sum.

Important: A subarray must contain at least one element, and its elements must be next to each other.

## 2. Examples

```
Input:  nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
```

Explanation:

The maximum-sum subarray is:

```
[4, -1, 2, 1]
```

Sum:

```
4 + (-1) + 2 + 1 = 6
```

## 3. Important Points

1. A subarray must be continuous.
2. The subarray must contain at least one element.
3. Negative numbers are allowed.
4. The maximum subarray does not have to start at index `0`.
5. We need the maximum sum, not the subarray itself.
6. If all elements are negative, the answer is the largest (least negative) element.

Example:

```
nums = [-5, -2, -8, -1]

Output = -1
```

We cannot return `0`, because an empty subarray is not allowed.

## 4. Main Concept – Kadane's Algorithm

Kadane's Algorithm is an efficient way to find the maximum sum of a contiguous subarray.

It uses two variables:

| Variable     | Purpose                                               |
| ------------ | ----------------------------------------------------- |
| `currentSum` | Maximum sum of a subarray ending at the current index |
| `maxSum`     | Maximum sum found so far                              |

### The main question at every element

Should we:

1. Continue the previous subarray?
2. Start a new subarray from the current element?

We compare these two choices:

```
currentSum = Math.max(nums[i], currentSum + nums[i]);
```

Choice 1: Start fresh

```
nums[i]
```

Ignore the previous subarray and start with the current element.

Choice 2: Continue

```
currentSum + nums[i]
```

Add the current element to the previous subarray.

Choose whichever gives the larger sum.

Then update the global maximum:

```
maxSum = Math.max(maxSum, currentSum);
```

### Why does this work?

Suppose the previous subarray sum is negative.

Adding a negative sum to the current element can only make the new subarray sum smaller.

So, starting fresh is better.

If the previous sum is positive, extending the subarray may produce a larger sum.

This is the key idea behind Kadane's Algorithm.

## 5. Main Logic – Step by Step

1. Initialize `currentSum` with the first array element.
2. Initialize `maxSum` with the first array element.
3. Start traversing from index `1`.
4. At every index, calculate:
   - Start a new subarray.
   - Extend the existing subarray.
5. Store the maximum of these two choices in `currentSum`.
6. Compare `currentSum` with `maxSum`.
7. Update `maxSum` if the current sum is greater.
8. Return `maxSum`.

## 6. Java Solution – Kadane's Algorithm

```
class Solution {
    public int maxSubArray(int[] nums) {

        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {

            currentSum = Math.max(nums[i], currentSum + nums[i]);

            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
```

## 7. Understand the Code

Part A – Initialize variables

```
int currentSum = nums[0];
int maxSum = nums[0];
```

For the first element, the only possible subarray ending at index `0` is the first element itself.

Example:

```
nums = [-2,1,-3,4,-1,2,1,-5,4]

currentSum = -2
maxSum     = -2
```

We initialize both with `nums[0]` instead of `0` because the array may contain only negative numbers.

Part B – Traverse the array

```
for (int i = 1; i < nums.length; i++)
```

We start from index `1` because index `0` is already considered.

Part C – Choose whether to start or continue

```
currentSum = Math.max(nums[i], currentSum + nums[i]);
```

This is the most important line.

It compares:

- `nums[i]`: Start a new subarray.
- `currentSum + nums[i]`: Continue the previous subarray.

The larger value becomes the new `currentSum`.

Part D – Update maximum sum

```
maxSum = Math.max(maxSum, currentSum);
```

Checks whether the current subarray sum is greater than the maximum sum found so far.

If yes, update `maxSum`.

Part E – Return answer

```
return maxSum;
```

Returns the maximum subarray sum.

## 10. Visualization – How Kadane's Algorithm Works

The algorithm makes a decision at each element:

```
                 Current Element
                       |
             ---------------------
             |                   |
         Start fresh          Continue
          nums[i]          currentSum + nums[i]
             |                   |
             ---------------------
                       |
                  Take maximum
                       |
                 Update maxSum
```

Remember:

```
If previous sum is negative:
    Start a new subarray.

If previous sum is positive:
    Continue the previous subarray.
```

This is a useful intuition, but in code we always compare both choices using `Math.max()`.
