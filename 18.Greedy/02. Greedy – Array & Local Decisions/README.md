| Problem Clue | Greedy Pattern |
|---|---|
| Collect profit from multiple price increases | Local Profit Accumulation |

| Find maximum balanced partitions | Greedy Counting |
| Find maximum sum of a contiguous subarray | Kadane's Algorithm |
| Find the longest alternating sequence | Direction Change Greedy |

| Find the largest number with non-decreasing digits | Right-to-Left Greedy |
