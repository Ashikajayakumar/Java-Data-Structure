# LeetCode 1221 – Split a String in Balanced Strings

Greedy Algorithm | String | Easy

## 1. Problem Statement

You are given a string `s` containing only two characters:

- `L` – Left
- `R` – Right

A balanced string is a string that contains an equal number of `L` and `R` characters.

Your task is to split the given string into the maximum number of balanced substrings.

Return the maximum number of balanced strings you can obtain.

## 2. Example

Example 1

```
Input:  s = "RLRRLLRLRL"
Output: 4
```

Explanation:

We can split the string into four balanced substrings:

```
R L | R R L L | R L | R L
```

| Substring | L count | R count | Balanced? |
| --------- | ------- | ------- | --------- |
| RL        | 1       | 1       | Yes       |
| RRLL      | 2       | 2       | Yes       |
| RL        | 1       | 1       | Yes       |
| RL        | 1       | 1       | Yes       |

Therefore, the answer is `4`.

Example 2

```
Input:  s = "LLLLRRRR"
Output: 1
```

Explanation:

```
LLLL RRRR
```

There are four `L` and four `R`, so the entire string is one balanced substring.

Example 3

```
Input:  s = "RLRRRLLRLL"
Output: 2
```

One valid split is:

```
RL | RRRLLRLL
```

Both substrings contain equal numbers of `L` and `R`.

## 3. Important Points

1. A balanced string must contain equal numbers of `L` and `R`.
2. We need the maximum number of balanced substrings, not just one balanced substring.
3. We can scan the string only once.
4. We do not need to create separate substring objects.
5. We only need two variables:
   - `balance` – tracks the difference between `R` and `L`.
   - `count` – counts the balanced substrings.

## 4. Main Concept – Greedy Algorithm

What is the greedy idea?

Whenever the number of `L` and `R` characters becomes equal, immediately split the string.

Why?

Because we want to create as many balanced substrings as possible. Splitting as soon as the current part becomes balanced gives us the earliest possible valid boundary.

### How do we track balance?

| Character | Operation   |
| --------- | ----------- |
| `R`       | `balance++` |
| `L`       | `balance--` |

When:

```
balance == 0
```

It means:

```
Number of R = Number of L
```

So, we found one balanced substring.

Increase:

```
count++;
```

## 5. Main Logic – Step by Step

1. Initialize `balance = 0`.
2. Initialize `count = 0`.
3. Traverse every character in the string.
4. If the character is `R`, increase `balance`.
5. If the character is `L`, decrease `balance`.
6. If `balance == 0`, increase `count`.
7. Return `count`.

## 6. Java Solution

```
class Solution {
    public int balancedStringSplit(String s) {

        int balance = 0;
        int count = 0;

        for (int i = 0; i < s.length(); i++) {

            if (s.charAt(i) == 'R') {
                balance++;
            } else {
                balance--;
            }

            if (balance == 0) {
                count++;
            }
        }

        return count;
    }
}
```

## 7. Understand the Code

Part A – Initialize variables

```
int balance = 0;
int count = 0;
```

- `balance` tracks the difference between `R` and `L`.
- `count` stores the number of balanced substrings found.

Part B – Traverse the string

```
for (int i = 0; i < s.length(); i++)
```

Visits each character from index `0` to the last index.

Part C – Update balance

```
if (s.charAt(i) == 'R') {
    balance++;
} else {
    balance--;
}
```

For every `R`, add 1.

For every `L`, subtract 1.

Part D – Check balanced substring

```
if (balance == 0) {
    count++;
}
```

When `balance` becomes zero, the current substring has an equal number of `L` and `R`.

So, increase the answer.

Part E – Return answer

```
return count;
```

Returns the maximum number of balanced substrings.
