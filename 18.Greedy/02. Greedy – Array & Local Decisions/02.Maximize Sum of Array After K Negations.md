# LeetCode 1005 – Maximize Sum of Array After K Negations

## 1. Problem Statement

You are given an integer array `nums` and an integer `k`.

In one operation, you can choose any index `i` and multiply `nums[i]` by `-1`.

You can perform this operation exactly `k` times. You may choose the same index multiple times.

Your task is to find the maximum possible sum of the array after performing exactly `k` operations.

## 2. Example

Input:

```
nums = [4, 2, 3]
k = 1
```

Output:

```
5
```

Explanation:

We can choose `-` operation on the element `2`:

```
Original array: [4, 2, 3]
After operation: [4, -2, 3]
```

Sum:

`` 4+(-2)+3= 5 ``
## 3. Important Points

1. We must perform exactly `k` negation operations.
2. Each operation changes the sign of one element.
3. We can choose the same element more than once.
4. Our goal is to maximize the sum.
5. Negating a negative number makes it positive, which increases the sum.
6. Negating a positive number makes it negative, which decreases the sum.

Important observation: Always try to convert negative numbers into positive numbers first. If operations remain, use them on the smallest absolute-value element.

## 4. Main Concept – Greedy + Sorting

The greedy strategy has two stages.

Stage 1: Convert negative numbers into positive numbers

A negative number gives us a chance to increase the sum.

Example:

```
-5 → +5
```

The sum increases by `10`.

So, we should flip the most negative numbers first.

Stage 2: Handle the remaining operations

After converting all negative numbers, we may still have some operations left.

- If remaining `k` is even, flip the same element twice. Its value returns to the original, so the sum does not change.
- If remaining `k` is odd, flip the element with the smallest absolute value. This causes the smallest possible decrease in the sum.
- If the array contains zero, flipping zero has no effect, so it can absorb any remaining operations.

Key observation:

 `` \[
\boxed{\text{If remaining } k \text{ is odd, flip the smallest absolute value}}
\] ``

## 5. Main Logic – Step by Step

1. Sort the array in ascending order.
2. Start from the smallest element.
3. While the current element is negative and `k > 0`:
   - Multiply it by `-1`.
   - Decrease `k` by one.
4. Calculate the sum of the updated array.
5. Find the smallest absolute value in the updated array.
6. If `k` is odd, subtract twice that smallest absolute value from the sum.
7. Return the maximum sum.

## 6. Java Solution



Greedy + Sorting

Optimal



```
import java.util.Arrays;

class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {

        Arrays.sort(nums);

        for (int i = 0; i < nums.length && k > 0; i++) {

            if (nums[i] < 0) {
                nums[i] = -nums[i];
                k--;
            }
        }

        int sum = 0;
        int minAbs = Integer.MAX_VALUE;

        for (int i = 0; i < nums.length; i++) {

            sum += nums[i];

            minAbs = Math.min(minAbs, Math.abs(nums[i]));
        }

        if (k % 2 == 1) {
            sum -= 2 * minAbs;
        }

        return sum;
    }
}
```

## 7. Understand the Code

Part A – Sort the array

```
Arrays.sort(nums);
```

Sorting places negative numbers first, from the most negative to the least negative.

Example:

```
Before sorting: [2, -3, -1, 5, -4]

After sorting:  [-4, -3, -1, 2, 5]
```

This helps us flip the most negative numbers first.

Part B – Flip negative numbers

```
for (int i = 0; i < nums.length && k > 0; i++) {

    if (nums[i] < 0) {
        nums[i] = -nums[i];
        k--;
    }
}
```

The loop continues while:

- There are elements left in the array.
- We still have operations available.

If the current element is negative:

```
nums[i] = -nums[i];
```

It becomes positive.

Then:

```
k--;
```

One operation has been completed.

Example:

```
-4 → 4
k = 3 → 2
```

Part C – Initialize sum and minimum absolute value

```
int sum = 0;
int minAbs = Integer.MAX_VALUE;
```

- `sum` stores the total of all updated elements.
- `minAbs` stores the smallest absolute value.

Why do we need `minAbs`?

If an odd number of operations remains, we must flip the smallest absolute-value element to minimize the loss.

Part D – Calculate sum and minimum absolute value

```
for (int i = 0; i < nums.length; i++) {

    sum += nums[i];

    minAbs = Math.min(minAbs, Math.abs(nums[i]));
}
```

For every element:

- Add its value to `sum`.
- Find its absolute value using `Math.abs()`.
- Update `minAbs` if a smaller value is found.

Example:

```
nums = [1, 2, 3]

Absolute values = [1, 2, 3]

minAbs = 1
```

Part E – Handle remaining odd operations

```
if (k % 2 == 1) {
    sum -= 2 * minAbs;
}
```

If `k` is odd, one effective negation remains after pairing the other operations.

Example:

```
Smallest element = 1

1 → -1

Change in sum = -1 - 1 = -2
```

Therefore, subtract `2 * minAbs`.

If `k` is even, no adjustment is needed.

Part F – Return the answer

```
return sum;
```

Returns the maximum possible sum.
