# LeetCode 376 – Wiggle Subsequence

Greedy Algorithm | Dynamic Programming | Medium
## 1. Problem Statement

You are given an integer array `nums`.

A wiggle sequence is a sequence where the differences between consecutive numbers strictly alternate between positive and negative.

In simple words:

- First, the numbers can increase.
- Next, they must decrease.
- Then increase again.
- Then decrease again.

The direction must keep alternating.

Your task is to find the length of the longest wiggle subsequence.

Important: A subsequence does not need to be continuous. You can skip elements, but you must maintain their original order.

## 2. Examples

Example 1

```
Input:  nums = [1,7,4,9,2,5]
Output: 6
```

Explanation:

The entire array is a wiggle sequence.

```
1 → 7 → 4 → 9 → 2 → 5
   +6  -3  +5  -7  +3
```

The differences alternate:

```
Positive → Negative → Positive → Negative → Positive
```

Therefore, the answer is `6`.

Example 2

```
Input:  nums = [1,17,5,10,13,15,10,5,16,8]
Output: 7
```

One longest wiggle subsequence is:

```
1 → 17 → 10 → 13 → 5 → 16 → 8
```

Differences:

```
+16 → -7 → +3 → -8 → +11 → -8
```

There are 7 elements.

Example 3

```
Input:  nums = [1,2,3,4,5,6,7,8,9]
Output: 2
```

Explanation:

The array is continuously increasing.

There is no direction change, so the longest wiggle subsequence contains only two elements.

For example:

```
1 → 2
```

Answer = `2`.

## 3. Important Points

Before writing the code, understand these three concepts.

| Concept             | Meaning                                                  |
| ------------------- | -------------------------------------------------------- |
| Subsequence         | Elements can be skipped, but order must remain the same. |
| Strictly increasing | Next number must be greater.                             |
| Strictly decreasing | Next number must be smaller.                             |

This problem asks for a subsequence, not a subarray.

## 4. Main Concept – Greedy Algorithm

The easiest way to solve this problem is to observe the direction of the numbers.

We only need to count direction changes.

### Greedy idea

1. Start with the first element.
2. Compare the current element with the previous element.
3. If the direction changes from increasing to decreasing, count one element.
4. If the direction changes from decreasing to increasing, count one element.
5. Ignore equal consecutive values.
6. Return the total length.

### Why do we ignore equal values?

Consider:

```
nums = [1, 5, 5, 5, 2]
```

Differences:

```
+4 → 0 → 0 → -3
```

The equal values do not create a positive or negative direction.

The wiggle sequence is:

```
1 → 5 → 2
```

Answer = `3`.

## 5. Main Logic – Step by Step

We use three variables:

| Variable   | Purpose                                     |
| ---------- | ------------------------------------------- |
| `count`    | Stores the length of the wiggle subsequence |
| `prevDiff` | Stores the previous difference              |
| `currDiff` | Stores the current difference               |

Algorithm:

1. If the array has only one element, return `1`.
2. Initialize `count = 1`.
3. Initialize `prevDiff = 0`.
4. Traverse the array from index `1`.
5. Calculate the difference:
   ```
   currDiff = nums[i] - nums[i - 1];
   ```
6. Check whether the direction changes:
   ```
   if ((currDiff > 0 && prevDiff <= 0) ||
       (currDiff < 0 && prevDiff >= 0))
   ```
7. If the direction changes, increase `count`.
8. Update `prevDiff`.
9. Return `count`.

## 6. Java Solution – Greedy Approach

```
class Solution {
    public int wiggleMaxLength(int[] nums) {

        if (nums.length == 1) {
            return 1;
        }

        int count = 1;
        int prevDiff = 0;

        for (int i = 1; i < nums.length; i++) {

            int currDiff = nums[i] - nums[i - 1];

            if ((currDiff > 0 && prevDiff <= 0) ||
                (currDiff < 0 && prevDiff >= 0)) {

                count++;
                prevDiff = currDiff;
            }
        }

        return count;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Handle a single element

```
if (nums.length == 1) {
    return 1;
}
```

A single element is already a valid wiggle subsequence.

Part B – Initialize variables

```
int count = 1;
int prevDiff = 0;
```

- `count = 1`: Every non-empty array has at least one element in its subsequence.
- `prevDiff = 0`: Initially, we have not found any direction.

Part C – Traverse the array

```
for (int i = 1; i < nums.length; i++)
```

Start from index `1` because we compare each element with the previous element.

Part D – Calculate the difference

```
int currDiff = nums[i] - nums[i - 1];
```

Example:

```
nums[i]     = 7
nums[i - 1] = 1

currDiff = 7 - 1 = +6
```

- Positive difference → Increasing.
- Negative difference → Decreasing.
- Zero difference → Equal.

Part E – Check direction change

```
if ((currDiff > 0 && prevDiff <= 0) ||
    (currDiff < 0 && prevDiff >= 0))
```

This is the most important condition.

There are two possibilities:

Case 1: Increasing after decreasing or equal

```
currDiff > 0 && prevDiff <= 0
```

Example:

```
Previous difference = -3
Current difference  = +5
```

Direction changes from decreasing to increasing.

Case 2: Decreasing after increasing or equal

```
currDiff < 0 && prevDiff >= 0
```

Example:

```
Previous difference = +6
Current difference  = -3
```

Direction changes from increasing to decreasing.

Part F – Update count and previous difference

```
count++;
prevDiff = currDiff;
```

Whenever the direction changes, we have found one more element in the wiggle subsequence.

Update `prevDiff` only when a direction change is detected. This also handles repeated equal values correctly.

Part G – Return answer

```
return count;
```

Returns the maximum wiggle subsequence length.
