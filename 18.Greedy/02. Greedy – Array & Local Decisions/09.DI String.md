## 1. Problem Statement

You are given a string `s` containing only the characters:

- `'I'` — Increasing
- `'D'` — Decreasing

Your task is to construct a permutation `perm` of numbers from `0` to `s.length()` such that:

- If `s[i] == 'I'`, then `perm[i] < perm[i + 1]`.
- If `s[i] == 'D'`, then `perm[i] > perm[i + 1]`.

Return any valid permutation.

### Example 1

```
Input:
s = "IDID"

Output:
[0, 4, 1, 3, 2]

Explanation:

s[0] = 'I' → 0 < 4
s[1] = 'D' → 4 > 1
s[2] = 'I' → 1 < 3
s[3] = 'D' → 3 > 2
```

### Example 2

```
Input:
s = "III"

Output:
[0, 1, 2, 3]

Explanation:
All characters are 'I'.

0 < 1 < 2 < 3
```

### Example 3

```
Input:
s = "DDI"

Output:
[3, 2, 0, 1]

Explanation:

3 > 2
2 > 0
0 < 1
```

## 2. Important Points

1. The output must contain every number from `0` to `s.length()` exactly once.
2. The output array length is `s.length() + 1`.
3. `'I'` means the next number must be greater.
4. `'D'` means the next number must be smaller.
5. We can solve this problem using two pointers: `low` and `high`.

## 3. Main Concept — Greedy Algorithm

We have a range of available numbers:

```
0, 1, 2, 3, 4
```

Instead of sorting or trying different permutations, we make a greedy choice.

- When we see `'I'`, select the smallest available number.
- When we see `'D'`, select the largest available number.

Why?

For increasing (`I`):

Choosing the smallest available number leaves larger numbers for future positions.

For decreasing (`D`):

Choosing the largest available number leaves smaller numbers for future positions.

This guarantees that the current condition is satisfied while keeping all remaining numbers available.

## 4. Two-Pointer Visualization

We maintain two pointers:

- `low = 0` — smallest available number.
- `high = s.length()` — largest available number.

Initially:

```
Numbers:  0   1   2   3   4
          ↑               ↑
         low             high
```

For each character:

| Character | Choice        | Pointer update |
| --------- | ------------- | -------------- |
| `I`       | Select `low`  | `low++`        |
| `D`       | Select `high` | `high--`       |

After processing all characters, exactly one number remains. Place it in the final position.

## 5. Main Logic — Step by Step

For every character in the string:

Case 1: `s[i] == 'I'`

```
perm[i] = low;
low++;
```

Choose the smallest available number.

Case 2: `s[i] == 'D'`

```
perm[i] = high;
high--;
```

Choose the largest available number.

Final Step:

```
perm[s.length()] = low;
```

The remaining number is assigned to the last position.

## 6. Complete Java Solution

```
class Solution {
    public int[] diStringMatch(String s) {

        int n = s.length();

        int[] perm = new int[n + 1];

        int low = 0;
        int high = n;

        for (int i = 0; i < n; i++) {

            if (s.charAt(i) == 'I') {

                perm[i] = low;
                low++;

            } else {

                perm[i] = high;
                high--;
            }
        }

        perm[n] = low;

        return perm;
    }
}
```

## 7. Understand the Code — Line by Line

Part A — Initialize variables

```
int n = s.length();

int[] perm = new int[n + 1];

int low = 0;
int high = n;
```

For input:

```
s = "IDID"
```

We get:

```
n = 4

perm = [0, 0, 0, 0, 0]

low = 0
high = 4
```

Why `n + 1`?

Because a string of length 4 contains 4 conditions, so we need 5 numbers to create the permutation.

Part B — Traverse the string

```
for (int i = 0; i < n; i++)
```

We process every character from index `0` to `n - 1`.

Part C — Handle increasing

```
if (s.charAt(i) == 'I') {
    perm[i] = low;
    low++;
}
```

If the character is `'I'`, choose the smallest available number.

Part D — Handle decreasing

```
else {
    perm[i] = high;
    high--;
}
```

If the character is `'D'`, choose the largest available number.

Part E — Fill the last position

```
perm[n] = low;
```

After processing all characters, `low` and `high` point to the same remaining number.
