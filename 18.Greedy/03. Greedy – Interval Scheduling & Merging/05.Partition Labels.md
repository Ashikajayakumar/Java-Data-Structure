## 1. Problem Statement

You are given a string `s`.

You need to divide the string into as many parts as possible so that:

- Each character appears in at most one part.
- If a character appears in a partition, all its occurrences must be inside that same partition.
- Return a list containing the length of each partition.

In simple words: A character must not be split across different partitions.

## 2. Example

Input:

```
s = "ababcbacadefegdehijhklij"
```

Output:

```
[9,7,8]
```

Explanation:

We can divide the string into three partitions:

```
ababcbaca | defegde | hijhklij
```

Their lengths are:

```
ababcbaca  → 9 characters
defegde    → 7 characters
hijhklij   → 8 characters
```

Therefore:

```
[9,7,8]
```

## 3. Important Points

1. Every character must belong to exactly one partition.
2. A character cannot appear in multiple partitions.
3. We need to maximize the number of partitions.
4. We must find the last occurrence of every character.
5. A partition can end only when the current index reaches the farthest last occurrence of all characters encountered so far.

Important observation:

Suppose the character `a` appears at indices:

```
0, 2, 6, 8
```

If we encounter `a` at index `0`, we cannot finish the partition before index `8`.

Why? Because `a` appears again at index `8`.

## 4. Main Concept — Greedy Algorithm

We use two important ideas:

1. Last occurrence array: Stores the last index of every character.
2. Greedy boundary: Tracks how far the current partition must extend.

### Step A — Find the last occurrence of every character

For every character, store its last index.

For example:

```
s = "abac"
```

Index:

```
 0 1 2 3
 a b a c
```

Last occurrence:

| Character | Last index |
| --------- | ---------- |
| a         | 2          |
| b         | 1          |
| c         | 3          |

We can store these values in an integer array of size 26 because the input contains lowercase English letters.

### Step B — Track the partition boundary

We use two variables:

```
int start = 0;
int end = 0;
```

- `start` = beginning of the current partition.
- `end` = farthest last occurrence that the current partition must reach.

As we traverse the string:

```
end = Math.max(end, last[s.charAt(i) - 'a']);
```

This updates the partition boundary whenever we encounter a character that appears farther ahead.

### Step C — Complete a partition

When:

```
i == end
```

We have reached the farthest last occurrence of every character in the current partition.

So, we can safely finish the partition.

Its length is:

```
end - start + 1
```

Then start the next partition:

```
start = i + 1;
```

## 5. Java Solution

```
import java.util.*;

class Solution {
    public List<Integer> partitionLabels(String s) {

        int[] last = new int[26];

        // Step 1: Store last occurrence of each character
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> result = new ArrayList<>();

        int start = 0;
        int end = 0;

        // Step 2: Find partitions
        for (int i = 0; i < s.length(); i++) {

            end = Math.max(end, last[s.charAt(i) - 'a']);

            // Step 3: Complete the partition
            if (i == end) {
                result.add(end - start + 1);
                start = i + 1;
            }
        }

        return result;
    }
}
```

## 6. Understand the Code — Line by Line

### Part A — Create the last occurrence array

```
int[] last = new int[26];
```

We create an array of size 26.

Why 26?

Because there are 26 lowercase English letters: `a` to `z`.

Each array position represents one character.

```
last[0] = last index of 'a'
last[1] = last index of 'b'
last[2] = last index of 'c'
...
last[25] = last index of 'z'
```

### Part B — Store the last occurrence

```
for (int i = 0; i < s.length(); i++) {
    last[s.charAt(i) - 'a'] = i;
}
```

Let's understand:

```
s.charAt(i)
```

Gets the character at index `i`.

```
s.charAt(i) - 'a'
```

Converts the character into an array index.

For example:

```
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
```

```
last[s.charAt(i) - 'a'] = i;
```

Stores the current index as the last occurrence.

If a character appears again, its previous index is overwritten. Therefore, after the loop, the array contains the last occurrence of every character.

### Part C — Create the result and boundaries

```
List<Integer> result = new ArrayList<>();

int start = 0;
int end = 0;
```

- `result` stores the length of each partition.
- `start` represents where the current partition begins.
- `end` represents the farthest index the current partition must reach.

### Part D — Traverse the string

```
for (int i = 0; i < s.length(); i++) {
```

We visit each character from left to right.

```
end = Math.max(end, last[s.charAt(i) - 'a']);
```

This is the most important line.

It finds the farthest last occurrence among all characters encountered so far in the current partition.

Example:

```
Current end = 8
Current character = 'b'
Last occurrence of b = 5
```

Then:

```
end = Math.max(8, 5);
end = 8;
```

The boundary remains 8.

If another character has its last occurrence at index 12:

```
end = Math.max(8, 12);
end = 12;
```

The partition must extend to index 12.

### Part E — Check whether the partition is complete

```
if (i == end) {
    result.add(end - start + 1);
    start = i + 1;
}
```

When `i == end`, all characters in the current partition have reached their final occurrence.

We calculate the partition length:

```
end - start + 1
```

Why `+1`?

Because array/string indices start from zero.

Example:

```
start = 0
end = 8

Length = 8 - 0 + 1 = 9
```

Then:

```
start = i + 1;
```

The next partition starts immediately after the current partition.

### Part F — Return the answer

```
return result;
```

Returns the lengths of all partitions.
