# LeetCode 1520 — Maximum Number of Non-Overlapping Substrings
<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/f5b94a7c-bd0d-489f-a6aa-481acf00b469" />

## 1. Problem Statement

You are given a string `s` containing only lowercase English letters.

You need to find the maximum number of non-empty substrings that satisfy two conditions:

1. The selected substrings must not overlap.
2. If a substring contains a character, it must contain all occurrences of that character in the original string.

If multiple answers contain the same maximum number of substrings, return the answer with the minimum total length.

Return a list of strings containing the selected substrings. They can be returned in any order.

## 2. Example 1

Input:

```
s = "adefaddaccc"
```

Output:

```
["e", "f", "ccc"]
```

Explanation:

Let's examine some possible substrings:

```
"adefadda"
"e"
"f"
"ccc"
```

Why can we choose `"e"`?

Because `e` appears only once in the original string.

Why can we choose `"f"`?

Because `f` also appears only once.

Why can we choose `"ccc"`?

Because all occurrences of `c` are included.

The selected substrings do not overlap:

```
adefaddaccc
  e
   f
        ccc
```

We can select three substrings:

```
["e", "f", "ccc"]
```

Choosing `"adefadda"` and `"ccc"` would give only two substrings.

Therefore, the maximum number is three.

## 3. Example 2

Input:

```
s = "abbaccd"
```

Output:

```
["d", "bb", "cc"]
```

Explanation:

Consider these possible substrings:

```
"abba"
"bb"
"cc"
"d"
```

Both `"abba"` and `"bb"` are valid, but they overlap.

We can choose:

```
"bb" + "cc" + "d"
```

This gives three non-overlapping substrings with a smaller total length than choosing `"abba"`, `"cc"`, and `"d"`.

## 4. Important Points

1. Every selected substring must contain all occurrences of each character it includes.
2. Selected substrings must not overlap.
3. We want the maximum number of substrings.
4. If multiple answers have the same count, choose the minimum total length.
5. We need the first and last occurrence of every character.
6. A character's first occurrence is the only useful starting position for its candidate substring.
7. A candidate substring may need to expand when it encounters another character.

Important observation:

Suppose a substring contains `a`.

If `a` occurs at indices `0`, `4`, and `7`, the substring must include all three occurrences.

If we encounter another character `b` inside this range, and `b` occurs farther to the right, we must expand the substring again.

This creates a chain of interval expansions.

## 5. Main Concept — Three Steps

Step 1 — Character positions

Find the first and last occurrence of every character.

Step 2 — Build valid intervals

Start from each character's first occurrence. Expand the interval until all occurrences of every included character are covered.

Step 3 — Greedy selection

Sort valid intervals by ending position and choose the maximum number of non-overlapping intervals.

### Step 1 — Find first and last occurrence

We create two arrays:

```
int[] first = new int[26];
int[] last = new int[26];
```

- `first[i]` stores the first occurrence of a character.
- `last[i]` stores the last occurrence of a character.

We use 26 because the string contains lowercase English letters.

Example:

```
s = "abbaccd"
```

Index:

```
 0 1 2 3 4 5 6
 a b b a c c d
```

Character occurrence table:

| Character | First | Last |
| --------- | ----- | ---- |
| a         | 0     | 3    |
| b         | 1     | 2    |
| c         | 4     | 5    |
| d         | 6     | 6    |

### Step 2 — Build valid intervals

For each character, start with:

```
int l = first[x];
int r = last[x];
```

Here:

- `l` is the starting index.
- `r` is the ending index.

Now scan from `l` to `r`.

Whenever we encounter a character, check its first occurrence.

Condition 1:

```
if (first[y] < l)
```

If true, the candidate is invalid.

Why?

Because the current substring starts after an occurrence of that character. We cannot include the character without also including its earlier occurrence.

Condition 2:

```
r = Math.max(r, last[y]);
```

If the character's last occurrence is farther ahead, extend the interval.

Continue until every character inside the interval has all its occurrences included.

### Step 3 — Select maximum non-overlapping intervals

After constructing valid intervals, sort them by ending position.

Then use greedy selection:

```
if (l > end)
```

If the current interval starts after the previously selected interval ends, select it.

Otherwise, skip it because it overlaps.

Why sort by ending position?

Because selecting the interval that finishes earliest leaves the most space for future intervals. This is the same greedy strategy as LC 435 — Non-overlapping Intervals.

## 6. Java Solution

```
import java.util.*;

class Solution {
    public List<String> maxNumOfSubstrings(String s) {

        int n = s.length();

        int[] first = new int[26];
        int[] last = new int[26];

        Arrays.fill(first, -1);

        // Step 1: Find first and last occurrence
        for (int i = 0; i < n; i++) {

            int x = s.charAt(i) - 'a';

            if (first[x] == -1) {
                first[x] = i;
            }

            last[x] = i;
        }

        // Step 2: Build valid intervals
        List<int[]> intervals = new ArrayList<>();

        for (int x = 0; x < 26; x++) {

            if (first[x] == -1) {
                continue;
            }

            int l = first[x];
            int r = last[x];

            int i = l;

            while (i <= r) {

                int y = s.charAt(i) - 'a';

                if (first[y] < l) {
                    break;
                }

                r = Math.max(r, last[y]);

                i++;
            }

            if (i > r) {
                intervals.add(new int[]{l, r});
            }
        }

        // Step 3: Sort intervals by ending position
        intervals.sort((a, b) ->
            Integer.compare(a[1], b[1])
        );

        // Step 4: Select non-overlapping intervals
        List<String> result = new ArrayList<>();

        int end = -1;

        for (int[] interval : intervals) {

            int l = interval[0];
            int r = interval[1];

            if (l > end) {

                result.add(s.substring(l, r + 1));

                end = r;
            }
        }

        return result;
    }
}
```

## 7. Understand the Code — Line by Line

### Part A — Create arrays

```
int n = s.length();

int[] first = new int[26];
int[] last = new int[26];

Arrays.fill(first, -1);
```

We create two arrays of size 26.

Initially:

```
first = [-1, -1, -1, ..., -1]
last  = [ 0,  0,  0, ...,  0]
```

Why initialize `first` with `-1`?

Because `-1` means that the character has not appeared yet.

### Part B — Find first and last occurrence

```
for (int i = 0; i < n; i++) {

    int x = s.charAt(i) - 'a';

    if (first[x] == -1) {
        first[x] = i;
    }

    last[x] = i;
}
```

Let's understand:

```
int x = s.charAt(i) - 'a';
```

Converts the character into an array index.

For example:

```
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
```

```
if (first[x] == -1) {
    first[x] = i;
}
```

Stores the first occurrence only once.

```
last[x] = i;
```

Updates the last occurrence every time the character appears.

### Part C — Create the interval list

```
List<int[]> intervals = new ArrayList<>();
```

Each valid substring is represented by an interval:

```
[start index, end index]
```

For example:

```
[1,2]
```

represents the substring from index 1 to index 2.

### Part D — Visit every character

```
for (int x = 0; x < 26; x++) {

    if (first[x] == -1) {
        continue;
    }
```

We examine all 26 characters.

If a character does not appear in the string, skip it.

### Part E — Initialize the candidate interval

```
int l = first[x];
int r = last[x];

int i = l;
```

For each character:

- `l` starts at its first occurrence.
- `r` starts at its last occurrence.
- `i` is used to scan the candidate interval.

Example:

```
Character = a
first[a] = 0
last[a] = 3

l = 0
r = 3
i = 0
```

### Part F — Expand the interval

```
while (i <= r) {

    int y = s.charAt(i) - 'a';

    if (first[y] < l) {
        break;
    }

    r = Math.max(r, last[y]);

    i++;
}
```

This is the most important part of the problem.

We scan all characters inside the current interval.

For each character:

1. Check whether its first occurrence is before `l`.
2. If yes, reject this candidate.
3. Otherwise, extend `r` if necessary.
4. Continue scanning, including any newly added positions.

Why does `r` change during the loop?

Because a character inside the current interval may have its last occurrence farther ahead.

Example:

```
Current interval = [0,3]
Character at index 2 = b
Last occurrence of b = 6
```

Update:

```
r = Math.max(3, 6);
r = 6;
```

Now the loop must also inspect indices 4, 5 and 6.

### Part G — Save only valid intervals

```
if (i > r) {
    intervals.add(new int[]{l, r});
}
```

If the loop completes successfully, all characters inside the interval have all their occurrences included.

Therefore, this is a valid substring.

If the loop breaks because `first[y] < l`, we do not add it.

### Part H — Sort intervals

```
intervals.sort((a, b) ->
    Integer.compare(a[1], b[1])
);
```

Sort by ending index in ascending order.

The interval that finishes earliest comes first.

### Part I — Greedy selection

```
List<String> result = new ArrayList<>();

int end = -1;
```

`end` stores the ending index of the last selected interval.

Initially, no interval has been selected, so `end = -1`.

```
for (int[] interval : intervals) {

    int l = interval[0];
    int r = interval[1];
```

Get the starting and ending positions.

```
if (l > end) {
```

If the current interval starts after the previous selected interval ends, it does not overlap.

```
result.add(s.substring(l, r + 1));
```

Extract the substring.

Remember: Java's `substring(start, end)` excludes the ending index.

Therefore, we use `r + 1`.

```
end = r;
```

Update the ending index of the last selected interval.

### Part J — Return the answer

```
return result;
```

Returns the maximum number of valid non-overlapping substrings with minimum total length.
