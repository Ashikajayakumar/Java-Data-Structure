# LeetCode 1024 — Video Stitching

## 1. Problem Statement

You are given a 2D integer array `clips`, where each interval represents a video clip:

```
clips[i] = [start, end]
```

Each clip covers the video from time `start` to time `end`.

You are also given an integer `time`, representing the total duration of the video you need to create.

Your task is to select the minimum number of clips required to cover the entire video from time `0` to `time`.

Important conditions:

- You can cut clips into smaller pieces.
- You can use overlapping clips.
- The selected clips must cover every moment from `0` to `time` without any gaps.
- If it is impossible to cover the complete duration, return `-1`.

## 2. Example

Input:

```
clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]]
time = 10
```

Output:

```
3
```

Explanation:

We can choose these three clips:

```
[0,2]
[1,9]
[8,10]
```

## 3. Important Points

1. We need to cover the entire interval `[0, time]`.
2. We need the minimum number of clips, not all possible clips.
3. Clips can overlap.
4. We can cut a clip and use only the required portion.
5. We must never leave a gap in the covered duration.
6. If we cannot extend the coverage, return `-1`.

Key observation: At every step, choose the clip that starts within the already-covered range and reaches the farthest possible time.

## 4. Main Concept — Greedy + Interval Coverage

We use three variables to track our progress:

```
int currentEnd = 0;
int farthest = 0;
int count = 0;
```

| Variable     | Meaning                                                           |
| ------------ | ----------------------------------------------------------------- |
| `currentEnd` | The time up to which our selected clips currently cover the video |
| `farthest`   | The maximum ending time reachable using the available clips       |
| `count`      | Number of clips selected                                          |

### Greedy idea

Suppose we have already covered:

```
[0,2]
```

Now we can choose any clip whose starting time is less than or equal to `2`.

For example:

```
[1,5]
[1,9]
[2,6]
```

Which clip should we choose?

We choose `[1,9]` because it extends our coverage the farthest.

```
Current coverage: [0,2]
Best next clip:   [1,9]

New coverage:     [0,9]
```

This is the greedy choice: always extend the current coverage as far as possible.

### Three phases of the algorithm

Phase 1

Sort clips by starting time

This lets us process clips in the order they become available.

Phase 2

Find the farthest reachable endpoint

Consider every clip with `start <= currentEnd` and update:

```
farthest = Math.max(farthest, clips[i][1]);
```

Phase 3

Select a clip or detect a gap

- If `farthest == currentEnd`, we cannot extend coverage. Return `-1`.
- Otherwise, select one clip, increment `count`, and move `currentEnd` to `farthest`.

## 5. Java Solution

```
import java.util.Arrays;

class Solution {
    public int videoStitching(int[][] clips, int time) {

        // Step 1: Sort clips by starting time
        Arrays.sort(clips, (a, b) ->
            Integer.compare(a[0], b[0])
        );

        int count = 0;
        int currentEnd = 0;
        int farthest = 0;

        int i = 0;
        int n = clips.length;

        // Step 2: Continue until the full video is covered
        while (currentEnd < time) {

            // Find the farthest reachable endpoint
            while (i < n && clips[i][0] <= currentEnd) {
                farthest = Math.max(farthest, clips[i][1]);
                i++;
            }

            // No clip can extend the coverage
            if (farthest == currentEnd) {
                return -1;
            }

            // Select one clip
            count++;

            // Extend the current coverage
            currentEnd = farthest;
        }

        return count;
    }
}
```

## 6. Understand the Code — Line by Line

### Part A — Sort clips by starting time

```
Arrays.sort(clips, (a, b) ->
    Integer.compare(a[0], b[0])
);
```

We sort the 2D array based on the starting time.

Example:

Before sorting:

```
[[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]]
```

After sorting:

```
[[0,2],[1,9],[1,5],[4,6],[5,9],[8,10]]
```

Why sort?

Because we need to easily identify which clips can extend our current coverage.

### Part B — Initialize variables

```
int count = 0;
int currentEnd = 0;
int farthest = 0;

int i = 0;
int n = clips.length;
```

Initially:

```
count      = 0
currentEnd = 0
farthest   = 0
i          = 0
```

We have not selected any clips yet, so coverage starts at time `0`.

### Part C — Continue until the video is covered

```
while (currentEnd < time) {
```

If `currentEnd` is smaller than `time`, we still need more clips.

For example:

```
currentEnd = 6
time = 10

6 < 10 → true
```

We must find another clip to extend coverage.

### Part D — Find the farthest reachable endpoint

```
while (i < n && clips[i][0] <= currentEnd) {
    farthest = Math.max(farthest, clips[i][1]);
    i++;
}
```

This is the most important part.

We examine all clips that start within our currently covered range.

Condition:

```
clips[i][0] <= currentEnd
```

Means the clip can connect to our existing coverage.

Then:

```
farthest = Math.max(farthest, clips[i][1]);
```

Keeps the maximum ending time.

Example:

```
currentEnd = 2

Available clips:
[1,5]
[1,9]
[2,6]
```

Updates:

```
farthest = max(0,5) = 5
farthest = max(5,9) = 9
farthest = max(9,6) = 9
```

Final:

```
farthest = 9
```

We can extend coverage from `2` to `9`.

### Part E — Check whether coverage is possible

```
if (farthest == currentEnd) {
    return -1;
}
```

If `farthest` has not increased, no available clip can extend our coverage.

Example:

```
currentEnd = 3
farthest = 3
```

No clip connects to a later time.

Therefore, a gap exists and we return `-1`.

### Part F — Count the selected clip

```
count++;
```

We have found a clip that extends our coverage.

We count one additional clip.

### Part G — Extend the current coverage

```
currentEnd = farthest;
```

We move our current coverage boundary to the farthest reachable endpoint.

Example:

```
Old currentEnd = 2
farthest = 9

New currentEnd = 9
```

Now we need to cover only the remaining duration.

### Part H — Return the answer

```
return count;
```

Once `currentEnd >= time`, the entire video is covered.

Return the minimum number of selected clips.

## 9. What Happens When Coverage Is Impossible?

Consider:

```
clips = [[0,1],[1,2]]
time = 5
```

First iteration:

```
currentEnd = 0
farthest = 1
count = 1
```

Second iteration:

```
currentEnd = 1
farthest = 2
count = 2
```

Third iteration:

```
currentEnd = 2
```

There are no more clips starting at or before `2` that can extend the coverage.

Therefore:

```
farthest = 2
currentEnd = 2
```

Condition:

```
if (farthest == currentEnd)
```

Returns:

```
-1
```

Because the video duration from `2` to `5` cannot be covered.
