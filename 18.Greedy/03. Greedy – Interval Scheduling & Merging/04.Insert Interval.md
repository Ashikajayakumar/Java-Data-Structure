# LeetCode 57 — Insert Interval

## 1. Problem Statement

You are given:

- `intervals`: a list of non-overlapping intervals sorted in ascending order by their starting time.
- `newInterval`: one new interval that you need to insert.

Your task is to insert `newInterval` into `intervals` and merge any overlapping intervals.

Return the final list of intervals. The result must remain sorted, and no two intervals should overlap.

Important: The original intervals are already sorted and non-overlapping. You do not need to sort them again.

## 2. Example

Input:

```
intervals = [[1,3],[6,9]]
newInterval = [2,5]
```

Output:

```
[[1,5],[6,9]]
```

Explanation:

The new interval `[2,5]` overlaps with `[1,3]`.

Merge them:

```
[1,3] + [2,5] = [1,5]
```

The interval `[6,9]` does not overlap, so it remains unchanged.


## 3. Important Points

1. The input intervals are already sorted by starting value.
2. Existing intervals do not overlap each other.
3. The new interval may overlap with zero, one, or multiple intervals.
4. We must preserve the sorted order.
5. If intervals overlap, merge them using:
   ```
   newStart = Math.min(start1, start2);
   newEnd = Math.max(end1, end2);
   ```
6. Intervals that touch at an endpoint are considered overlapping in this problem.

For example:

```
[1,3] and [3,5] → [1,5]
```

## 4. Main Concept — Three Phases

We can solve this problem using a single traversal with three phases.

Phase 1

Add intervals before the new interval

If an interval ends before the new interval starts, add it directly.

```
intervals[i][1] < newInterval[0]
```

Phase 2

Merge overlapping intervals

If an interval starts before or at the new interval's end, merge it.

```
intervals[i][0] <= newInterval[1]
```

Update the new interval's start and end using `Math.min()` and `Math.max()`.

Phase 3

Add the remaining intervals

Once the current interval starts after the new interval ends, add the merged interval and then add all remaining intervals.

## 5. Java Solution

Approach: Three phases using a `while` loop

```
import java.util.*;

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {

        List<int[]> result = new ArrayList<>();

        int i = 0;
        int n = intervals.length;

        // Phase 1: Add intervals before newInterval
        while (i < n && intervals[i][1] < newInterval[0]) {
            result.add(intervals[i]);
            i++;
        }

        // Phase 2: Merge overlapping intervals
        while (i < n && intervals[i][0] <= newInterval[1]) {

            newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
            newInterval[1] = Math.max(newInterval[1], intervals[i][1]);

            i++;
        }

        // Add the merged interval
        result.add(newInterval);

        // Phase 3: Add remaining intervals
        while (i < n) {
            result.add(intervals[i]);
            i++;
        }

        return result.toArray(new int[result.size()][]);
    }
}
```

## 6. Understand the Code — Line by Line

### Part A — Create the result list

```
List<int[]> result = new ArrayList<>();

int i = 0;
int n = intervals.length;
```

- `result` stores the final intervals.
- `i` tracks the current interval.
- `n` stores the total number of existing intervals.

### Part B — Add intervals before the new interval

```
while (i < n && intervals[i][1] < newInterval[0]) {
    result.add(intervals[i]);
    i++;
}
```

Here we check:

```
Current interval end < New interval start
```

If true, the current interval is completely before the new interval. So, we add it directly.

Example:

```
Current interval = [1,2]
New interval     = [4,8]

2 < 4 → true
```

Therefore, `[1,2]` is added without modification.

### Part C — Merge overlapping intervals

```
while (i < n && intervals[i][0] <= newInterval[1]) {

    newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
    newInterval[1] = Math.max(newInterval[1], intervals[i][1]);

    i++;
}
```

This is the most important part.

We check:

```
Current interval start <= New interval end
```

If true, the intervals overlap or touch.

We update:

```
newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
```

This chooses the smaller starting point.

```
newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
```

This chooses the larger ending point.

For example:

```
New interval     = [4,8]
Current interval = [3,5]

New start = min(4,3) = 3
New end   = max(8,5) = 8

Merged interval = [3,8]
```

We continue checking because the merged interval may overlap with more intervals.

### Part D — Add the merged interval

```
result.add(newInterval);
```

After merging all overlapping intervals, add the final merged interval once.

### Part E — Add remaining intervals

```
while (i < n) {
    result.add(intervals[i]);
    i++;
}
```

All remaining intervals start after the merged interval ends.

Since the original array is already sorted and non-overlapping, we can add them directly.

### Part F — Convert the list into a 2D array

```
return result.toArray(new int[result.size()][]);
```

LeetCode expects an `int[][]`, but we used an `ArrayList<int[]>` to build the answer.

This converts the list into the required 2D array.
