# LeetCode 56 – Merge Intervals

## 1. Problem Statement

You are given an array of intervals.

Each interval contains two values:

```
intervals[i] = [start, end]
```

Your task is to merge all overlapping intervals and return an array containing only the non-overlapping intervals.

What does merging mean?

If two intervals overlap, combine them into one interval.

For example:

```
[1,3] and [2,6]
```

These intervals overlap because the second interval starts before the first one ends.

Merge them:

```
[1,6]
```

## 2. Examples

Example 1

```
Input:
intervals = [[1,3], [2,6], [8,10], [15,18]]

Output:
[[1,6], [8,10], [15,18]]
```

Explanation:

- `[1,3]` and `[2,6]` overlap → merge into `[1,6]`.
- `[8,10]` does not overlap with `[1,6]`.
- `[15,18]` does not overlap with `[8,10]`.

Before merging

[1,3]

[2,6]

After merging

3 merged intervals

Example 2

```
Input:
intervals = [[1,4], [4,5]]

Output:
[[1,5]]
```

Explanation:

The intervals touch at coordinate 4.

For this problem, touching intervals are considered overlapping and should be merged.

Example 3

```
Input:
intervals = [[4,7], [1,4]]

Output:
[[1,7]]
```

Explanation:

After sorting:

```
[1,4], [4,7]
```

They overlap at coordinate 4, so merge them.

## 3. Important Points

Before writing the code, understand these observations:

1. Every interval contains a start and an end.
2. We need to combine overlapping intervals.
3. Sorting by starting coordinate makes it easier to find overlaps.
4. If the next interval starts before or at the current end, merge them.
5. If the next interval starts after the current end, save the current interval and start a new one.

Most important condition:

```
currentStart <= previousEnd
```

This means the intervals overlap or touch.

## 4. Main Concept – Greedy + Sorting

We use two concepts:

- Sorting: Arrange intervals by starting coordinate.
- Greedy: Merge an interval immediately whenever it overlaps with the current interval.

Why sort by starting coordinate?

Consider:

```
[[8,10], [1,3], [2,6], [15,18]]
```

It is difficult to identify the correct merging order without sorting.

After sorting:

```
[[1,3], [2,6], [8,10], [15,18]]
```

Now we can process intervals from left to right.

### How merging works

Consider:

```
Current interval = [1,3]
Next interval    = [2,6]
```

Check:

```
2 <= 3
```

True!

So merge:

```
newStart = 1
newEnd = Math.max(3, 6);
```

Result:

```
[1,6]
```

Why use `Math.max()`?

Because we must preserve the farthest ending coordinate.

For example:

```
Current = [1,10]
Next    = [2,5]
```

The merged interval must remain `[1,10]`, not `[1,5]`.

## 5. Main Logic – Step by Step

### Step 1: Sort intervals by starting coordinate

```
Arrays.sort(intervals, (a, b) ->
    Integer.compare(a[0], b[0]));
```

We compare `a[0]` and `b[0]`.

Here:

```
a[0] = First interval's start
b[0] = Second interval's start
```

### Step 2: Create a list to store merged intervals

```
List<int[]> result = new ArrayList<>();
```

This list stores the final merged intervals.

### Step 3: Start with the first interval

```
int[] current = intervals[0];
```

We initially assume the first interval is part of our result.

### Step 4: Traverse remaining intervals

```
for (int i = 1; i < intervals.length; i++)
```

We start at index 1 because index 0 is already selected.

### Step 5: Check for overlap

```
if (intervals[i][0] <= current[1])
```

Meaning:

```
Next interval start <= Current interval end
```

If true, merge:

```
current[1] = Math.max(current[1], intervals[i][1]);
```

### Step 6: If there is no overlap

```
else {
    result.add(current);
    current = intervals[i];
}
```

- Save the completed current interval.
- Start processing the next interval.

### Step 7: Add the final interval

After the loop finishes, we must add the last current interval:

```
result.add(current);
```

### Step 8: Convert the list into a 2D array

```
return result.toArray(new int[result.size()][]);
```

LeetCode expects the answer as `int[][]`, so we convert our list into a 2D array.

## 6. Java Solution

Recommended Solution

```
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {

        // Sort intervals by starting coordinate
        Arrays.sort(intervals, (a, b) ->
            Integer.compare(a[0], b[0]));

        // Store merged intervals
        List<int[]> result = new ArrayList<>();

        // Start with the first interval
        int[] current = intervals[0];

        // Traverse remaining intervals
        for (int i = 1; i < intervals.length; i++) {

            // Check if intervals overlap
            if (intervals[i][0] <= current[1]) {

                // Merge intervals
                current[1] = Math.max(
                    current[1],
                    intervals[i][1]
                );

            } else {

                // Save the completed interval
                result.add(current);

                // Start a new interval
                current = intervals[i];
            }
        }

        // Add the last interval
        result.add(current);

        // Convert List into 2D array
        return result.toArray(new int[result.size()][]);
    }
}
```

```

```

Sort by starting coordinate in ascending order.

Example:

```
Before:
[[8,10], [1,3], [2,6], [15,18]]

After:
[[1,3], [2,6], [8,10], [15,18]]
```

Part B – Create result list

```
List<int[]> result = new ArrayList<>();
```

This stores the merged intervals.

Initially:

```
result = []
```

Part C – Select the first interval

```
int[] current = intervals[0];
```

Initially:

```
current = [1,3]
```

Think of `current` as the interval we are currently building.

Part D – Loop

```
for (int i = 1; i < intervals.length; i++)
```

We process the remaining intervals one by one.

Part E – Overlap condition

```
if (intervals[i][0] <= current[1])
```

Example:

```
Current = [1,3]
Next    = [2,6]
```

Check:

```
2 <= 3 → true
```

They overlap.

Part F – Merge

```
current[1] = Math.max(
    current[1],
    intervals[i][1]
);
```

Here:

```
current[1] = 3
next[1]    = 6
```

So:

```

```

Now:

```

```

Part G – No overlap

```
else {
    result.add(current);
```

When there is no overlap:

1. Add the completed interval to the result.
