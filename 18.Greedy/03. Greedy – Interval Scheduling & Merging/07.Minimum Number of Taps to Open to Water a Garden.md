# LeetCode 1326 — Minimum Number of Taps to Open to Water a Garden


## 1. Problem Statement

You are given:

- An integer `n`, representing a garden from position `0` to position `n`.
- An integer array `ranges`, where `ranges[i]` represents how far tap `i` can water in both directions.

There are `n + 1` taps, located at positions:

```
0, 1, 2, 3, ..., n
```

Each tap can water a continuous interval.

For a tap at position `i`, its watering interval is:

```
[i - ranges[i], i + ranges[i]]
```

Your task is to find the minimum number of taps needed to water the entire garden from `0` to `n`.

If it is impossible to water the entire garden, return `-1`.

## 2. Example

Input:

```
n = 5
ranges = [3,4,1,1,0,0]
```

Output:

```
1
```

Explanation:

Tap positions and watering ranges:

| Tap position | Range | Watering interval |
| ------------ | ----- | ----------------- |
| 0            | 3     | `[-3,3]`          |
| 1            | 4     | `[-3,5]`          |
| 2            | 1     | `[1,3]`           |
| 3            | 1     | `[2,4]`           |
| 4            | 0     | `[4,4]`           |
| 5            | 0     | `[5,5]`           |

Tap 1 can water from `-3` to `5`.

The required garden is only from `0` to `5`.

Therefore, opening tap 1 alone is sufficient.

5

1 tap is sufficient

Tap 1 covers the entire required garden [0,5].

## 3. Important Points

1. There are `n + 1` taps, from position `0` to position `n`.
2. Every tap covers an interval, not just one point.
3. The watering interval of tap `i` is:
   ```
   [i - ranges[i], i + ranges[i]]
   ```
4. We only need to cover the garden from `0` to `n`.
5. A tap's watering range may extend outside the garden, so we can limit it to `[0,n]`.
6. We need the minimum number of taps.
7. If there is a gap that no tap can cover, return `-1`.

Key observation: This is an interval coverage problem, just like Video Stitching (LC 1024).

## 4. Main Concept — Convert Taps into Intervals

Before applying Greedy, convert every tap into its watering interval.

Formula:

\\[ left = \max(0, i-ranges[i]) \\]

\\[ right = \min(n, i+ranges[i]) \\]

For example:

```
n = 5
ranges = [3,4,1,1,0,0]
```

Tap 1:

```
Position = 1
Range = 4

left  = max(0, 1 - 4) = 0
right = min(5, 1 + 4) = 5

Interval = [0,5]
```

Now the problem becomes:

```
Find the minimum number of intervals
needed to cover [0,n].
```

### Step A — Create a `maxReach` array

Instead of storing and sorting all intervals, we can use an array of size `n + 1`.

```
int[] maxReach = new int[n + 1];
```

`maxReach[left]` stores the farthest right endpoint among all taps that start watering at `left`.

For every tap:

```
maxReach[left] = Math.max(maxReach[left], right);
```

Why use `Math.max()`?

Because multiple taps may start at the same left position. We only need to remember the one that reaches farthest.

### Step B — Greedy coverage

We use three variables:

```
int taps = 0;
int currentEnd = 0;
int farthest = 0;
```

| Variable     | Meaning                                          |
| ------------ | ------------------------------------------------ |
| `taps`       | Number of taps selected                          |
| `currentEnd` | End of the currently covered garden              |
| `farthest`   | Farthest position reachable using available taps |

At each position, update:

```
farthest = Math.max(farthest, maxReach[i]);
```

When we reach the end of the current coverage:

```
if (i == currentEnd)
```

we must select another tap to extend coverage.

If no extension is possible:

```
if (farthest == currentEnd) {
    return -1;
}
```

Otherwise:

```
taps++;
currentEnd = farthest;
```

This is the same greedy boundary-expansion idea used in Video Stitching.

## 5. Java Solution

```
class Solution {
    public int minTaps(int n, int[] ranges) {

        // Step 1: Store the farthest reach for each starting position
        int[] maxReach = new int[n + 1];

        for (int i = 0; i <= n; i++) {

            int left = Math.max(0, i - ranges[i]);
            int right = Math.min(n, i + ranges[i]);

            maxReach[left] = Math.max(maxReach[left], right);
        }

        // Step 2: Apply Greedy
        int taps = 0;
        int currentEnd = 0;
        int farthest = 0;

        for (int i = 0; i < n; i++) {

            farthest = Math.max(farthest, maxReach[i]);

            // We must select another tap
            if (i == currentEnd) {

                // Cannot extend coverage
                if (farthest == currentEnd) {
                    return -1;
                }

                taps++;
                currentEnd = farthest;

                // Entire garden is covered
                if (currentEnd >= n) {
                    return taps;
                }
            }
        }

        return taps;
    }
}
```

## 6. Understand the Code — Line by Line

### Part A — Create the array

```
int[] maxReach = new int[n + 1];
```

This array stores the farthest watering endpoint for each starting position.

Example:

```
maxReach[0] = 5
```

Means there is a tap whose watering interval starts at position `0` and reaches position `5`.

### Part B — Convert every tap into an interval

```
for (int i = 0; i <= n; i++) {
```

We visit every tap, including the tap at position `n`.

```
int left = Math.max(0, i - ranges[i]);
```

Calculates the left endpoint.

We use `Math.max(0, ...)` because the garden begins at position `0`.

```
int right = Math.min(n, i + ranges[i]);
```

Calculates the right endpoint.

We use `Math.min(n, ...)` because the garden ends at position `n`.

### Part C — Store the farthest endpoint

```
maxReach[left] = Math.max(maxReach[left], right);
```

If multiple taps start at the same position, keep the one that reaches farthest.

For example:

```
Tap A = [0,3]
Tap B = [0,5]

maxReach[0] = max(3,5)
            = 5
```

### Part D — Initialize Greedy variables

```
int taps = 0;
int currentEnd = 0;
int farthest = 0;
```

Initially:

```
taps = 0
currentEnd = 0
farthest = 0
```

We have not selected any taps yet.

### Part E — Traverse the garden

```
for (int i = 0; i < n; i++) {
```

We traverse positions from `0` to `n - 1`.

```
farthest = Math.max(farthest, maxReach[i]);
```

Find the farthest endpoint reachable using intervals that begin at or before the current position.

### Part F — Check the current coverage boundary

```
if (i == currentEnd) {
```

This means we have reached the end of the coverage provided by the taps already selected.

We must now select another tap to extend the coverage.

### Part G — Check whether extension is possible

```
if (farthest == currentEnd) {
    return -1;
}
```

If `farthest` has not increased, there is no tap that can extend the current coverage.

Therefore, the entire garden cannot be watered.

### Part H — Select another tap

```
taps++;
currentEnd = farthest;
```

We select one additional tap and extend the coverage as far as possible.

```
if (currentEnd >= n) {
    return taps;
}
```

If we have reached the garden's end, return the number of taps selected.
