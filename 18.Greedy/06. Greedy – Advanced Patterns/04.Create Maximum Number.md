# LeetCode 321 — Create Maximum Number


## 1. Problem Statement

You are given two integer arrays:

- `nums1` of length `m`
- `nums2` of length `n`

You are also given an integer `k`.

Your task is to create the maximum possible number of length `k` by selecting digits from both arrays.

### Important rules

1. You must select exactly `k` digits in total.
2. The relative order of selected digits from each original array must remain unchanged.
3. You can combine digits from both arrays in any order that respects their individual relative orders.
4. Return the lexicographically largest possible sequence.

What does lexicographically largest mean?

Compare two sequences from left to right. At the first position where they differ, the sequence with the larger digit is greater.

## 2. Examples

Example 1

```
Input:
nums1 = [3, 4, 6, 5]
nums2 = [9, 1, 2, 5, 8, 3]
k = 5

Output:
[9, 8, 6, 5, 3]
```

Explanation:

One optimal selection is:

- From `nums1`: `[6, 5]`
- From `nums2`: `[9, 8, 3]`

Merge them while preserving the order inside each selected sequence:

```
nums1 selected: [6, 5]
nums2 selected: [9, 8, 3]

Maximum result: [9, 8, 6, 5, 3]
```

Example 2

```
Input:
nums1 = [6, 7]
nums2 = [6, 0, 4]
k = 5

Output:
[6, 7, 6, 0, 4]
```

Explanation: All five digits must be selected, and their original relative order is preserved.

Example 3

```
Input:
nums1 = [3, 9]
nums2 = [8, 9]
k = 3

Output:
[9, 8, 9]
```

One optimal choice is `[9]` from `nums1` and `[8, 9]` from `nums2`.

## 3. Important Points

This problem combines three important techniques:

| Technique                | Purpose                                                   |
| ------------------------ | --------------------------------------------------------- |
| Greedy + Monotonic Stack | Select the maximum subsequence from each array            |
| Enumerating splits       | Decide how many digits to select from `nums1` and `nums2` |
| Greedy Merge             | Combine both subsequences to get the maximum result       |

The most important observation:

We cannot simply take the largest `k` digits from both arrays. We must preserve the relative order of digits in each original array.

For example:

```
nums1 = [3, 9, 2]
```

Selecting `[9, 3]` is invalid because it changes the original order. We can select `[3, 9]` or `[3, 2]` or `[9, 2]`, but not `[9, 3]`.

## 4. Main Concepts / Approach

We divide the problem into three steps.

### Step 1: Try every possible split

Suppose:

```
nums1 = [3, 4, 6, 5]
nums2 = [9, 1, 2, 5, 8, 3]
k = 5
```

We need to select exactly 5 digits.

Possible selections from `nums1`:

| From nums1 | From nums2 |
| ---------- | ---------- |
| 0          | 5          |
| 1          | 4          |
| 2          | 3          |
| 3          | 2          |
| 4          | 1          |

For every valid split:

1. Find the maximum subsequence from `nums1`.
2. Find the maximum subsequence from `nums2`.
3. Merge both subsequences to form the maximum possible sequence for that split.
4. Compare it with the best answer found so far.

The valid number of digits selected from `nums1` ranges from:

\\[ \max(0,k-n) \quad \text{to} \quad \min(k,m) \\]

Here, `m` is the length of `nums1`, and `n` is the length of `nums2`.

### Step 2: Find the maximum subsequence using a monotonic stack

We need to select a fixed number of digits while preserving their order.

Greedy rule:

- Prefer a larger digit over a smaller digit.
- If the current digit is larger than the last selected digit, remove the smaller digit if we still have enough remaining digits to complete the required length.
- Continue until the required number of digits is selected.

Example:

```
nums = [3, 4, 6, 5]
Required length = 2
```

Dry run:

| Current digit | Stack before | Action          | Stack after |
| ------------- | ------------ | --------------- | ----------- |
| 3             | `[]`         | Add 3           | `[3]`       |
| 4             | `[3]`        | Remove 3, add 4 | `[4]`       |
| 6             | `[4]`        | Remove 4, add 6 | `[6]`       |
| 5             | `[6]`        | Add 5           | `[6,5]`     |

Maximum subsequence:

```
[6, 5]
```

Why do we remove smaller digits?

Because a larger digit at an earlier position makes the resulting number larger.

### Step 3: Merge both subsequences

Suppose:

```
A = [6, 5]
B = [9, 8, 3]
```

Compare the remaining suffixes:

```
A: [6, 5]
B: [9, 8, 3]
```

Since `9 > 6`, select `9`.

Continue comparing:

```
A: [6, 5]
B: [8, 3]
```

Since `8 > 6`, select `8`.

Then:

```
A: [6, 5]
B: [3]
```

Since `6 > 3`, select `6`.

Finally:

```
A: [5]
B: [3]
```

Select `5`, then `3`.

Result:

```
[9, 8, 6, 5, 3]
```

Important: When the current digits are equal, compare the entire remaining suffixes. Do not automatically choose from either array.

For example:

```
A = [6, 7]
B = [6, 0, 4]
```

Both begin with `6`, but:

```
A remaining: [6, 7]
B remaining: [6, 0, 4]
```

At the next position, `7 > 0`, so choose from `A` first.

This suffix comparison is essential for getting the correct answer.

## 5. Main Logic — Step by Step

```
Start
  |
  v
Calculate valid split range
  |
  v
For every possible split:
  |
  +--> Select maximum subsequence from nums1
  |
  +--> Select maximum subsequence from nums2
  |
  +--> Merge both subsequences
  |
  +--> Compare with best answer
  |
  v
Return maximum answer
```

## 6. Java Solution

Complete LeetCode solution

```
class Solution {

    public int[] maxNumber(int[] nums1, int[] nums2, int k) {

        int m = nums1.length;
        int n = nums2.length;

        int[] best = new int[k];

        // Try every valid split
        for (int i = Math.max(0, k - n);
             i <= Math.min(k, m); i++) {

            // Select maximum subsequences
            int[] a = maxSubsequence(nums1, i);
            int[] b = maxSubsequence(nums2, k - i);

            // Merge both subsequences
            int[] candidate = merge(a, b, k);

            // Keep the maximum result
            if (greater(candidate, 0, best, 0)) {
                best = candidate;
            }
        }

        return best;
    }

    // Find maximum subsequence of required length
    private int[] maxSubsequence(int[] nums, int k) {

        int[] stack = new int[k];

        int top = 0;
        int remove = nums.length - k;

        for (int i = 0; i < nums.length; i++) {

            while (top > 0 &&
                   remove > 0 &&
                   stack[top - 1] < nums[i]) {

                top--;
                remove--;
            }

            if (top < k) {
                stack[top] = nums[i];
                top++;
            } else {
                remove--;
            }
        }

        return stack;
    }

    // Merge two subsequences to form maximum number
    private int[] merge(int[] a, int[] b, int k) {

        int[] result = new int[k];

        int i = 0;
        int j = 0;

        for (int r = 0; r < k; r++) {

            if (greater(a, i, b, j)) {
                result[r] = a[i];
                i++;
            } else {
                result[r] = b[j];
                j++;
            }
        }

        return result;
    }

    // Compare remaining suffixes lexicographically
    private boolean greater(int[] a, int i,
                            int[] b, int j) {

        while (i < a.length && j < b.length &&
               a[i] == b[j]) {

            i++;
            j++;
        }

        if (j == b.length) {
            return true;
        }

        if (i == a.length) {
            return false;
        }

        return a[i] > b[j];
    }
}
```

## 7. Understand the Code — Part by Part

### Part A: Try every valid split

```
int m = nums1.length;
int n = nums2.length;

int[] best = new int[k];

for (int i = Math.max(0, k - n);
     i <= Math.min(k, m); i++) {

    int[] a = maxSubsequence(nums1, i);
    int[] b = maxSubsequence(nums2, k - i);

    int[] candidate = merge(a, b, k);

    if (greater(candidate, 0, best, 0)) {
        best = candidate;
    }
}
```

- `m` stores the length of the first array.
- `n` stores the length of the second array.
- `best` stores the maximum sequence found so far.
- `i` represents how many digits we select from `nums1`.
- `k - i` represents how many digits we select from `nums2`.
- `maxSubsequence()` selects the best digits from each array.
- `merge()` combines the two selected subsequences.
- `greater()` checks whether the new candidate is better than the current answer.

### Part B: Maximum subsequence

```
private int[] maxSubsequence(int[] nums, int k) {

    int[] stack = new int[k];

    int top = 0;
    int remove = nums.length - k;

    for (int i = 0; i < nums.length; i++) {

        while (top > 0 &&
               remove > 0 &&
               stack[top - 1] < nums[i]) {

            top--;
            remove--;
        }

        if (top < k) {
            stack[top] = nums[i];
            top++;
        } else {
            remove--;
        }
    }

    return stack;
}
```

Important variables:

| Variable | Meaning                                    |
| -------- | ------------------------------------------ |
| `stack`  | Stores selected digits                     |
| `top`    | Number of digits currently selected        |
| `remove` | Number of digits we are allowed to discard |
| `i`      | Current input-array index                  |

Why `remove = nums.length - k`?

If the input has 4 digits and we need only 2, we must discard exactly:

\\[ 4-2=2 \\]

digits.

Why `stack[top - 1] < nums[i]`?

If the current digit is greater than the last selected digit, removing the smaller digit can improve the resulting number.

Why `top < k`?

We must never store more than `k` digits.

Why do we use `else { remove--; }`?

If the stack is already full and we cannot remove another digit, we discard the current digit instead.

### Part C: Merge

```
private int[] merge(int[] a, int[] b, int k) {

    int[] result = new int[k];

    int i = 0;
    int j = 0;

    for (int r = 0; r < k; r++) {

        if (greater(a, i, b, j)) {
            result[r] = a[i];
            i++;
        } else {
            result[r] = b[j];
            j++;
        }
    }

    return result;
}
```

- `i` points to the current digit in the first subsequence.
- `j` points to the current digit in the second subsequence.
- `r` points to the position being filled in the result.
- `greater()` compares the remaining digits, not just the current digits.
- The larger remaining suffix is selected first.

### Part D: Compare remaining suffixes

```
private boolean greater(int[] a, int i,
                        int[] b, int j) {

    while (i < a.length && j < b.length &&
           a[i] == b[j]) {

        i++;
        j++;
    }

    if (j == b.length) {
        return true;
    }

    if (i == a.length) {
        return false;
    }

    return a[i] > b[j];
}
```

This method answers:

Should we select the next digit from array `a` or array `b`?

Example:

```
a = [6, 7]
b = [6, 0, 4]
```

Comparison:

| Position | Array A | Array B | Result           |
| -------- | ------- | ------- | ---------------- |
| 0        | 6       | 6       | Equal — continue |
| 1        | 7       | 0       | A is greater     |

Therefore, select from `a`.

Special cases:

- If both suffixes are equal but `b` finishes first, choose `a`.
- If `a` finishes first, choose `b`.
- If both finish together, either choice gives the same remaining sequence.
