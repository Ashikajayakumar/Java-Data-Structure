## 1. Problem Statement

You are given:

- A sorted integer array `nums`.
- An integer `n`.

You can add new numbers to the array. These added numbers are called patches.

Your task is to find the minimum number of patches required so that every number from `1` to `n` can be formed using the sum of some elements from the array.

Each array element can be used at most once in a sum.

Return the minimum number of patches required.

In simple words:

We need to fill the missing numbers in the possible subset sums by adding as few numbers as possible.

## 2. Examples

Example 1

```
Input:
nums = [1,3]
n = 6

Output:
1
```

Explanation:

Initially, we have:

```
nums = [1,3]
```

Possible sums:

| Combination | Sum |
| ----------- | --- |
| [1]         | 1   |
| [3]         | 3   |
| [1,3]       | 4   |

We can form:

```
1, 3, 4
```

But we cannot form `2`.

So, add `2` as a patch.

```
Updated array = [1,2,3]
```

Now possible sums include:

```
1, 2, 3, 4, 5, 6
```

All numbers from 1 to 6 can be formed.

Therefore:

```
Output = 1
```

Example 2

```

Explanation:

We need to add:

```
Patches = [2,4]
```

Updated array:

```
[1,2,4,5,10]
```

Now every number from 1 to 20 can be formed.

Example 3

```
Input:

Output = 0
```

## 3. Important Points

1. The input array is already sorted in ascending order.
2. Every number from `1` to `n` must be representable.
3. We can use each element only once in a subset sum.
4. We need the minimum number of additional elements.
5. `n` can be very large, up to \\(2^{31}-1\\).

Important observation:

Instead of generating every possible subset sum, we only track the smallest positive number that we cannot form.

We call this variable:

```
miss
```

This is the most important concept in this problem.

## 4. Main Concepts / Approach

### A. Greedy Algorithm

At every step, we decide whether to:

- Use the next available array element.
- Add a new patch.

Our goal is to extend the range of numbers that can be formed as much as possible.

### B. Range Coverage

Suppose we can already form every number in this range:

```
[1, 5]
```

The next missing number is:

```
6
```

So:

```
miss = 6
```

This means:

```
Can form:       1, 2, 3, 4, 5
Cannot form:    6
```

Now there are two possibilities.

Case 1 — Next array number is less than or equal to `miss`

Suppose the next number is `4`.

```
miss = 6
next number = 4
```

We can safely use 4.

Previously, we could form:

```
1, 2, 3, 4, 5
```

After adding 4, we can also form:

```
5, 6, 7, 8, 9
```

Together, we can form:

```
1 to 9
```

So update:

```
miss = miss + nums[i];
```

Now:

```
miss = 6 + 4 = 10
```

Case 2 — Next array number is greater than `miss`

Suppose:

```
miss = 6
next number = 10
```

We cannot form 6 using the existing numbers.

So we must add a patch.

Which number should we add?

The best choice is exactly:

```
patch = miss
```

That means:

```
patch = 6
```

Previously, we could form:

```
1 to 5
```

After adding 6, we can form:

```
1 to 11
```

Therefore:

```
miss = miss * 2;
```

Now:

```
miss = 12
```

The two greedy decisions

Use existing number

If `nums[i] <= miss`:

```
miss += nums[i];
i++;
```

Add a patch

Otherwise:

```
miss += miss;
patches++;
```

## 5. Main Logic — Step by Step

We need three variables.

```
int miss = 1;
int i = 0;
int patches = 0;
```

| Variable  | Purpose                                        |
| --------- | ---------------------------------------------- |
| `miss`    | Smallest positive number that cannot be formed |
| `i`       | Current index in `nums`                        |
| `patches` | Number of patches added                        |

Step 1 — Initialize `miss`

```
int miss = 1;
```

Initially, we cannot form any positive number.

So the smallest missing number is 1.

Step 2 — Continue until coverage reaches `n`

```
while (miss <= n)
```

If `miss` becomes greater than `n`, all numbers from 1 to `n` are covered.

Step 3 — Check whether the next array element can extend coverage

```
if (i < nums.length && nums[i] <= miss)
```

If the next array number is less than or equal to `miss`, use it.

```
miss += nums[i];
i++;
```

Step 4 — Otherwise, add a patch

```
else {
    miss += miss;
    patches++;
}
```

The optimal patch is `miss` itself.

Step 5 — Return the answer

```
return patches;
```

## 6. Java Solution

Optimal Greedy Solution

```
class Solution {
    public int minPatches(int[] nums, int n) {

        long miss = 1;

        int i = 0;
        int patches = 0;

        while (miss <= n) {

            // Use existing number if possible
            if (i < nums.length && nums[i] <= miss) {

                miss += nums[i];

                i++;
            }

            // Otherwise, add a patch
            else {

                miss = miss * 2;

                patches++;
            }
        }

        return patches;
    }
}
```

Important Java detail: We use `long` for `miss` because `n` can be as large as `2,147,483,647`. Doubling `miss` may exceed the maximum value of an `int`.

## 7. Understand the Code

Part A — Initialize variables

```
long miss = 1;

int i = 0;
int patches = 0;
```

Initially:

```
miss = 1
i = 0
patches = 0
```

We cannot form 1 yet.

Part B — While loop

```
while (miss <= n)
```

We continue until the smallest missing number becomes greater than `n`.

Example:

```
n = 6
miss = 7
```

We can already form every number from 1 to 6.

So the loop stops.

Part C — Check the existing array element

```
if (i < nums.length && nums[i] <= miss)
```

There are two conditions:

1. `i < nums.length` ensures that an unused array element exists.
2. `nums[i] <= miss` ensures that the number does not create a gap in our coverage.

Part D — Extend the range

```
miss += nums[i];

i++;
```

Example:

```
miss = 4
nums[i] = 3
```

Previously, we could form 1, 2, 3.

After using 3, we can form every number from 1 to 6.

So:

```
miss = 4 + 3 = 7
```

Part E — Add a patch

```
else {
    miss = miss * 2;
    patches++;
}
```

If the next array element is too large, we patch the missing number itself.

Example:

```
miss = 5
```

Add patch 5.

Now coverage extends from 1–4 to 1–9.

Therefore:

```
miss = 10
patches = 1
```

Part F — Return patches

```
return patches;
```

We return only the number of patches, not the modified array.

## 8. Complete Dry Run

Let's take Example 1.

Input

```

### Iteration 1

Current values:

```

```

```

```

True.

Use the existing number 1.

```
miss += nums[i];
i++;
```

Updated:

```
miss = 1 + 1 = 2
i = 1
patches = 0
```

Coverage:

```
[1,1]
```

We can form 1.

### Iteration 2

Current values:

```
nums[i] = 3
miss = 2
```

Check:

```
3 <= 2
```

False.

We cannot form 2.

So add patch 2.

```
miss = miss * 2;
patches++;
```

Updated:

```
miss = 2 * 2 = 4
patches = 1
```

Coverage:

```
[1,3]
```

We can form 1, 2, 3.

### Iteration 3

Current values:

```
nums[i] = 3
miss = 4
```

Check:

```
3 <= 4
```

True.

Use existing number 3.

```
miss += nums[i];
i++;
```

Updated:

```
miss = 4 + 3 = 7
i = 2
patches = 1
```

Coverage:

```
[1,6]
```

Now:

```
miss = 7
n = 6
```

Since:

```
7 > 6
```

The loop stops.

Final answer:

```
1
```
