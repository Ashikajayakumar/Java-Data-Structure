# LeetCode 406 — Queue Reconstruction by Height


## 1. Problem Statement

You are given a 2D integer array `people`.

Each person is represented by two values:

```
[height, k]
```

- `height` = height of the person.
- `k` = number of people standing in front of this person whose height is greater than or equal to their height.

Your task is to reconstruct the original queue so that every person's `k` condition is satisfied.

Return the reconstructed queue.

## 2. Example

Example 1

```
Input:
people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]

Output:
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

Explanation:

Let's understand the output:

```
Position    Person
   0        [5,0]
   1        [7,0]
   2        [5,2]
   3        [6,1]
   4        [4,4]
   5        [7,1]
```

Check each person:

| Person | People in front with height ≥ their height | Required `k` |
| ------ | ------------------------------------------ | ------------ |
| [5,0]  | 0                                          | 0            |
| [7,0]  | 0                                          | 0            |
| [5,2]  | 2                                          | 2            |
| [6,1]  | 1                                          | 1            |
| [4,4]  | 4                                          | 4            |
| [7,1]  | 1                                          | 1            |

Every person's condition is satisfied.

Example 2

```
Input:
people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]

Output:
[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]
```

## 3. Important Points

Before coding, understand these observations:

1. A taller person affects the `k` value of a shorter person standing behind them.
2. A shorter person does not affect the `k` value of a taller person.
3. People with the same height must be handled in increasing order of `k`.
4. We need to reconstruct the queue, not simply sort it.

Important greedy observation:

Place taller people first, then insert shorter people at their required positions.

Why?

When we process a person, everyone already placed is taller than or equal to that person. Therefore, inserting that person at index `k` gives exactly `k` taller-or-equal people in front.

## 4. Main Concepts / Approach

We use two main concepts:

### A. Sorting — tallest person first

Sort using two conditions:

1. Height in descending order.
2. If heights are equal, `k` in ascending order.

Example:

```
Before sorting:
[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]

After sorting:
[[7,0],[7,1],[6,1],[5,0],[5,2],[4,4]]
```

Why this order?

- First, place the tallest people.
- Then place shorter people.
- For equal heights, place the person who needs fewer people in front first.

### B. ArrayList insertion

We create an empty list:

```
List<int[]> queue = new ArrayList<>();
```

For every person `[height, k]`, insert them at index `k`.

```
queue.add(k, person);
```

For example:

```
Current queue:
[[7,0], [7,1]]

New person:
[6,1]
```

Insert `[6,1]` at index `1`:

```
Before:
Index  0       1
      [7,0]  [7,1]

After:
Index  0       1       2
      [7,0]  [6,1]  [7,1]
```

Now `[6,1]` has exactly one person of height greater than or equal to 6 in front.

## 5. Main Logic — Step by Step

Our algorithm has four steps.

Step 1 — Sort the people

```
Arrays.sort(people, (a, b) -> {
    if (a[0] == b[0]) {
        return Integer.compare(a[1], b[1]);
    }
    return Integer.compare(b[0], a[0]);
});
```

Step 2 — Create an empty queue

```
List<int[]> queue = new ArrayList<>();
```

Step 3 — Insert each person at index `k`

```
for (int i = 0; i < people.length; i++) {
    int[] person = people[i];
    int k = person[1];

    queue.add(k, person);
}
```

Step 4 — Convert the list into a 2D array

```
return queue.toArray(new int[queue.size()][]);
```

## 6. Java Solution

Greedy + Sorting + Insertion

```
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] reconstructQueue(int[][] people) {

        // Sort by height descending
        // If heights are equal, sort k ascending
        Arrays.sort(people, (a, b) -> {
            if (a[0] == b[0]) {
                return Integer.compare(a[1], b[1]);
            }
            return Integer.compare(b[0], a[0]);
        });

        // Create an empty queue
        List<int[]> queue = new ArrayList<>();

        // Insert each person at index k
        for (int i = 0; i < people.length; i++) {

            int[] person = people[i];

            int k = person[1];

            queue.add(k, person);
        }

        // Convert ArrayList into 2D array
        return queue.toArray(new int[queue.size()][]);
    }
}
```

## 7. Understand the Code

Part A — Import packages

```
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;
```

- `Arrays` → used for sorting.
- `ArrayList` → used for insertion at a particular index.
- `List` → used as the reference type for our result.

Part B — Sorting

```
Arrays.sort(people, (a, b) -> {
    if (a[0] == b[0]) {
        return Integer.compare(a[1], b[1]);
    }
    return Integer.compare(b[0], a[0]);
});
```

Remember:

```
a[0] = height
a[1] = k
```

If heights are equal:

```
Integer.compare(a[1], b[1])
```

Sort `k` in ascending order.

Otherwise:

```
Integer.compare(b[0], a[0])
```

Sort height in descending order.

Part C — Create the result list

```
List<int[]> queue = new ArrayList<>();
```

Initially:

```
queue = []
```

We gradually reconstruct the queue.

Part D — Traverse the sorted array

```
for (int i = 0; i < people.length; i++) {
    int[] person = people[i];
}
```

We process every person in the sorted order.

Part E — Get the required position

```
int k = person[1];
```

For `[6,1]`:

```
height = 6
k = 1
```

This person needs exactly one person of height greater than or equal to 6 in front.

Part F — Insert the person

```
queue.add(k, person);
```

This inserts the person at index `k`.

All previously inserted people have heights greater than or equal to the current person's height. So the insertion position satisfies the person's condition.

Part G — Return the answer

```
return queue.toArray(new int[queue.size()][]);
```

LeetCode expects a 2D integer array, so we convert the `ArrayList` into `int[][]`.
