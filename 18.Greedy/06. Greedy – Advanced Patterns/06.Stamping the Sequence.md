# LeetCode 936 — Stamping the Sequence

Greedy + Reverse Simulation + String | Hard

## 1. Problem Statement

You are given two strings:

- `stamp` — the string used to overwrite characters.
- `target` — the string that you need to create.

Initially, you have a string `s` of length `target.length()` containing only question marks (`?`).

In each operation:

1. Choose a valid starting index.
2. Place `stamp` at that index.
3. Replace the characters in that section with the characters of `stamp`.

Your task is to return an array containing the starting indices of all stamping operations that create `target`.

If it is impossible, return an empty array.

You can perform at most:

\\[ 10 \times target.length() \\]

operations.&#x20;

## 2. Important Points

The main challenge is understanding why we solve this problem backward instead of forward.

### Forward approach

Initially:

```
?????
```

We need to find the correct stamping positions to construct:

```
ababc
```

This is difficult because a later stamp can overwrite characters created by an earlier stamp.

### Reverse approach — Greedy

Instead of constructing the target, start with the target and remove stamp-compatible sections.

```
Target: ababc
          |
          v
Remove "abc" at index 2
          |
          v
       ab???
          |
          v
Remove "ab?" at index 0
          |
          v
       ?????
```

We have successfully converted the target back into question marks.

But remember:

The reverse operations must be reversed before returning the answer.

Reverse removal order:

```
[2, 0]
```

Actual forward stamping order:

```
[0, 2]
```

## 3. Main Concepts / Approach

### Concept 1: Reverse Simulation

Forward:

```
?????  ->  abc??  ->  ababc
```

Backward:

```
ababc  ->  ab???  ->  ?????
```

Backward processing is easier because `?` acts as a wildcard.

### Concept 2: When can we remove a section?

Suppose:

```
stamp  = "abc"
target = "ab?bc"
```

Consider the window at index `0`:

```
Window: ab?
Stamp:  abc
```

This window is compatible because:

- `a` matches `a`.
- `b` matches `b`.
- `?` can represent any character that was already removed.

We can safely replace this window with question marks.

Two conditions must be satisfied:

1. Every character that is not `?` must match the corresponding stamp character.
2. At least one character must be changed to `?`.

The second condition prevents repeatedly processing a window that has already been removed.

### Concept 3: Greedy Processing

We repeatedly:

1. Check every possible window.
2. Find a window compatible with the stamp.
3. Replace its characters with `?`.
4. Record its starting index.
5. Continue until every character becomes `?` or no more progress is possible.

This is the reverse-greedy approach.&#x20;

## 4. Main Logic — Step by Step

We use:

```
char[] arr = target.toCharArray();
boolean[] visited = new boolean[n - m + 1];
List<Integer> result = new ArrayList<>();
```

| Variable     | Meaning                                                           |
| ------------ | ----------------------------------------------------------------- |
| `arr`        | Mutable copy of target                                            |
| `visited[i]` | Whether the window starting at index `i` has already been removed |
| `result`     | Stores reverse stamping positions                                 |
| `n`          | Length of target                                                  |
| `m`          | Length of stamp                                                   |
| `count`      | Number of characters converted into `?`                           |

### Step 1: Convert target into a character array

```
char[] arr = target.toCharArray();
```

Java strings are immutable, so we convert the target into a character array to modify it.

### Step 2: Check every possible window

```
for (int i = 0; i <= n - m; i++)
```

If:

```
target length = 5
stamp length  = 3
```

Possible starting positions are:

```
0, 1, 2
```

### Step 3: Check whether a window can be removed

```
private boolean canReplace(char[] arr, String stamp, int pos)
```

For every character:

- If the target character is `?`, ignore it.
- Otherwise, it must match the corresponding stamp character.
- At least one character must be a real character, not `?`.

### Step 4: Replace the window with question marks

```
for (int j = 0; j < stamp.length(); j++) {
    if (arr[pos + j] != '?') {
        arr[pos + j] = '?';
        count++;
    }
}
```

We erase the matching window and count how many new characters were removed.

### Step 5: Record the starting index

```
result.add(pos);
visited[pos] = true;
```

We record the index because this reverse removal represents a forward stamping operation.

### Step 6: Repeat until all characters are removed

```
while (count < n)
```

If an entire pass makes no progress, it means no remaining window can be removed.

In that case, return an empty array.

### Step 7: Reverse the result

```
Collections.reverse(result);
```

We processed the operations backward, so we reverse their order to obtain the actual forward stamping sequence.

## 5. Java Solution

Beginner-friendly solution — Reverse Greedy

```
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {

    public int[] movesToStamp(String stamp, String target) {

        int n = target.length();
        int m = stamp.length();

        char[] arr = target.toCharArray();

        // Track already processed windows
        boolean[] visited = new boolean[n - m + 1];

        List<Integer> result = new ArrayList<>();

        int count = 0;

        // Continue until every character becomes '?'
        while (count < n) {

            boolean changed = false;

            // Check every possible starting position
            for (int i = 0; i <= n - m; i++) {

                // Skip already processed windows
                if (visited[i]) {
                    continue;
                }

                // Check whether this window can be removed
                if (canReplace(arr, stamp, i)) {

                    // Replace characters with '?'
                    for (int j = 0; j < m; j++) {

                        if (arr[i + j] != '?') {

                            arr[i + j] = '?';
                            count++;
                        }
                    }

                    // Record reverse stamping position
                    result.add(i);

                    visited[i] = true;
                    changed = true;
                }
            }

            // No progress means impossible
            if (!changed) {
                return new int[0];
            }
        }

        // Reverse to get forward stamping order
        Collections.reverse(result);

        // Convert List<Integer> into int[]
        int[] answer = new int[result.size()];

        for (int i = 0; i < result.size(); i++) {
            answer[i] = result.get(i);
        }

        return answer;
    }

    // Check whether a window matches the stamp
    private boolean canReplace(char[] arr, String stamp, int pos) {

        boolean hasCharacter = false;

        for (int j = 0; j < stamp.length(); j++) {

            if (arr[pos + j] == '?') {
                continue;
            }

            if (arr[pos + j] != stamp.charAt(j)) {
                return false;
            }

            hasCharacter = true;
        }

        return hasCharacter;
    }
}
```

### Part B: Outer while loop


Now:

```

```
