LeetCode 1094 — Car Pooling
Greedy Algorithm + Difference Array + Prefix Sum | Medium
1. Problem Statement
You are given a car with a fixed number of seats (capacity).

You are also given a 2D integer array trips. Each trip is represented as:
[numPassengers, from, to] 


- numPassengers = number of passengers.
- from = location where passengers enter the car.
- to = location where passengers leave the car.
The car travels only in one direction (east).

Your task is to check whether the car can complete all trips without ever exceeding its seating capacity.

Return:
- true if all trips can be completed.
- false if the number of passengers exceeds the capacity at any point.
Important: Passengers leave the car at location to. They are not considered passengers in the car from that location onward.
2. Examples
Example 1
Input:
trips = [[2,1,5],[3,3,7]]
capacity = 4

Output:
false


Explanation:
- At location 1, 2 passengers enter.
- At location 3, 3 more passengers enter.
- Total passengers = 5.
- Capacity = 4.
The car cannot carry 5 passengers, so return false.

Example 2
Input:
trips = [[2,1,5],[3,5,7]]
capacity = 3

Output:
true


Explanation:
- At location 1, 2 passengers enter.
- At location 5, those 2 passengers leave.
- At location 5, 3 new passengers enter.
- Maximum passengers at any time = 3.
The car never exceeds its capacity.
3. Important Points
1. The car moves in only one direction.
2. Passengers enter at from.
3. Passengers leave at to.
4. Multiple trips can start or end at the same location.
5. We must check the passenger count throughout the journey, not just the total number of passengers across all trips.
Key observation:

Instead of tracking every passenger individually, track how the passenger count changes at each location.
- Passenger pickup → add passengers.
- Passenger drop-off → subtract passengers.
This leads to the Difference Array + Prefix Sum approach.
4. Main Concepts / Approach
We use two concepts:
A. Difference Array
A difference array records only where a value changes.

For each trip:
diff[from] += passengers;
diff[to] -= passengers;


Why?
- At from, passengers enter, so passenger count increases.
- At to, passengers leave, so passenger count decreases.
Example:
trips = [[2,1,5], [3,3,7]]


Passenger changes:
Location	Change	Meaning
1	'+2	2 passengers enter
3	'+3	3 passengers enter
5	'-2	2 passengers leave
7	'-3	3 passengers leave

All other locations have a change of 0.
B. Prefix Sum
After recording all changes, traverse the difference array from left to right.

Maintain:
int passengers = 0;


At each location:
passengers += diff[i];


This gives the number of passengers in the car after processing that location.

If:
passengers > capacity


return false.

If we finish the traversal without exceeding capacity, return true.
5. Main Logic — Step by Step
Step 1 — Create a difference array
int[] diff = new int[1001];


The problem guarantees locations are between 0 and 1000, so an array of size 1001 is sufficient.

Step 2 — Process every trip
for (int i = 0; i < trips.length; i++) {
    int passengers = trips[i][0];
    int from = trips[i][1];
    int to = trips[i][2];

    diff[from] += passengers;
    diff[to] -= passengers;
}


Step 3 — Calculate the running passenger count
int currentPassengers = 0;

for (int i = 0; i <= 1000; i++) {
    currentPassengers += diff[i];

    if (currentPassengers > capacity) {
        return false;
    }
}


Step 4 — Return true

If no location exceeds the capacity:
return true;


6. Java Solution
Optimal — Difference Array + Prefix Sum
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {

        // Difference array for locations 0 to 1000
        int[] diff = new int[1001];

        // Record passenger changes
        for (int i = 0; i < trips.length; i++) {

            int passengers = trips[i][0];
            int from = trips[i][1];
            int to = trips[i][2];

            // Passengers enter
            diff[from] += passengers;

            // Passengers leave
            diff[to] -= passengers;
        }

        // Calculate running passenger count
        int currentPassengers = 0;

        for (int i = 0; i <= 1000; i++) {

            currentPassengers += diff[i];

            // Check car capacity
            if (currentPassengers > capacity) {
                return false;
            }
        }

        return true;
    }
}

11. Complexity Analysis
Let:
- n = number of trips.
- M = maximum location, which is 1000.
Operation	Complexity
Initialize difference array	O(M)
Process all trips	O(n)
Calculate prefix sum	O(M)

Time Complexity: O(n + M)

Since M = 1000 is fixed by the problem constraints, this is effectively O(n) for this problem.

Space Complexity: O(M)

We use one difference array of size 1001. Since the location range is fixed, the auxiliary space is effectively O(1) with respect to the number of trips.
12. Important Interview Points
Why do we subtract at to?
Consider:
Trip = [2,1,5]


The two passengers are in the car while travelling from location 1 up to location 5.

At location 5, they leave.

So the passenger contribution is active over:
\[
[from,to)
\]

That means:
- Location 1: passengers enter.
- Locations 2, 3, 4: passengers remain.
- Location 5: passengers leave.
What if passengers leave and new passengers enter at the same location?
Example:
trips = [[2,1,5],[3,5,7]]


At location 5:
2 passengers leave
3 passengers enter


The net change is:
-2 + 3 = +1


This correctly represents the passenger count after processing location 5. The problem specifies that passengers are dropped off before new passengers are picked up at the same location.

Pattern Recognition Trick
When a problem contains:
- Multiple trips or intervals.
- A start and end location.
- Values that increase at the start and decrease at the end.
- A need to track the running total.
Think:
Difference Array + Prefix Sum
1. Record positive changes at the starting index.
2. Record negative changes at the ending index.
3. Calculate the prefix sum.
4. Check whether the running value violates the condition.

Common Mistakes
Mistake	Correct approach
Subtract passengers at to - 1	Subtract at to
Add passengers at to	Subtract passengers at to
Check only the final passenger count	Check every location
Use total passengers across all trips	Track simultaneous passengers
Forget same-location drop-offs	Apply the net change at that location
