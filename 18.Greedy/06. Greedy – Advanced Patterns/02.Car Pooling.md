# LeetCode 1094 — Car Pooling

## 1. Problem Statement

You are given a car with a fixed number of seats (`capacity`).

You are also given a 2D integer array `trips`. Each trip is represented as:

```
[numPassengers, from, to]
```

- `numPassengers` = number of passengers entering the car.
- `from` = location where passengers enter.
- `to` = location where passengers leave.

The car travels in one direction (east).

Your task is to check whether the car can complete all trips without ever exceeding its seating capacity.

Return:

- `true` if the car can complete all trips.
- `false` if the number of passengers exceeds the capacity at any point.

Important: Passengers leave the car at location `to`. Therefore, they are not counted as passengers travelling beyond that location.

## 2. Example

Example 1

```
Input:
trips = [[2,1,5],[3,3,7]]
capacity = 4

Output:
false
```

Explanation:

- At location 1, 2 passengers enter.
- At location 3, 3 more passengers enter.
- Total passengers = 5.
- The car has only 4 seats.

So the capacity is exceeded.

Example 2

```
Input:
trips = [[2,1,5],[3,3,7]]
capacity = 5

Output:
true
```

Explanation:

The maximum number of passengers in the car is 5, which equals the capacity.

Example 3

```
Input:
trips = [[2,1,5],[3,5,7]]
capacity = 3

Output:
true
```

Explanation:

At location 5, the first 2 passengers leave before the next 3 passengers enter. The car never carries more than 3 passengers.

## 3. Important Points

1. Multiple trips can overlap.
2. Passengers enter at `from`.
3. Passengers leave at `to`.
4. The car can never carry more than `capacity` passengers.
5. We must check passenger count at every location where it changes.

Key observation:

Instead of processing each trip separately, we can record how the passenger count changes at each location.

- At the pickup location, add passengers.
- At the drop-off location, subtract passengers.

This is called the Difference Array + Prefix Sum technique.

## 4. Main Concepts / Approach

We use three concepts:

### A. Difference Array

A difference array helps us record changes to values over a range without updating every position individually.

For each trip:

```
[numPassengers, from, to]
```

We perform:

```
diff[from] += numPassengers;
diff[to] -= numPassengers;
```

Why?

- At `from`, passengers enter, so passenger count increases.
- At `to`, passengers leave, so passenger count decreases.

Example:

```
Trip = [2, 1, 5]

At location 1: +2
At location 5: -2
```

### B. Prefix Sum

The difference array stores only changes. To calculate the actual number of passengers at each location, we calculate its prefix sum.

```
passengers += diff[i];
```

The running `passengers` value tells us how many people are currently inside the car.

### C. Greedy Capacity Check

At every location, check:

```
if (passengers > capacity) {
    return false;
}
```

If the passenger count never exceeds the capacity, return `true`.

## 5. Main Logic — Step by Step

Step 1 — Create a difference array

The problem constraints say that locations range from 0 to 1000.

So we create:

```
int[] diff = new int[1001];
```

Step 2 — Process every trip

```
for (int i = 0; i < trips.length; i++) {
    int passengers = trips[i][0];
    int from = trips[i][1];
    int to = trips[i][2];

    diff[from] += passengers;
    diff[to] -= passengers;
}
```

Step 3 — Calculate prefix sum

```
int currentPassengers = 0;

for (int i = 0; i <= 1000; i++) {
    currentPassengers += diff[i];
}
```

Step 4 — Check capacity

```
if (currentPassengers > capacity) {
    return false;
}
```

Step 5 — If no violation occurs

```
return true;
```

## 6. Java Solution

Optimal — Difference Array + Prefix Sum

```
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {

        // Difference array for locations 0 to 1000
        int[] diff = new int[1001];

        // Record passenger changes
        for (int i = 0; i < trips.length; i++) {

            int passengers = trips[i][0];
            int from = trips[i][1];
            int to = trips[i][2];

            // Passengers enter
            diff[from] += passengers;

            // Passengers leave
            diff[to] -= passengers;
        }

        // Calculate prefix sum
        int currentPassengers = 0;

        for (int i = 0; i <= 1000; i++) {

            currentPassengers += diff[i];

            // Check car capacity
            if (currentPassengers > capacity) {
                return false;
            }
        }

        return true;
    }
}
```

## 7. Understand the Code

Part A — Create the difference array

```
int[] diff = new int[1001];
```

Each index represents a location.

Initially:

```
Index:  0  1  2  3  4  5  6  7 ...
diff:   0  0  0  0  0  0  0  0 ...
```

Part B — Read trip information

```
int passengers = trips[i][0];
int from = trips[i][1];
int to = trips[i][2];
```

For this trip:

```
trips[i] = [3, 2, 6]
```

We get:

```
passengers = 3
from = 2
to = 6
```

Part C — Add passengers at pickup

```
diff[from] += passengers;
```

At location 2, three passengers enter.

```
diff[2] += 3
```

Part D — Subtract passengers at drop-off

```
diff[to] -= passengers;
```

At location 6, those three passengers leave.

```
diff[6] -= 3
```

Part E — Calculate the running passenger count

```
currentPassengers += diff[i];
```

This is the prefix sum.

For example:

```
diff:                [0, 2, 0, 3, 0, -2, 0, -3]
Prefix sum:          [0, 2, 2, 5, 5,  3, 3,  0]
```

The prefix sum gives the actual passenger count at each location.

Part F — Check the capacity

```
if (currentPassengers > capacity) {
    return false;
}
```

If the car has 5 passengers but its capacity is 4, we immediately return `false`.

Part G — Return true

```
return true;
```

If every location satisfies the capacity limit, all trips are possible.
