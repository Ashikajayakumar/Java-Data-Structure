## 1. Problem Statement

You are given an integer array `nums` sorted in non-decreasing order.

Your task is to split the array into one or more subsequences such that:

1. Every subsequence contains consecutive increasing numbers.
2. Every subsequence must contain at least 3 elements.
3. Every array element must be used exactly once.
4. The original relative order of elements must be preserved.

Return `true` if such a split is possible; otherwise, return `false`.

What is a consecutive subsequence?

A sequence where every next number is exactly one greater than the previous number.

Examples:

```
Valid:
[1, 2, 3]
[2, 3, 4, 5]
[5, 6, 7, 8, 9]

Invalid:
[1, 2]       // Length less than 3
[1, 3, 4]    // Missing 2
[2, 4, 5]    // Missing 3
```

The input array is already sorted, so we can process its numbers from left to right.&#x20;

## 3. Important Points

This problem uses a Greedy + HashMap approach.

We maintain two HashMaps:

| HashMap     | Purpose                                                                   |
| ----------- | ------------------------------------------------------------------------- |
| `frequency` | Counts how many unused copies of each number remain                       |
| `need`      | Counts how many existing subsequences are waiting for a particular number |

### Understand `frequency`

Example:

```
nums = [1, 2, 3, 3, 4, 5]
```

Frequency:

| Number | Frequency |
| ------ | --------- |
| 1      | 1         |
| 2      | 1         |
| 3      | 2         |
| 4      | 1         |
| 5      | 1         |

`frequency[3] = 2` means two copies of `3` are available.

### Understand `need`

Suppose we have already created:

```
[1, 2, 3]
```

This subsequence can be extended by `4`.

Therefore:

```
need[4] = 1
```

It means one existing subsequence is waiting for `4`.

If we add `4`, that subsequence becomes:

```
[1, 2, 3, 4]
```

Now it waits for `5`:

```
need[4] = 0
need[5] = 1
```

Important distinction:

- `frequency[x]` = How many unused copies of `x` are available?
- `need[x]` = How many subsequences are waiting for `x`?

## 4. Main Concepts / Approach

The greedy strategy has two priorities.

Priority 1

Extend an existing subsequence

If a subsequence is waiting for the current number, add the number to that subsequence.

Priority 2

Create a new subsequence

If no existing subsequence can be extended, try to create:

```
[num, num + 1, num + 2]
```

Failure

Return false

If we cannot extend an existing subsequence or create a new valid sequence, splitting is impossible.

### Why extend an existing subsequence first?

Suppose we have:

```
Existing sequence: [1, 2]
Current number: 3
```

We should extend it:

```
[1, 2, 3]
```

Now it becomes valid.

If we unnecessarily start a new sequence instead, the old `[1,2]` might remain incomplete.

Therefore, extending an existing subsequence is safer than creating a new one.&#x20;

## 5. Main Logic — Step by Step

We use two HashMaps:

```
Map<Integer, Integer> frequency = new HashMap<>();
Map<Integer, Integer> need = new HashMap<>();
```

### Step 1: Count the frequency of every number

```
for (int num : nums) {
    frequency.put(num,
        frequency.getOrDefault(num, 0) + 1);
}
```

Example:

```
nums = [1, 2, 3, 3, 4, 5]

frequency:
1 -> 1
2 -> 1
3 -> 2
4 -> 1
5 -> 1
```

### Step 2: Process every number

```
for (int num : nums) {
```

Because the array is sorted, smaller numbers are processed before larger numbers.

### Step 3: Skip already-used numbers

```
if (frequency.get(num) == 0) {
    continue;
}
```

If the frequency is zero, all copies of that number have already been assigned to subsequences.

### Step 4: Extend an existing subsequence

```
if (need.getOrDefault(num, 0) > 0) {

    need.put(num, need.get(num) - 1);

    need.put(num + 1,
        need.getOrDefault(num + 1, 0) + 1);

    frequency.put(num, frequency.get(num) - 1);
}
```

Why `need[num]`?

If `need[4] = 2`, it means two subsequences are waiting for the number `4`.

When we process `4`:

- One subsequence gets extended.
- `need[4]` decreases by one.
- That subsequence now waits for `5`.
- `need[5]` increases by one.
- The used `4` is removed from the available frequency.

### Step 5: Create a new subsequence if extension is impossible

```
else if (frequency.getOrDefault(num + 1, 0) > 0 &&
         frequency.getOrDefault(num + 2, 0) > 0) {

    frequency.put(num, frequency.get(num) - 1);

    frequency.put(num + 1,
        frequency.get(num + 1) - 1);

    frequency.put(num + 2,
        frequency.get(num + 2) - 1);

    need.put(num + 3,
        need.getOrDefault(num + 3, 0) + 1);
}
```

We check whether the next two consecutive numbers are available.

For example:

```
Current number = 1

Check:
2 available?
3 available?

Yes!

Create:
[1, 2, 3]
```

After creating `[1,2,3]`, the sequence waits for `4`.

So we update:

```
need[num + 3]++;
```

### Step 6: If neither operation is possible

```
else {
    return false;
}
```

The current number cannot be placed into any valid subsequence.

### Step 7: Return true

```
return true;
```

If all elements are successfully assigned, every subsequence is valid.

## 6. Java Solution

Recommended solution — Greedy + Two HashMaps

```
import java.util.HashMap;
import java.util.Map;

class Solution {

    public boolean isPossible(int[] nums) {

        Map<Integer, Integer> frequency = new HashMap<>();
        Map<Integer, Integer> need = new HashMap<>();

        // Step 1: Count frequency of every number
        for (int num : nums) {
            frequency.put(num,
                frequency.getOrDefault(num, 0) + 1);
        }

        // Step 2: Process numbers from left to right
        for (int num : nums) {

            // Skip numbers already used
            if (frequency.get(num) == 0) {
                continue;
            }

            // Step 3: Extend an existing subsequence
            if (need.getOrDefault(num, 0) > 0) {

                need.put(num, need.get(num) - 1);

                need.put(num + 1,
                    need.getOrDefault(num + 1, 0) + 1);

                frequency.put(num,
                    frequency.get(num) - 1);
            }

            // Step 4: Create a new subsequence
            else if (frequency.getOrDefault(num + 1, 0) > 0 &&
                     frequency.getOrDefault(num + 2, 0) > 0) {

                frequency.put(num,
                    frequency.get(num) - 1);

                frequency.put(num + 1,
                    frequency.get(num + 1) - 1);

                frequency.put(num + 2,
                    frequency.get(num + 2) - 1);

                need.put(num + 3,
                    need.getOrDefault(num + 3, 0) + 1);
            }

            // Step 5: Cannot form a valid subsequence
            else {
                return false;
            }
        }

        return true;
    }
}
```

## 7. Understand the Code — Important Variables

| Variable    | Meaning                                               |
| ----------- | ----------------------------------------------------- |
| `nums`      | Sorted input array                                    |
| `frequency` | Remaining unused numbers                              |
| `need`      | Number of subsequences waiting for a particular value |
| `num`       | Current number being processed                        |

### Understand the most important conditions

Condition 1:

```
if (need.getOrDefault(num, 0) > 0)
```

Meaning: Can I extend an existing subsequence with this number?

Condition 2:

```
else if (frequency.getOrDefault(num + 1, 0) > 0 &&
         frequency.getOrDefault(num + 2, 0) > 0)
```

Meaning: If I cannot extend an existing subsequence, can I create a new sequence of length 3?

Condition 3:

```
else {
    return false;
}
```

Meaning: Neither option is possible.

Most important interview rule:

Always check whether you can extend an existing subsequence before creating a new one.
