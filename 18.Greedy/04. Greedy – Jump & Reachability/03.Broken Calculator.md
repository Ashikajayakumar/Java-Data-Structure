# LeetCode 991 – Broken Calculator

## 1. Problem Statement

You are given two integers:

- `startValue`: The initial number displayed on the calculator.
- `target`: The number you want to reach.

The calculator supports only two operations:

1. Double: Multiply the displayed number by 2.
2. Decrement: Subtract 1 from the displayed number.

Your task is to find the minimum number of operations required to transform `startValue` into `target`.

Return the minimum number of operations.

## 2. Examples

Example 1

```
Input:  startValue = 2, target = 3
Output: 2
```

Explanation:

```
2 → 4 → 3
   ×2   -1
```

Total operations = 2.

Example 2

```
Input:  startValue = 5, target = 8
Output: 2
```

Explanation:

```
5 → 10 → 9 → 8
```

That sequence takes 3 operations, but there is a better way:

```
5 → 4 → 8
   -1  ×2
```

Total operations = 2.

Example 3

```
Input:  startValue = 3, target = 10
Output: 3
```

Explanation:

```
3 → 6 → 5 → 10
   ×2  -1  ×2
```

Total operations = 3.

## 3. Important Points

| Operation | Forward direction | Reverse direction |
| --------- | ----------------- | ----------------- |
| Double    | `x = x * 2`       | `x = x / 2`       |
| Decrement | `x = x - 1`       | `x = x + 1`       |

The important observation is:

Instead of transforming `startValue` into `target`, work backward from `target` to `startValue`.

Why?

- Forward direction has two possible operations at each step.
- Backward direction gives us a greedy choice based on whether the target is odd or even.

## 4. Main Concepts – Greedy + Reverse Operations

Let's understand the reverse operations.

Forward operations:

```
Double:    x → 2x
Decrement: x → x - 1
```

Reverse operations:

```
If target is EVEN:
    target = target / 2

If target is ODD:
    target = target + 1
```

Why these choices?

Case 1 – Target is even

If the target is even, it may have been produced by doubling a smaller number.

For example:

```
16 → 8
```

Instead of guessing whether to double or decrement, divide by 2.

Case 2 – Target is odd

An odd number greater than 1 cannot be the result of doubling an integer.

So we reverse a decrement operation by adding 1.

For example:

```
9 → 10
```

Now 10 is even, so we can divide it by 2.

Case 3 – Target is smaller than startValue

If `target < startValue`, doubling is not useful. We only need to decrement.

Therefore:

```
Operations = startValue - target
```

## 5. Main Logic – Step by Step

We use two variables:

```
int operations = 0;
int target = target;
```

Follow these steps:

1. While `target` is greater than `startValue`:
   - If `target` is odd, increment it by 1.
   - If `target` is even, divide it by 2.
   - Increase `operations` by 1.
2. Once `target` becomes less than or equal to `startValue`, we cannot benefit from doubling anymore.
3. Add the remaining difference:
   ```
   operations += startValue - target;
   ```
4. Return `operations`.

## 6. Java Solution – Optimal Greedy

```
class Solution {
    public int brokenCalc(int startValue, int target) {

        int operations = 0;

        while (target > startValue) {

            if (target % 2 == 1) {
                target++;
            } else {
                target = target / 2;
            }

            operations++;
        }

        operations += startValue - target;

        return operations;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Initialize operation count

```
int operations = 0;
```

Initially, we have not performed any operation.

Part B – Continue while target is greater than startValue

```
while (target > startValue)
```

We work backward until the target becomes equal to or smaller than the starting value.

Part C – Check whether target is odd

```
if (target % 2 == 1) {
    target++;
}
```

If the target is odd, add 1.

Why?

Because in the forward direction, the previous operation must have been decrementing a number by 1.

Example:

```
9 → 10
```

Part D – If target is even

```
else {
    target = target / 2;
}
```

If the target is even, reverse the doubling operation.

Example:

```
16 → 8
```

Part E – Count each reverse operation

```
operations++;
```

Every reverse operation represents one forward operation.

Part F – Handle the remaining difference

```
operations += startValue - target;
```

When `target` becomes smaller than `startValue`, we can only use decrement operations in the forward direction.

For example:

```
startValue = 10
target = 7

10 → 9 → 8 → 7
```

Remaining operations = `10 - 7 = 3`.

## 8. Complete Dry Run – Example 1

Input:

```
startValue = 2;
target = 3;
```

Initial values:

```
operations = 0
target = 3
startValue = 2
```

Iteration 1

Check:

```
target > startValue
3 > 2 → true
```

Check odd or even:

```
3 % 2 == 1
```

Target is odd.

```
target++;
```

New values:

```
target = 4
operations = 1
```

Iteration 2

Check:

```
4 > 2 → true
```

Target is even.

```
target = target / 2;
```

New values:

```
target = 2
operations = 2
```

Loop ends

```
target > startValue
2 > 2 → false
```

Remaining difference:

```
operations += startValue - target;
```

```
operations = 2 + (2 - 2)
           = 2
```

Output: 2

Reverse visualization:

```
Forward:  2 → 4 → 3
Reverse:  3 → 4 → 2
```
