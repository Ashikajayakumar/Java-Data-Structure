# LeetCode 55 – Jump Game


## 1. Problem Statement

You are given an integer array `nums`.

- You start at the first index (index 0).
- Each element `nums[i]` represents the maximum number of steps you can jump forward from that position.
- You can jump any distance from `1` to `nums[i]` steps.
- Your task is to determine whether you can reach the last index.

Return:

- `true` if you can reach the last index.
- `false` if you cannot reach the last index.

Important: `nums[i]` is the maximum jump distance, not the exact distance.

## 2. Examples

Example 1

```
Input:  nums = [2,3,1,1,4]
Output: true
```

Explanation:

We start at index `0`.

```
Index:  0   1   2   3   4
Value:  2   3   1   1   4
        ^
```

One possible path:

```
Index 0 → Index 1 → Index 4

          Jump 1     Jump 3
```

- At index 0, maximum jump = 2.
- We jump to index 1.
- At index 1, maximum jump = 3.
- We jump to index 4.

We successfully reach the last index.

Output: `true`

Example 2

```
Input:  nums = [3,2,1,0,4]
Output: false
```

Explanation:

```
Index:  0   1   2   3   4
Value:  3   2   1   0   4
```

From index 0, we can reach index 1, 2, or 3.

But index 3 contains `0`.

```
0 → 1 → 2 → 3    X    4
                  |
             Jump = 0
```

We cannot move forward from index 3, and index 4 is unreachable.

Output: `false`

## 3. Important Points

| Concept           | Meaning                                   |
| ----------------- | ----------------------------------------- |
| Starting position | Index 0                                   |
| Destination       | Last index                                |
| `nums[i]`         | Maximum jump distance                     |
| `i + nums[i]`     | Farthest index reachable from index `i`   |
| Zero              | Cannot move forward from that position    |
| Goal              | Check whether the last index is reachable |

Important observations:

1. We do not need to find the exact jump sequence.
2. We only need to track the farthest index we can reach.
3. If the current index is beyond our farthest reachable index, we are stuck.
4. If our farthest reach reaches the last index, the answer is `true`.

## 4. Main Concepts – Greedy Algorithm

Which pattern should we recognize?

The question asks whether we can reach the destination by making choices at every position.

Instead of checking every possible jump, we can make a greedy decision.

The main idea is:

Always maintain the farthest reachable index.

We use one variable:

```
int farthest = 0;
```

This variable represents the maximum index we can reach so far.

For every index:

```
farthest = Math.max(farthest, i + nums[i]);
```

Why `Math.max()`?

Because we should never lose the maximum reach obtained from an earlier index.

For example:

```
nums = [2, 3, 1, 1, 4]

At index 0:
Reach = 0 + 2 = 2

At index 1:
Reach = 1 + 3 = 4

At index 2:
Reach = 2 + 1 = 3
```

Even though index 2 can only reach index 3, we already know index 4 is reachable from index 1.

Therefore, we retain the maximum value: `4`.

## 5. Main Logic – Step by Step

1. Initialize `farthest = 0`.
2. Traverse the array from left to right.
3. Check whether the current index is reachable:
   - If `i > farthest`, return `false`.
4. Otherwise, calculate the farthest reachable index:
   - `farthest = Math.max(farthest, i + nums[i])`.
5. If `farthest` reaches the last index, return `true`.
6. If the loop completes, return `true`.

## 6. Java Solution – Optimal Greedy

```
class Solution {
    public boolean canJump(int[] nums) {

        int farthest = 0;

        for (int i = 0; i < nums.length; i++) {

            if (i > farthest) {
                return false;
            }

            farthest = Math.max(farthest, i + nums[i]);

            if (farthest >= nums.length - 1) {
                return true;
            }
        }

        return true;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Initialize farthest

```
int farthest = 0;
```

- We start at index 0.
- Initially, we can reach only index 0.
- So `farthest = 0`.

Part B – Traverse the array

```
for (int i = 0; i < nums.length; i++)
```

We visit each index one by one.

For example:

```
i = 0
i = 1
i = 2
i = 3
i = 4
```

Part C – Check whether the current index is reachable

```
if (i > farthest) {
    return false;
}
```

This is the most important condition.

Suppose:

```
i = 4
farthest = 3
```

We want to visit index 4, but we can only reach index 3.

Therefore:

```
4 > 3

Return false
```

Part D – Update the farthest reachable index

```
farthest = Math.max(farthest, i + nums[i]);
```

We calculate how far we can jump from the current index.

Example:

```
i = 1
nums[i] = 3

i + nums[i] = 1 + 3 = 4
```

If the previous farthest value was 2:

```
farthest = Math.max(2, 4);
```

New value:

```
farthest = 4
```

Part E – Check whether we reached the destination

```
if (farthest >= nums.length - 1) {
    return true;
}
```

The last index is:

```
nums.length - 1
```

If the farthest reachable index is greater than or equal to the last index, we can reach the destination.

Part F – Final return

```
return true;
```

If the loop finishes without finding an unreachable index, the destination is reachable.
