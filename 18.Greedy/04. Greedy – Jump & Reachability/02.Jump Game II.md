# LeetCode 45 – Jump Game II


## 1. Problem Statement

You are given an integer array `nums`.

- You start at the first index (index `0`).
- Each element `nums[i]` represents the maximum number of steps you can jump forward from that position.
- You can jump any distance from `1` to `nums[i]` steps.
- Your task is to reach the last index using the minimum number of jumps.

Return the minimum number of jumps required to reach the last index.

Important difference:

- Jump Game (LC 55): Can we reach the last index? Return `true` or `false`.
- Jump Game II (LC 45): What is the minimum number of jumps needed? Return an integer.

## 2. Examples

Example 1

```
Input:  nums = [2,3,1,1,4]
Output: 2
```

Explanation:

One optimal path is:

```
Index 0 → Index 1 → Index 4
```

- From index 0, jump to index 1.
- From index 1, jump to index 4.

Total jumps = 2.

Example 2

```
Input:  nums = [2,3,0,1,4]
Output: 2
```

Explanation:

```
Index 0 → Index 1 → Index 4
```

Total jumps = 2.

## 3. Important Points

| Concept        | Meaning                           |
| -------------- | --------------------------------- |
| Starting index | 0                                 |
| Destination    | Last index                        |
| `nums[i]`      | Maximum jump distance             |
| Goal           | Minimum number of jumps           |
| Approach       | Greedy                            |
| Main variables | `jumps`, `currentEnd`, `farthest` |

The key observation:

We should explore all positions reachable within the current jump before deciding where the next jump should take us.

We do not need to actually choose the exact next index immediately.

## 4. Main Concepts – Greedy Algorithm

We use three variables.

```
int jumps = 0;
int currentEnd = 0;
int farthest = 0;
```

1\. `jumps`

Counts the number of jumps taken.

2\. `currentEnd`

Represents the end of the range that we can reach using the current number of jumps.

3\. `farthest`

Represents the farthest index we can reach from all positions in the current range.

### Understand with a diagram

Input:

```
nums = [2, 3, 1, 1, 4]
```

Index:

```
         0   1   2   3   4
nums =  [2,  3,  1,  1,  4]
```

Initially, we are at index 0.

From index 0, we can reach:

```
       [0, 1, 2]
```

This is our first jump range.

Now explore indices 1 and 2 to find the farthest position reachable:

- Index 1 can reach index 4.
- Index 2 can reach index 3.

The farthest position is index 4.

Therefore, we need one more jump to reach the destination.

```
Jump 1: Index 0 → Range [1, 2]
Jump 2: Reach index 4
```

Total jumps = 2.

## 5. Main Logic – Step by Step

1. Initialize `jumps = 0`, `currentEnd = 0`, and `farthest = 0`.
2. Traverse the array until the second-last index.
3. At every index, calculate the farthest reachable position:
   ```
   farthest = Math.max(farthest, i + nums[i]);
   ```
4. When `i == currentEnd`, we have explored the entire range reachable with the current number of jumps.
5. Increase the jump count:
   ```
   jumps++;
   ```
6. Update the current range boundary:
   ```
   currentEnd = farthest;
   ```
7. Continue until the last index is covered.

Why do we stop at `nums.length - 1` instead of the last index?

Because we only need to decide how to reach the last index. We do not need to jump again after arriving there.

## 6. Java Solution – Optimal Greedy

```
class Solution {
    public int jump(int[] nums) {

        int jumps = 0;
        int currentEnd = 0;
        int farthest = 0;

        for (int i = 0; i < nums.length - 1; i++) {

            farthest = Math.max(farthest, i + nums[i]);

            if (i == currentEnd) {
                jumps++;
                currentEnd = farthest;
            }
        }

        return jumps;
    }
}
```

## 7. Understand the Code – Line by Line

Part A – Initialize variables

```
int jumps = 0;
int currentEnd = 0;
int farthest = 0;
```

Initially:

| Variable     | Value | Purpose                                 |
| ------------ | ----- | --------------------------------------- |
| `jumps`      | 0     | No jumps taken                          |
| `currentEnd` | 0     | Current reachable range ends at index 0 |
| `farthest`   | 0     | Maximum reachable index so far          |

Part B – Traverse the array

```
for (int i = 0; i < nums.length - 1; i++)
```

We traverse from index 0 to the second-last index.

For an array of length 5:

```
i = 0, 1, 2, 3
```

We don't need to process index 4 because it is our destination.

Part C – Calculate farthest reach

```
farthest = Math.max(farthest, i + nums[i]);
```

Example:

```
i = 1
nums[i] = 3

i + nums[i] = 1 + 3 = 4
```

If the previous farthest value is 2:

```
farthest = Math.max(2, 4);
```

New value:

```
farthest = 4
```

Part D – Check whether the current range has ended

```
if (i == currentEnd)
```

This means we have reached the end of the range covered by our current number of jumps.

Now we must take another jump to extend our reachable range.

Part E – Increase jump count

```
jumps++;
```

We have decided to move to the next reachable range.

Part F – Update the current boundary

```
currentEnd = farthest;
```

The next range ends at the farthest position we discovered.
