# LeetCode 122 – Best Time to Buy and Sell Stock II

## 1. Problem Statement

You are given an integer array `prices`, where `prices[i]` represents the price of a stock on the `i-th` day.

You can buy and sell the stock multiple times to maximize your total profit.

Rules:

1. You can hold at most one stock at a time.
2. You can buy and sell on the same day.
3. You must sell the stock before buying again.
4. You can make as many transactions as you want.

Your task is to return the maximum profit you can achieve.

## 2. Example

Input:

```
prices = [7, 1, 5, 3, 6, 4]
```

Output:

```
7
```

Explanation:

We can make two transactions:

- Buy at price `1` and sell at price `5` → Profit = `4`.
- Buy at price `3` and sell at price `6` → Profit = `3`.

Total profit:

`` (5-1)+(6-3)=4+3=\boxed{7} ``

We do not buy again after selling at price `6`, because the final price `4` is lower.

## 3. Important Points

- We can perform multiple transactions.
- We can buy and sell multiple times, but cannot hold multiple stocks simultaneously.
- We must sell before buying again.
- We need maximum profit, not the maximum number of transactions.
- A transaction is profitable only when the selling price is greater than the buying price.

Important observation:

Whenever tomorrow's price is higher than today's price, we can earn that difference as profit.

For example:

```
Prices:  1 → 5 → 3 → 6
         +4   -2  +3
```

We collect the positive increases:

`` 4+3=7 ``

## 4. Main Concept – Greedy Algorithm

The greedy approach is to collect every positive price difference between consecutive days.

Formula:

`` text{Profit} = \sum\_{i=1}^{n-1}\max(0,prices[i]-prices[i-1]) ``

In simple words:

- If today's price is lower than tomorrow's price, add the difference to profit.
- If tomorrow's price is lower or equal, do nothing.

Why does this work?

Suppose prices increase from `1 → 5 → 8`.

We could:

\- Buy at 1 and sell at 8 → Profit = 7.

Or:

- Buy at 1 and sell at 5 → Profit = 4.
- Buy at 5 and sell at 8 → Profit = 3.

Both give the same total profit:

`` 8-1=(5-1)+(8-5)=7 ``

Therefore, adding every positive consecutive increase gives the maximum possible profit.

## 5. Main Logic – Step by Step

1. Initialize `profit = 0`.
2. Start iterating from index `1`.
3. Compare the current day's price with the previous day's price.
4. If the current price is greater, calculate the difference.
5. Add the difference to `profit`.
6. Continue until the last day.
7. Return the total profit.

## 6. Java Solution

Greedy – Optimal Approach

```
class Solution {
    public int maxProfit(int[] prices) {

        int profit = 0;

        for (int i = 1; i < prices.length; i++) {

            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }

        return profit;
    }
}
```

## 7. Understand the Code

Part A – Initialize profit

```
int profit = 0;
```

This variable stores the total profit earned from all transactions.

Initially, profit is zero because we have not made any transactions.

Part B – Start the loop

```
for (int i = 1; i < prices.length; i++)
```

Why start from index `1` instead of `0`?

Because we compare the current day's price with the previous day's price:

```
prices[i] > prices[i - 1]
```

If we start at index `0`, `prices[i - 1]` would cause an index error.

Part C – Check whether the price increased

```
if (prices[i] > prices[i - 1])
```

We check whether today's stock price is greater than yesterday's price.

Example:

```
Yesterday = 1
Today     = 5

5 > 1 → True
```

We can make a profit.

Part D – Add the profit

```
profit += prices[i] - prices[i - 1];
```

Calculate the difference between today's and yesterday's prices.

```
Today's price     = 5
Yesterday's price = 1

Profit = 5 - 1 = 4
```

Add 4 to the total profit.

Part E – Return the answer

```
return profit;
```

After checking all days, return the maximum accumulated profit.
