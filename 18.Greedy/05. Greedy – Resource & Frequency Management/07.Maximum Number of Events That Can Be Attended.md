# LeetCode 1353 — Maximum Number of Events That Can Be Attended
<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/6ae561ef-c786-49e2-99ce-e930ad27a6f9" />

## 1. Problem Statement

You are given a 2D integer array `events`, where:

- `events[i][0]` = the start day of the event.
- `events[i][1]` = the end day of the event.

You can attend only one event per day.

You may attend an event on any day between its start day and end day, including both days.

Your task is to return the maximum number of events you can attend.

The important challenge is choosing which event to attend when multiple events are available on the same day.

## 2. Example

Example 1

```
Input:
events = [[1,2],[2,3],[3,4]]

Output:
3
```

Explanation:

- Attend event 1 on day 1.
- Attend event 2 on day 2.
- Attend event 3 on day 3.

All three events can be attended.

Example 2

```
Input:
events = [[1,2],[1,2],[3,3],[1,5],[1,5]]

Output:
5
```

Explanation:

We can attend one event on each of days 1, 2, 3, 4, and 5.

## 3. Important Points

1. Only one event can be attended per day.
2. You can attend an event on its start day or end day.
3. You do not need to attend events in the order they are given.
4. If multiple events are available, prefer the event that ends earliest.
5. Events that have already ended cannot be attended.

The key greedy observation:

Always attend the available event with the earliest ending day.

## 4. Main Concepts / Approach

We use three concepts:

### A. Sorting

Sort events by their start day in ascending order.

This allows us to process events in chronological order and know which events have become available.

### B. Min Heap (PriorityQueue)

A min heap gives us the smallest element quickly.

Here, we store the ending day of every event that has started but has not yet been attended.

For example:

```
Events available:
[1,5], [1,2], [2,4]

Heap:
       2
      / \
     5   4
```

The smallest ending day is `2`, so we attend that event first.

In Java:

```
PriorityQueue<Integer> pq = new PriorityQueue<>();
```

- `pq.offer(x)` → insert an ending day.
- `pq.peek()` → see the smallest ending day.
- `pq.poll()` → remove the smallest ending day.

### C. Greedy

On each day:

1. Add all events that have started.
2. Remove events that have already expired.
3. Attend the available event with the earliest ending day.
4. Move to the next day.

Why choose the earliest ending day?

Because an event that ends soon may become impossible to attend if we postpone it. An event with a later ending day has more flexibility.

This is the Greedy + Sorting + Min Heap pattern.&#x20;

## 6. Java Solution

Optimal Greedy + Min Heap

```
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int maxEvents(int[][] events) {

        // Sort events by starting day
        Arrays.sort(events, (a, b) ->
            Integer.compare(a[0], b[0])
        );

        // Min heap stores ending days
        PriorityQueue<Integer> pq = new PriorityQueue<>();

        int i = 0;
        int day = 0;
        int count = 0;

        while (i < events.length || !pq.isEmpty()) {

            // If no event is available, jump to next start day
            if (pq.isEmpty()) {
                day = Math.max(day, events[i][0]);
            }

            // Add all events that have started
            while (i < events.length &&
                   events[i][0] <= day) {

                pq.offer(events[i][1]);
                i++;
            }

            // Remove events that have already expired
            while (!pq.isEmpty() && pq.peek() < day) {
                pq.poll();
            }

            // Attend the event ending earliest
            if (!pq.isEmpty()) {
                pq.poll();
                count++;
                day++;
            }
        }

        return count;
    }
}
```

## 7. Understand the Code

Part A — Sort by starting day

```
Arrays.sort(events, (a, b) ->
    Integer.compare(a[0], b[0])
);
```

`a[0]` and `b[0]` represent the starting days.

We sort in ascending order so that events starting earlier are processed first.

Part B — Create the min heap

```
PriorityQueue<Integer> pq = new PriorityQueue<>();
```

The heap stores only ending days.

Example:

```
pq = [2, 4, 5]
```

The event ending on day `2` is the most urgent.

Part C — Initialize variables

```
int i = 0;
int day = 0;
int count = 0;
```

| Variable | Purpose                              |
| -------- | ------------------------------------ |
| `i`      | Tracks the next event to process     |
| `day`    | Current day                          |
| `count`  | Number of events attended            |
| `pq`     | Stores available events' ending days |

Part D — Main while loop

```
while (i < events.length || !pq.isEmpty())
```

Continue while either:

- Some events have not yet been added to the heap, or
- Some available events remain in the heap.

Part E — Skip empty days

```
if (pq.isEmpty()) {
    day = Math.max(day, events[i][0]);
}
```

If no event is currently available, move directly to the next event's starting day.

This avoids wasting time checking days when nothing can be attended.

Part F — Add available events

```
while (i < events.length &&
       events[i][0] <= day) {

    pq.offer(events[i][1]);
    i++;
}
```

Add every event whose starting day is less than or equal to the current day.

Part G — Remove expired events

```
while (!pq.isEmpty() && pq.peek() < day) {
    pq.poll();
}
```

If an event ends before the current day, it can no longer be attended.

Notice the condition is:

```
pq.peek() < day
```

An event ending exactly on the current day is still valid.

Part H — Attend one event

```
if (!pq.isEmpty()) {
    pq.poll();
    count++;
    day++;
}
```

- Remove the event with the earliest ending day.
- Increase the attended event count.
- Move to the next day.
