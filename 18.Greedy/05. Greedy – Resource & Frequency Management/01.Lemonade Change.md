# LeetCode 860 – Lemonade Change

Greedy Algorithm | Array | Simulation | Easy



Optimal: O(n) time

O(1) space



## 1. Problem Statement

You are running a lemonade stand.

- Each lemonade costs $5.
- Customers stand in a queue and pay one by one.
- Each customer pays using a `$5`, `$10`, or `$20` bill.
- You must give the correct change so that each customer effectively pays $5.
- Initially, you have no money in your cash register.

Given an integer array `bills`, return:

- `true` if you can provide correct change to every customer.
- `false` if you cannot provide change to even one customer.

Important: Customers must be served in the given order. You cannot rearrange the bills.

## 3. Important Points

Each lemonade costs $5.

Therefore, the change required depends on the customer's bill.

| Customer pays | Change required |
| ------------- | --------------- |
| $5            | $0              |
| $10           | $5              |
| $20           | $15             |

We only need to track two types of bills:

- `five` – number of $5 bills.
- `ten` – number of $10 bills.

Why don't we track $20 bills?

Because we never need to give a customer a $20 bill as change. The required change is either $5 or $15.

## 4. Main Concepts – Greedy Algorithm

Which pattern should we recognize?

This problem involves:

- Processing customers in order.
- Maintaining available resources.
- Making the best local choice.
- Returning false when a transaction cannot be completed.

This is a Greedy + Simulation problem.

### Understand the greedy choice

When a customer pays $20, we need to return $15.

There are two possible combinations:

Option 1

# $10 + $5

One $10 bill and one $5 bill

Prefer this

Option 2

# $5 × 3

Three $5 bills

Fallback

Why prefer $10 + $5?

Because $5 bills are more useful.

- A $10 customer needs one $5 bill.
- A $20 customer needs either one $10 + one $5 or three $5 bills.

So, we should preserve our $5 bills whenever possible.

## 5. Main Logic – Step by Step

Initialize:

```
int five = 0;
int ten = 0;
```

Process every customer's bill.

Case 1: Customer pays $5

```
if (bill == 5) {
    five++;
}
```

No change is required. We receive one $5 bill.

Case 2: Customer pays $10

```
else if (bill == 10) {
    if (five == 0) {
        return false;
    }
    five--;
    ten++;
}
```

- Give one $5 bill as change.
- Receive one $10 bill.

Case 3: Customer pays $20

```
else {
    if (ten > 0 && five > 0) {
        ten--;
        five--;
    } else if (five >= 3) {
        five -= 3;
    } else {
        return false;
    }
}
```

- First preference: one $10 + one $5.
- Otherwise: three $5 bills.
- If neither is possible, return false.

After processing every customer, return `true`.

## 6. Java Solution – Optimal Greedy

```
class Solution {
    public boolean lemonadeChange(int[] bills) {

        int five = 0;
        int ten = 0;

        for (int bill : bills) {

            if (bill == 5) {
                five++;
            }

            else if (bill == 10) {

                if (five == 0) {
                    return false;
                }

                five--;
                ten++;
            }

            else {

                if (ten > 0 && five > 0) {
                    ten--;
                    five--;
                }

                else if (five >= 3) {
                    five -= 3;
                }

                else {
                    return false;
                }
            }
        }

        return true;
    }
}
```
