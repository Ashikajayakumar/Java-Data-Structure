# LeetCode 1665 — Minimum Initial Energy to Finish Tasks

Greedy Algorithm | Hard | Custom Sorting | Energy Management

## 1. Problem Statement

You are given a 2D integer array `tasks`.

Each task contains two values:

```
tasks[i] = [actual, minimum]
```

- `actual`: Energy required to complete the task.
- `minimum`: Minimum energy required before starting the task.

You can complete the tasks in any order.

Your goal is to find the minimum initial energy required to finish all tasks.

### Important example

Suppose:

```
Task = [10, 12]
```

This means:

- You need at least 12 energy to start.
- After completing the task, you spend 10 energy.
- If you start with 12 energy, you have 2 energy remaining.

If your current energy is 11, you cannot start this task, even though the actual cost is only 10.

## 3. Important Points

1. Every task has two values: actual energy and minimum starting energy.
2. You can rearrange the tasks.
3. You must satisfy the minimum requirement before starting each task.
4. After completing a task, subtract its actual energy.
5. We need the minimum initial energy, not the maximum remaining energy.
6. The order of tasks is the most important part of this problem.

## 4. Main Concepts — Greedy + Custom Sorting

This problem uses a Greedy Sorting Strategy.

The important question is:

Which task should we complete first?

Consider:

```
Task A = [1, 10]
Task B = [5, 6]
```

| Task | Actual energy | Minimum energy | Difference (`minimum - actual`) |
| ---- | ------------- | -------------- | ------------------------------- |
| A    | 1             | 10             | 9                               |
| B    | 5             | 6              | 1                               |

Task A requires 10 energy to start but consumes only 1 energy.

Task B requires only 6 energy but consumes 5 energy.

It is better to complete Task A first while our energy is high.

This gives us the greedy rule:

\\[ \boxed{\text{Sort by }(minimum-actual)\text{ in descending order}} \\]

In Java, we can write:

```
Arrays.sort(tasks, (a, b) ->
    Integer.compare(b[1] - b[0], a[1] - a[0])
);
```

Remember: A task with a larger `minimum - actual` difference should be completed earlier.

## 5. Main Logic — Step by Step

We use two variables to simulate the energy:

| Variable | Purpose                       |
| -------- | ----------------------------- |
| `energy` | Current available energy      |
| `answer` | Total initial energy required |

### Step 1 — Sort the tasks

Sort by:

\\[ minimum-actual \\]

in descending order.

Example:

```
Original:
[[1,2], [2,4], [4,8]]

Differences:
[1, 2, 4]

After sorting:
[[4,8], [2,4], [1,2]]
```

### Step 2 — Initialize variables

```
int energy = 0;
int answer = 0;
```

Initially, we have no energy in our simulation.

### Step 3 — Check the minimum requirement

For every task:

```
if (energy < minimum) {
    int need = minimum - energy;

    answer += need;
    energy += need;
}
```

If our current energy is less than the minimum requirement, we add only the missing amount.

For example:

```
Current energy = 4
Minimum needed = 8

Need = 8 - 4 = 4
```

We add 4 energy.

```
answer = answer + 4
energy = energy + 4
```

### Step 4 — Complete the task

```
energy -= actual;
```

After completing the task, subtract the actual energy consumed.

### Step 5 — Return the answer

After processing all tasks:

```
return answer;
```

The accumulated additional energy is the minimum initial energy required.

## 6. Java Solution — Optimal Greedy

```
import java.util.Arrays;

class Solution {
    public int minimumEffort(int[][] tasks) {

        // Sort by (minimum - actual) in descending order
        Arrays.sort(tasks, (a, b) ->
            Integer.compare(b[1] - b[0], a[1] - a[0])
        );

        int energy = 0;
        int answer = 0;

        // Process every task
        for (int i = 0; i < tasks.length; i++) {

            int actual = tasks[i][0];
            int minimum = tasks[i][1];

            // Check whether current energy is sufficient
            if (energy < minimum) {

                int need = minimum - energy;

                answer += need;
                energy += need;
            }

            // Complete the task
            energy -= actual;
        }

        return answer;
    }
}
```
