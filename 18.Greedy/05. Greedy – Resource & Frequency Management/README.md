## 📌 Pattern Recognition

| Problem Clue | Greedy Pattern |
|---|---|
| Give correct change while serving customers | Frequency + Resource Tracking |
| Complete a circular journey with limited fuel | Total Gas vs Total Cost |
| Schedule tasks with a cooldown period | Frequency + Max Heap |
| Distribute minimum candies based on ratings | Two-Pass Greedy |
| Minimize initial energy needed for all tasks | Sorting by Energy Requirement |
| Minimize the last blooming day | Sort by Decreasing Growth Time |
| Attend the maximum number of events | Sorting + Min Heap |
