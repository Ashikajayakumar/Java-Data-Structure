## 1. Problem Statement

There are `n` children standing in a line. Each child has a rating value given in an integer array `ratings`.

You must distribute candies according to these rules:

1. Every child must receive at least one candy.
2. If a child has a higher rating than an adjacent child, they must receive more candies than that neighbor.
3. Your goal is to distribute the minimum total number of candies.

Return the minimum number of candies required.

Important: We compare only adjacent children. Children with equal ratings do not need to receive equal candies.

## 2. Example

Example 1

```
Input:
ratings = [1, 0, 2]

Output:
5
```

Explanation:

We can distribute candies as:

```
Ratings:  [1, 0, 2]
Candies:  [2, 1, 2]
```

- Child 0 has a higher rating than child 1, so child 0 gets more candies.
- Child 2 has a higher rating than child 1, so child 2 gets more candies.
- Every child receives at least one candy.

Total:

\\[ 2+1+2=\boxed{5} \\]

Example 2

```
Input:
ratings = [1, 2, 2]

Output:
4
```

Explanation:

```
Ratings:  [1, 2, 2]
Candies:  [1, 2, 1]
```

The first child gets one candy, the second gets two, and the third gets one.

The last two children have equal ratings, so there is no extra requirement between them.

Total:

\\[ 1+2+1=\boxed{4} \\]

## 3. Important Points

- Every child must receive at least one candy.
- Higher rating than the left neighbor means more candies than the left neighbor.
- Higher rating than the right neighbor means more candies than the right neighbor.
- Equal ratings do not impose any candy requirement.
- We need to satisfy both left and right neighbor conditions.
- We must minimize the total candy count.

## 4. Main Concepts — Greedy + Two-Pass Technique

This problem is interesting because one traversal is not enough for the straightforward greedy solution.

Why?

Each child has two neighbors:

- Left neighbor.
- Right neighbor.

We must satisfy both conditions.

So we divide the problem into two independent passes.

Pass 1 — Left to Right

Handle the left neighbor condition.

If the current rating is greater than the previous rating:

```
candies[i] = candies[i - 1] + 1;
```

Pass 2 — Right to Left

Handle the right neighbor condition.

If the current rating is greater than the next rating:

```
candies[i] = Math.max(
    candies[i],
    candies[i + 1] + 1
);
```

The most important idea is:

Left pass + Right pass + Maximum value = Minimum valid candy distribution.

## 5. Main Logic — Step by Step

Let's understand the two-pass approach using:

```
ratings = [1, 2, 3, 2, 1]
```

### Step 1 — Give every child one candy

Initially:

```
Ratings:  [1, 2, 3, 2, 1]
Candies:  [1, 1, 1, 1, 1]
```

Every child gets the minimum of one candy.

### Step 2 — First pass: Left to Right

Check whether the current child has a higher rating than the child on the left.

Rule:

```
if (ratings[i] > ratings[i - 1]) {
    candies[i] = candies[i - 1] + 1;
}
```

Result:

```
Ratings:  [1, 2, 3, 2, 1]
Candies:  [1, 2, 3, 1, 1]
```

Why?

- Rating 2 is greater than 1 → give 2 candies.
- Rating 3 is greater than 2 → give 3 candies.
- Rating 2 is less than 3 → no change.
- Rating 1 is less than 2 → no change.

Now the left-neighbor condition is satisfied.

But the right-neighbor condition may not be satisfied yet.

### Step 3 — Second pass: Right to Left

Now traverse from the last child to the first child.

Rule:

```
if (ratings[i] > ratings[i + 1]) {
    candies[i] = Math.max(
        candies[i],
        candies[i + 1] + 1
    );
}
```

Why use `Math.max()`?

Because the first pass may already have given a child more candies.

We must not reduce that value and break the left-neighbor condition.

Result:

```
Ratings:  [1, 2, 3, 2, 1]
Candies:  [1, 2, 3, 2, 1]
```

### Step 4 — Calculate the total

```
total = 1 + 2 + 3 + 2 + 1;
```

\\[ \boxed{Total = 9} \\]

## 6. Java Solution — Optimal Two-Pass Greedy

```
class Solution {
    public int candy(int[] ratings) {

        int n = ratings.length;

        int[] candies = new int[n];

        // Give every child one candy
        for (int i = 0; i < n; i++) {
            candies[i] = 1;
        }

        // First pass: Left to Right
        for (int i = 1; i < n; i++) {

            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        // Second pass: Right to Left
        for (int i = n - 2; i >= 0; i--) {

            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(
                    candies[i],
                    candies[i + 1] + 1
                );
            }
        }

        // Calculate total candies
        int total = 0;

        for (int i = 0; i < n; i++) {
            total += candies[i];
        }

        return total;
    }
}
```

## 7. Understand the Code — Line by Line

Part A — Find the number of children

```
int n = ratings.length;
```

For example:

```
ratings = [1, 2, 3, 2, 1]

n = 5
```

There are five children.

Part B — Create the candies array

```
int[] candies = new int[n];
```

This array stores how many candies each child receives.

Part C — Give every child one candy

```
for (int i = 0; i < n; i++) {
    candies[i] = 1;
}
```

Initially:

```
candies = [1, 1, 1, 1, 1]
```

This satisfies the first condition: every child gets at least one candy.

Part D — First pass: Left to Right

```
for (int i = 1; i < n; i++) {
```

We start at index `1` because index `0` has no left neighbor.

```
if (ratings[i] > ratings[i - 1]) {
    candies[i] = candies[i - 1] + 1;
}
```

If the current child's rating is greater than the previous child's rating, give the current child one more candy.

Example:

```
ratings = [1, 2]
```

Since:

```
2 > 1
```

The candy distribution becomes:

```
[1, 2]
```

Part E — Second pass: Right to Left

```
for (int i = n - 2; i >= 0; i--) {
```

We start at `n - 2` because the last child has no right neighbor.

We move backward until index `0`.

```
if (ratings[i] > ratings[i + 1]) {
```

If the current child has a higher rating than the child on the right, the current child must receive more candies.

```
candies[i] = Math.max(
    candies[i],
    candies[i + 1] + 1
);
```

This is the most important line.

Suppose:

```
candies[i]     = 3
candies[i + 1] = 2
```

The right-side requirement is:

```
2 + 1 = 3
```

So:

```
Math.max(3, 3) = 3
```

If the current child already has 4 candies, we must preserve 4 rather than reduce it to 3.

Part F — Calculate the total

```
int total = 0;

for (int i = 0; i < n; i++) {
    total += candies[i];
}
```

Add all the candy counts.

Part G — Return the answer

```
return total;
```

The returned value is the minimum number of candies required.

## 8. Complete Dry Run — Example 1

Input

```
ratings = [1, 0, 2]
```

Initial distribution:

```
Ratings:  [1, 0, 2]
Candies:  [1, 1, 1]
```

### Pass 1 — Left to Right

Loop:

```
for (int i = 1; i < n; i++)
```

Iteration 1 — i = 1

```
ratings[1] = 0
ratings[0] = 1

0 > 1 ? No
```

No update.

```
candies = [1, 1, 1]
```

Iteration 2 — i = 2

```
ratings[2] = 2
ratings[1] = 0

2 > 0 ? Yes
```

Update:

```
candies[2] = candies[1] + 1;
```

```
candies[2] = 1 + 1 = 2
```

Now:

```
candies = [1, 1, 2]
```

### Pass 2 — Right to Left

Loop:

```
for (int i = n - 2; i >= 0; i--)
```

Here `n = 3`, so we start at index `1`.

Iteration 1 — i = 1

```
ratings[1] = 0
ratings[2] = 2

0 > 2 ? No
```

No update.

```
candies = [1, 1, 2]
```

Iteration 2 — i = 0

```
ratings[0] = 1
ratings[1] = 0

1 > 0 ? Yes
```

Update:

```
candies[0] = Math.max(
    candies[0],
    candies[1] + 1
);
```

```
candies[0] = Math.max(1, 1 + 1)
            = Math.max(1, 2)
            = 2
```

Final distribution:

```
candies = [2, 1, 2]
```

### Calculate the total

```
total = 2 + 1 + 2
      = 5
```

Output: 5
