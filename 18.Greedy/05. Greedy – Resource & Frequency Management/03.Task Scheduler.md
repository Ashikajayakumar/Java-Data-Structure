## 1. Problem Statement 

You are given an array of CPU tasks. Each task is represented by an uppercase English letter from `A` to `Z`.   
   
You are also given an integer `n`, which represents the cooldown period.   
 
Rules:

1. Each task takes exactly one unit of time. 
2. The CPU can execute only one task at a time.
3. Two identical tasks must have at least `n` intervals between them.
4. If no task is available, the CPU can remain idle.

Your task is to return the minimum number of CPU intervals required to complete all tasks.

## 2. Example

Example 1

```
Input:
tasks = ["A","A","A","B","B","B"]
n = 2

Output: 8
```

Explanation:

A possible execution order is:

```
A → B → Idle → A → B → Idle → A → B
```

Let's understand the cooldown:

- After executing `A`, we must wait 2 intervals before executing `A` again.
- The same rule applies to `B`.
- Idle intervals are needed because there are not enough different tasks to fill every gap.

## 3. Important Points

- `n = 0`: There is no cooldown. Execute all tasks consecutively.
- Higher-frequency tasks are harder to schedule because they need more cooldown gaps.
- Different tasks can fill the cooldown gaps.
- Idle intervals are counted in the answer.
- We need the minimum total time, not a particular task ordering.

## 4. Main Concepts — Greedy + Frequency Counting

We can solve this problem using a mathematical greedy formula.

The most frequent task determines how much space the schedule needs.

We need only two important values:

| Variable   | Meaning                                            |
| ---------- | -------------------------------------------------- |
| `maxFreq`  | Highest frequency of any task                      |
| `maxCount` | Number of task types having that highest frequency |

For example:

```
tasks = [A,A,A,B,B,B,C,C,D]
```

Frequency:

| Task | Frequency |
| ---- | --------- |
| A    | 3         |
| B    | 3         |
| C    | 2         |
| D    | 1         |

Therefore:

```
maxFreq  = 3
maxCount = 2
```

Both `A` and `B` have the maximum frequency.

## 5. Main Logic — Deriving the Greedy Formula

Instead of simulating every CPU interval, we can calculate the minimum time directly.

### Step 1 — Find the maximum frequency

Suppose:

```
tasks = [A,A,A,B,B,B]
n = 2
```

The frequency of `A` is 3 and the frequency of `B` is 3.

```
maxFreq = 3
maxCount = 2
```

### Step 2 — Arrange the most frequent tasks

Place the most frequent tasks first:

```
A _ _ A _ _ A
```

There are:

\\[ maxFreq - 1 = 3 - 1 = 2 \\]

gaps between the three occurrences of `A`.

Each gap needs at least `n = 2` intervals.

```
A _ _ | A _ _ | A
```

Initial idle slots:

\\[ (maxFreq - 1) \times n \\]

\\[ = 2 \times 2 = 4 \\]

### Step 3 — Fill the gaps using other tasks

We have three occurrences of `B`.

Place them in the available gaps:

```
A B _ | A B _ | A B
```

Now the schedule becomes:

```
A → B → Idle → A → B → Idle → A → B
```

The total number of intervals is 8.

### Step 4 — Calculate the formula

The formula is:

\\[ \boxed{(maxFreq-1)\times(n+1)+maxCount} \\]

Why `n + 1`?

Each full frame contains:

- One most-frequent task.
- `n` intervals for cooldown.

For this example:

\\[ (3-1)\times(2+1)+2 \\]

\\[ =2\times3+2 \\]

\\[ =\boxed{8} \\]

### Step 5 — Compare with the total number of tasks

Sometimes there are enough different tasks to fill all cooldown gaps.

For example:

```
tasks = [A,A,A,B,B,C,C,D,D]
n = 2
```

We cannot need fewer intervals than the number of actual tasks.

Therefore, the final formula is:

\\[ \boxed{ Answer = \max(tasks.length,\ (maxFreq-1)(n+1)+maxCount) } \\]

This is the optimal greedy formula.&#x20;

## 6. Java Solution — Optimal Greedy

```
class Solution {
    public int leastInterval(char[] tasks, int n) {

        int[] freq = new int[26];

        // Count the frequency of each task
        for (int i = 0; i < tasks.length; i++) {
            freq[tasks[i] - 'A']++;
        }

        int maxFreq = 0;

        // Find the maximum frequency
        for (int i = 0; i < 26; i++) {
            maxFreq = Math.max(maxFreq, freq[i]);
        }

        int maxCount = 0;

        // Count how many tasks have maximum frequency
        for (int i = 0; i < 26; i++) {
            if (freq[i] == maxFreq) {
                maxCount++;
            }
        }

        int result = (maxFreq - 1) * (n + 1) + maxCount;

        return Math.max(tasks.length, result);
    }
}
```
