## 1. Problem Statement

You are given two integer arrays:

- `plantTime[i]` = number of days required to plant seed `i`.
- `growTime[i]` = number of days required for seed `i` to grow after planting is completed.

You have several flower seeds, and you can plant only one seed at a time.

However, once a seed is completely planted, it can grow independently while you plant other seeds.

Your task is to find the earliest day when all flowers have bloomed.

You can choose the order in which you plant the seeds.

### Important concept

Planting and growing happen differently:

- Planting: only one seed can be planted at a time.
- Growing: multiple seeds can grow simultaneously.

Therefore, we should plant seeds strategically to allow seeds with longer growing times to start growing as early as possible.

## 3. Important Points

1. Only one seed can be planted at a time.
2. A seed starts growing only after its planting is complete.
3. Multiple seeds can grow simultaneously.
4. We can choose any planting order.
5. The final answer is the maximum bloom day among all seeds.
6. Seeds with longer growing times should generally be planted earlier.

## 4. Main Concepts — Greedy + Custom Sorting

The main question is:

Which seed should we plant first?

Consider:

```
Seed A:
plantTime = 2
growTime  = 10

Seed B:
plantTime = 3
growTime  = 2
```

If we plant Seed A first:

```
Seed A: Plant 2 days → Grow 10 days → Bloom day 12
Seed B: Plant 3 days → Grow 2 days  → Bloom day 7
```

All flowers bloom by day 12.

If we plant Seed B first:

```
Seed B: Plant 3 days → Grow 2 days  → Bloom day 5
Seed A: Plant 2 days → Grow 10 days → Bloom day 15
```

All flowers bloom by day 15.

So planting the seed with the longer growing time first is better.

Greedy rule:

\\[ \boxed{\text{Sort by growTime in descending order}} \\]

That means:

- Highest `growTime` first.
- Lowest `growTime` last.

Why? A seed with a long growing time should start growing as early as possible, while we continue planting the remaining seeds.

## 5. Main Logic — Step by Step

We use three important variables:

| Variable   | Purpose                                    |
| ---------- | ------------------------------------------ |
| `time`     | Total planting time completed so far       |
| `bloomDay` | Bloom day of the current seed              |
| `answer`   | Latest bloom day among all processed seeds |

### Step 1 — Sort by growing time

Sort seeds in descending order of `growTime`.

Example:

```
plantTime = [1, 4, 3]
growTime  = [2, 3, 1]
```

Pair the values:

```
Seed 0 = [1, 2]
Seed 1 = [4, 3]
Seed 2 = [3, 1]
```

After sorting:

```
[[4, 3], [1, 2], [3, 1]]
```

### Step 2 — Initialize variables

```
int time = 0;
int answer = 0;
```

Initially:

```
time = 0
answer = 0
```

### Step 3 — Calculate the planting completion day

For each seed:

```
time += plantTime;
```

The planting time is cumulative because we can plant only one seed at a time.

### Step 4 — Calculate the bloom day

```
int bloomDay = time + growTime;
```

A seed blooms after its planting is completed and its growing period finishes.

### Step 5 — Update the final answer

```
answer = Math.max(answer, bloomDay);
```

Why `Math.max()`?

Because we need the day when the last flower blooms.

### Step 6 — Return the answer

```
return answer;
```

## 6. Java Solution — Optimal Greedy

```
import java.util.Arrays;

class Solution {
    public int earliestFullBloom(int[] plantTime, int[] growTime) {

        int n = plantTime.length;

        // Store planting and growing times together
        int[][] seeds = new int[n][2];

        for (int i = 0; i < n; i++) {
            seeds[i][0] = plantTime[i];
            seeds[i][1] = growTime[i];
        }

        // Sort by growTime in descending order
        Arrays.sort(seeds, (a, b) ->
            Integer.compare(b[1], a[1])
        );

        int time = 0;
        int answer = 0;

        // Process seeds in sorted order
        for (int i = 0; i < n; i++) {

            // Complete planting this seed
            time += seeds[i][0];

            // Calculate its bloom day
            int bloomDay = time + seeds[i][1];

            // Find the latest bloom day
            answer = Math.max(answer, bloomDay);
        }

        return answer;
    }
}
```
