## 1. Problem Statement

There are `n` gas stations arranged in a circle.

You are given two integer arrays:

- `gas[i]` = amount of gas available at station `i`.
- `cost[i]` = amount of gas required to travel from station `i` to the next station `(i + 1) % n`.

Your car starts with an empty tank. You can choose any station as your starting point.

Your task is to return the starting station index from which you can travel around the entire circle and return to that station. If no starting station works, return `-1`.

Important: If a valid starting station exists, the problem guarantees that it is unique.

## 2. Example

Example 1

```
Input:
gas  = [1, 2, 3, 4, 5]
cost = [3, 4, 5, 1, 2]

Output:
3
```

Explanation:

Start at station `3` (zero-based index).

| Station | Gas collected | Travel cost | Gas left |
| ------- | ------------- | ----------- | -------- |
| 3       | 4             | 1           | 3        |
| 4       | 5             | 2           | 6        |
| 0       | 1             | 3           | 4        |
| 1       | 2             | 4           | 2        |
| 2       | 3             | 5           | 0        |

The car completes the full circle and returns to station `3`.

Example 2

```
Input:
gas  = [2, 3, 4]
cost = [3, 4, 3]

Output:
-1
```

The total gas is `9`, but the total travel cost is `10`. Therefore, completing the circle is impossible.

## 3. Important Points

1. The car starts with an empty tank.
2. You must have enough gas to travel to the next station.
3. The stations form a circle, so after the last station you return to index `0`.
4. You need to find a valid starting index, not the maximum amount of gas.
5. If total available gas is less than total travel cost, the answer must be `-1`.

## 4. Main Concepts — Greedy Approach

We use two important ideas:

A. Total gas check

Calculate:

\\[ totalGas = \sum gas[i] \\]

\\[ totalCost = \sum cost[i] \\]

If:

\\[ totalGas < totalCost \\]

there is not enough gas to complete the circle from any station.

So return `-1`.

B. Greedy starting station

At each station, calculate the net gas:

\\[ diff = gas[i] - cost[i] \\]

Maintain:

- `tank`: current remaining gas.
- `start`: possible starting station.
- `total`: total net gas across all stations.

If `tank` becomes negative, the current starting station cannot reach the next station.

The key greedy observation is:

If you start at station `start` and run out of gas at station `i`, none of the stations between `start` and `i` can be a valid starting point.

Therefore, move the starting station to `i + 1` and reset the tank to zero.

## 5. Main Logic — Step by Step

We can solve this in one traversal.

1. Initialize `total = 0`, `tank = 0`, and `start = 0`.
2. Visit every station.
3. Calculate the net gas: `gas[i] - cost[i]`.
4. Add the net gas to both `total` and `tank`.
5. If `tank < 0`:
   - The current starting point is invalid.
   - Set `start = i + 1`.
   - Reset `tank = 0`.
6. After visiting all stations:
   - If `total < 0`, return `-1`.
   - Otherwise, return `start`.

## 6. Java Solution — Optimal Greedy

```
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {

        int total = 0;
        int tank = 0;
        int start = 0;

        for (int i = 0; i < gas.length; i++) {

            int diff = gas[i] - cost[i];

            total += diff;
            tank += diff;

            if (tank < 0) {
                start = i + 1;
                tank = 0;
            }
        }

        if (total < 0) {
            return -1;
        }

        return start;
    }
}
```

## 7. Understand the Code — Line by Line

Part A — Initialize variables

```
int total = 0;
int tank = 0;
int start = 0;
```

| Variable | Purpose                                                        |
| -------- | -------------------------------------------------------------- |
| `total`  | Stores the net gas balance across all stations                 |
| `tank`   | Stores the current balance from our candidate starting station |
| `start`  | Stores the possible starting station index                     |

Part B — Traverse all stations

```
for (int i = 0; i < gas.length; i++) {
```

We visit each station exactly once, from index `0` to `n - 1`.

Part C — Calculate net gas

```
int diff = gas[i] - cost[i];
```

Net gas means:

\\[ \text{Net Gas} = \text{Gas Available} - \text{Travel Cost} \\]

For example, if a station provides 5 units and travel costs 2 units:

\\[ diff = 5 - 2 = 3 \\]

We gain 3 units.

Part D — Update total and current tank

```
total += diff;
tank += diff;
```

- `total` tracks the overall balance.
- `tank` tracks whether the current candidate start can reach the next stations.

Part E — Reset when the tank becomes negative

```
if (tank < 0) {
    start = i + 1;
    tank = 0;
}
```

If the tank becomes negative, we cannot travel to the next station from our current candidate.

We skip all stations from the previous candidate through `i` and try `i + 1`.

Part F — Check whether a solution exists

```
if (total < 0) {
    return -1;
}
```

If total gas is less than total cost, completing the circle is impossible.

Part G — Return the answer

```
return start;
```

If the total balance is non-negative, the remaining candidate is the valid starting station.

```

tank = 0
```

Iteration 2 — i = 1

```
diff = 2 - 4 = -2

total = -2 + (-2) = -4
tank  = 0 + (-2) = -2
```

Since `tank < 0`:

```
start = 1 + 1 = 2
tank = 0
```

```

total = -4 + (-2) = -6
tank  = 0 + (-2) = -2
```

Since `tank < 0`:


Tank is positive, so continue.
